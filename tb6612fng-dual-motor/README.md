# TB6612FNG Pre-Soldered Dual DC & Stepper Motor Driver Module for Arduino, Raspberry Pi & ESP32

The TB6612FNG pre-soldered dual motor driver is a small H-bridge board for driving two DC motors or one stepper from microcontrollers like Arduino, ESP32, or single-board computers like Raspberry Pi. Developers can use it to build motorized projects such as robots, motorized platforms, or simple actuators with direction control, PWM speed control, and braking.
