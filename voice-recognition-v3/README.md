# Voice Recognition Module V3 for Arduino

The Voice Recognition Module V3 is a UART-based module that stores trained voiceprints onboard and recognizes spoken commands. Developers can use it to add simple voice control to projects (lights, robots, appliances); verify the module pinout and voltage levels before wiring it into a microcontroller or Raspberry Pi.
