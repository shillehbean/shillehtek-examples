# Esp32 examples

- [`example.ino`](./example.ino) — Print the ESP32-P4 chip model and PSRAM size over serial, initialize I2C on SDA=GPIO7 SCL=GPIO8, and scan the I2C bus for devices (the ES8311 codec is expected at 0x18).
