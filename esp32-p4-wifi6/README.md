# ESP32-P4 Wi-Fi 6 Development Board Kit

The ESP32-P4 Wi-Fi 6 Development Board Kit is built around Espressif's ESP32-P4 dual-core RISC‑V microcontroller (with 32 MB of PSRAM inside the package and 16 MB of on-board flash) and uses an ESP32-C6 companion chip over SDIO to provide Wi‑Fi 6 and Bluetooth 5 LE. Developers can use this board to build Wi‑Fi 6 and BLE-enabled applications, audio projects using the on-board ES8311 codec, and high-performance edge compute tasks.
