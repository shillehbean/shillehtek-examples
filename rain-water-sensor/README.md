# Rain and Water Level Detection Sensor Module for Arduino, Raspberry Pi & ESP32

This is a rain and water level detection sensor module that uses exposed probe contacts to detect presence and approximate level of water. Developers can use it to build leak alerts, tank-level sensors, or irrigation control systems with Arduino, Raspberry Pi, or ESP32 while powering the probe from a GPIO to reduce corrosion.
