# Micropython examples

- [`example_1.py`](./example_1.py) — In MicroPython on ESP32, briefly powers the probe from a GPIO, reads the ADC (0-4095), classifies the level as dry/low/HIGH, and prints the reading in a loop.
- [`example_2.py`](./example_2.py) — On a Raspberry Pi Pico running MicroPython, briefly powers the probe from a GPIO, reads the 16-bit ADC value, determines dry/low/HIGH water state, and prints the result repeatedly.
