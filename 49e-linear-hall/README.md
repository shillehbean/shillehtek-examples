# 49E Linear Hall Effect Magnetic Sensor for Arduino & ESP32

The 49E is a ratiometric linear Hall effect sensor that outputs an analog voltage proportional to magnetic field strength. Developers can use it to measure magnetic field (gauss), detect magnet polarity, or build simple position/limit sensing projects with microcontrollers like Arduino, ESP32, or Raspberry Pi (with an ADC).
