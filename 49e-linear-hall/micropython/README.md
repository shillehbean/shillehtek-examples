# Micropython examples

- [`example_1.py`](./example_1.py) — ESP32 MicroPython script that samples GPIO34 with full-range ADC, calibrates the zero point, converts voltage to gauss, and prints readings and detected pole to the REPL.
- [`example_2.py`](./example_2.py) — Raspberry Pi Pico MicroPython example that samples ADC0 (GP26), calibrates the zero-voltage baseline, converts readings to gauss, and prints field strength and pole to the REPL.
