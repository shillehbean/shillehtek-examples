# MPU6050 Accelerometer 6DOF - Raspberry Pi, Arduino, ESP32 I2C Accelerometer

The MPU6050 is a 6-axis inertial measurement unit combining a 3-axis accelerometer and 3-axis gyroscope. Use this module to add motion sensing to projects — for example tilt detection, basic orientation, gesture inputs, or simple dead-reckoning on Arduino, ESP32, or Raspberry Pi.
