# Arduino examples

- [`example.ino`](./example.ino) — Initializes the MPU6050 using the Adafruit_MPU6050 library, configures accelerometer/gyro ranges and filter bandwidth, then prints accelerometer, gyro, and temperature readings to the Serial console every 500 ms.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/mpu6050-accelerometer-6dof-raspberry-pi-arduino-esp32-i2c-accelerometer)
