# GY-906 MLX90614 BAA Non-Touch Infrared Temperature Sensor

The GY-906 MLX90614 BAA is a pre-soldered non-contact infrared temperature sensor module that reports object and ambient temperature over I2C. Developers can use it to add contactless temperature sensing to projects such as digital thermometers, thermal monitoring, or presence/skin-temperature detection with Arduino, ESP32, Raspberry Pi, or MicroPython boards.
