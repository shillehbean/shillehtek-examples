# Micropython examples

- [`example.py`](./example.py) — Runs on a MicroPython board (e.g., Pico), uses I2C0 (GP0 SDA, GP1 SCL) with an mlx90614 driver to read and print ambient and object temperatures in a loop.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/gy-906-mlx90614-baa-non-touch-infrared-temperature-sensor)
