# KY-040 Encoder

The KY-040 is a mechanical rotary encoder with an integrated push button. Developers can use it as a rotary input (for example a volume knob, menu selector, or jog wheel) in microcontroller or Raspberry Pi projects; the examples show how to read rotations and the push button on Arduino, ESP32, Raspberry Pi, and MicroPython.
