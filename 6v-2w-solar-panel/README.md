# 6V 2W Solar Panel

This is a small 6 V, 2 W photovoltaic panel useful for low-power projects like battery trickle chargers, sensor nodes, and simple power experiments. Example projects below show how to read the panel voltage and measure current/power using Arduino, ESP32, and a Pico with an INA219.
