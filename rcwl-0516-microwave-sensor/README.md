# RCWL-0516

The RCWL-0516 is a microwave Doppler radar motion sensor that outputs a digital HIGH when it detects movement. Developers can use it to add motion detection to projects (Arduino, ESP32, Raspberry Pi, or MicroPython) for triggering lights, logging events, counting people, or other automation tasks.
