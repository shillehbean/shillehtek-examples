# W5500 SPI Ethernet Network Module for Arduino & ESP32

The W5500 SPI Ethernet board provides a hardware TCP/IP controller accessible over SPI for adding wired LAN to microcontrollers. Developers can use it to build web servers, HTTP clients, remote monitoring, and other embedded TCP/IP projects with Arduino, ESP32, or RP2040 (Pico) boards.
