# Python examples

- [`example_1.py`](./example_1.py) — CircuitPython client for Raspberry Pi Pico using the adafruit_wiznet5k driver to bring up Ethernet via DHCP and fetch a web page with adafruit_requests.
- [`example_2.py`](./example_2.py) — CircuitPython web server for Raspberry Pi Pico that listens on port 80 and serves a simple HTML page with hit count and uptime using the WIZNET5K driver.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/w5500-spi-ethernet-module-arduino-esp32-manual)
