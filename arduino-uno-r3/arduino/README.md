# Arduino examples

- [`example_1.ino`](./example_1.ino) — Blinks the board's built-in LED on pin 13 at a 1 Hz rate (500 ms on, 500 ms off).
- [`example_2.ino`](./example_2.ino) — Uses PWM on pin 9 to smoothly fade an external LED in and out by varying duty cycle with analogWrite.
- [`example_3.ino`](./example_3.ino) — Reads a pushbutton using the internal pull-up on pin 2 and turns an LED on pin 8 on while the button is pressed.
- [`example_4.ino`](./example_4.ino) — Reads an analog value from a potentiometer on A0, converts it to a voltage, and prints raw and voltage readings to Serial at 9600 baud.
