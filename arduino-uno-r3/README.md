# Super Starter Kit for Arduino Uno R3 with Tutorial

Super Starter Kit for Arduino Uno R3 provides an Arduino Uno R3 board and common components to learn basic electronics and Arduino programming. Example projects include blinking the onboard LED, PWM LED fading, reading a pushbutton with the internal pull-up, and sampling a potentiometer via analog input.
