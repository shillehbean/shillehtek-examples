# 28BYJ-48 5V 4-Phase Stepper Motor for Arduino, Raspberry Pi & ESP32

The 28BYJ-48 is a 5V 4‑phase stepper motor commonly paired with a ULN2003 driver board for low-cost positional control. This repo contains example sketches and scripts to drive the motor from Arduino, Raspberry Pi, ESP32 and RP2040 (MicroPython) to build projects such as pan/tilt mechanisms, rotary actuators, or small robot drives.
