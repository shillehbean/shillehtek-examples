# Micropython examples

- [`example_1.py`](./example_1.py) — MicroPython example for ESP32 that drives the 28BYJ-48 in half-step mode to perform one full revolution clockwise and counter-clockwise, with coil release after motion.
- [`example_2.py`](./example_2.py) — MicroPython example for Raspberry Pi Pico (RP2040) that runs the 28BYJ-48 in half-step mode to rotate one revolution clockwise and counter-clockwise, then releases the coils.
