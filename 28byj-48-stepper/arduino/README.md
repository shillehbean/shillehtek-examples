# Arduino examples

- [`example.ino`](./example.ino) — Uses the built-in Arduino Stepper library to rotate the 28BYJ-48 one full revolution clockwise and counter-clockwise at a set RPM, demonstrating the correct pin ordering for the ULN2003 board.
