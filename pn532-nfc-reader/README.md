# PN532 NFC RFID Reader Writer Module V3 13.56MHz

The PN532 NFC RFID Reader Writer V3 is a 13.56MHz breakout based on the PN532 controller that supports I2C, SPI, and serial interfaces. Developers can use it to read/write ISO14443A/MIFARE tags and build projects like tag readers, access control systems, or simple data-exchange prototypes for Arduino, ESP32, Raspberry Pi, or MicroPython platforms.
