# FS90R 360-Degree Continuous Rotation Micro Servo

The FS90R is a 360-degree continuous-rotation micro servo whose output shaft keeps turning; pulse width controls direction and speed (about 1.5 ms stops). Developers can use it for small wheeled robots, pan/drive mechanisms, or other projects that need continuous rotary motion and simple speed/direction control.
