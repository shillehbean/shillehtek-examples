# Micropython examples

- [`example.py`](./example.py) — Reads temperature from a MAX6675 using MicroPython on a Pico (or similar) via SPI, converting the raw 12-bit value to Celsius and printing the result while detecting an open thermocouple.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/max6675-module-k-type-thermocouple-sensor-measures-up-to-1024-degrees-manual)
