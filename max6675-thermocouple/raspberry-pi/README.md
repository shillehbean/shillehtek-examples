# Raspberry Pi examples

- [`example.py`](./example.py) — Uses Python with spidev on a Raspberry Pi to read the MAX6675 over SPI, convert the raw data to Celsius, and print temperature or a disconnected warning in a loop.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/max6675-module-k-type-thermocouple-sensor-measures-up-to-1024-degrees-manual)
