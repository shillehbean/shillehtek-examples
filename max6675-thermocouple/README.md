# MAX6675

The MAX6675 is an SPI thermocouple-to-digital converter for K-type thermocouples, providing temperature readings with 0.25 °C resolution. These examples show how to read temperatures from the MAX6675 on Arduino, ESP32, Raspberry Pi, and MicroPython boards so you can build temperature monitors, data loggers, or basic oven/thermal controllers.
