# Esp32 examples

- [`example.ino`](./example.ino) — Samples the AD8232 OUTPUT on ESP32 ADC1 (GPIO34) with 11dB attenuation and prints 0 on lead-off or the 0–4095 ADC value at ~500 Hz.
