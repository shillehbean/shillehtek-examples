# ECG Electrode Pads 5-Pack for AD8232 Heart Rate & ECG Sensor

Disposable ECG electrode pads used with the AD8232 heart rate & ECG sensor for short-term biosignal measurements. Developers can use these pads to build simple ECG monitoring projects with Arduino, ESP32, Raspberry Pi (with an ADC), or MicroPython-capable boards.
