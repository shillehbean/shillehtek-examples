# Micropython examples

- [`example.py`](./example.py) — MicroPython example (e.g., Raspberry Pi Pico) that reads the AD8232 OUTPUT on ADC GP26 and prints a 12-bit-like sample or 0 if LO+ / LO- indicate an electrode is loose, at ~500 Hz.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/ecg-electrode-pads-ad8232-5-pack-manual)
