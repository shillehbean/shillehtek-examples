# Raspberry Pi examples

- [`example.py`](./example.py) — Uses an ADS1115 I²C ADC on a Raspberry Pi to read the AD8232 OUTPUT (ADS A0) at a high data rate and prints raw values every ~2 ms for plotting or logging.
