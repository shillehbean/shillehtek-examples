# Arduino examples

- [`example.ino`](./example.ino) — Reads the AD8232 analog OUTPUT on A0 and reports either the ECG waveform (analogRead) or 0 when LO+ or LO- indicate a lead-off, printing at ~500 samples/s to the Serial Plotter.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/ecg-electrode-pads-ad8232-5-pack-manual)
