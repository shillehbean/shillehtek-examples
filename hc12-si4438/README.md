# HC-12 433MHz Long-Range Wireless Serial Transceiver Module (SI4438) for Arduino, Raspberry Pi & ESP32

The HC-12 (SI4438) is a 433 MHz long-range wireless serial transceiver for creating transparent UART links between microcontrollers and single-board computers. Developers can use it to build chat links, telemetry senders, or packet loggers between Arduinos, ESP32s, and Raspberry Pis; the examples here show UART wiring, basic AT configuration, and simple send/receive sketches and scripts.
