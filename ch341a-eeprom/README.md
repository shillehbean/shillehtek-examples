# CH341A USB EEPROM & BIOS Flash Programmer (24/25 Series)

This repository documents using the CH341A USB EEPROM & BIOS flash programmer to read, write, erase, and back up 24/25-series SPI and I2C EEPROMs and BIOS chips. A developer can use these instructions to make verified backups, recover or reflash router/BIOS firmware, and program small serial memory chips for embedded projects.
