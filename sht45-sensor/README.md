# GY-SHT45 Pre-Soldered Temperature & Humidity I2C Sensor Module

The GY-SHT45 is a pre-soldered I2C temperature and humidity sensor board using Sensirion's SHT45 chip. Developers can use it to add high-accuracy temperature (≈±0.1°C) and relative-humidity (≈±1%RH) measurements to weather stations, incubators, filament dry boxes, or indoor climate loggers.
