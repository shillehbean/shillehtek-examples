# Micropython examples

- [`example_1.py`](./example_1.py) — MicroPython script for ESP32 that maps a 5x5 WS2812B matrix, applies brightness scaling, draws heart and smile bitmaps, and runs a bouncing-pixel animation.
- [`example_2.py`](./example_2.py) — MicroPython script for the Raspberry Pi Pico that maps a 5x5 WS2812B matrix, scales brightness, displays tiny 5x5 digit bitmaps (0–3), and cycles through them.
