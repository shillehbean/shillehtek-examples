# Arduino examples

- [`example.ino`](./example.ino) — Arduino sketch using Adafruit_NeoPixel to map a 5x5 WS2812B matrix (optional serpentine indexing), run an index test to show pixel order, and draw a 5x5 heart in alternating colors.
