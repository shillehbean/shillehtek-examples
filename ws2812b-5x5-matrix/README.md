# WS2812B 5x5 RGB LED Matrix Module for Arduino, Raspberry Pi & ESP32

A 5x5 WS2812B RGB LED matrix breakout for creating small pixel displays. Developers can use it to build animated icons, indicators, tiny numeric displays, or wearable pixel art controlled from an Arduino, Raspberry Pi, or ESP32.
