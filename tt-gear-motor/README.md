# TT Gear Motor 3-6V 1:48 125RPM for Robot Car

The TT Gear Motor (3–6V, 1:48, ~125 RPM) is a small DC geared motor commonly used to drive wheels on hobby robot cars and small mobile robots. This repository contains basic control examples and notes for using the motor with Arduino-class boards and microcontrollers via common motor drivers (e.g., L298N).
