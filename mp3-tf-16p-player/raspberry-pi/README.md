# Raspberry Pi examples

- [`example.py`](./example.py) — Raspberry Pi (Python) example that builds and sends raw 10-byte DFPlayer command frames over /dev/serial0 (pyserial) to initialize the device, set volume, play/pause/skip tracks, and stop playback.
