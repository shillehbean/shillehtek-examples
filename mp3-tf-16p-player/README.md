# MP3-TF-16P Mini MP3 Player Module with TF Card Slot for Arduino & Raspberry Pi

The MP3-TF-16P is a compact serial-controlled MP3 player board with a TF (microSD) card slot that accepts simple UART command frames or the DFPlayer protocol. Developers can use it to add standalone audio playback to Arduino, ESP32, Raspberry Pi, or MicroPython projects for sound effects, voice prompts, or background music.
