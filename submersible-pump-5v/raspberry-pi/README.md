# Raspberry Pi examples

- [`example.py`](./example.py) — Toggles GPIO18 on a Raspberry Pi using RPi.GPIO to switch the pump on for 5 seconds and off for 55 seconds in a loop, assuming the pump is powered from the Pi's 5V rail or an external 5V supply.
