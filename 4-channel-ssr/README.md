# 4-Channel 5V Solid State Relay Module (High-Level Trigger) for Arduino, Raspberry Pi & ESP32

This board is a 4-channel, 5V high-level trigger solid state relay (SSR) interface that provides four GPIO-controlled outputs for microcontrollers and SBCs. Use it to add isolated switching of lamps, heaters, or other loads from Arduino, Raspberry Pi, or ESP32 projects — observe safe mains wiring practices when switching high voltage loads.
