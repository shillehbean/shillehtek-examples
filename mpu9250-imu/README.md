# MPU9250 Authentic GY-9250 Pre-Soldered 9-Axis 9 DOF Accelerometer + Magnetometer

The MPU9250 Authentic GY-9250 is a pre-soldered 9-axis IMU combining a 3-axis accelerometer, 3-axis gyroscope, and 3-axis magnetometer. Developers can use it to build motion-tracking, orientation/heading, sensor-fusion, or stabilization projects on Arduino, ESP32, Raspberry Pi, or MicroPython-capable boards.
