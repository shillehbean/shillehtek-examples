# Esp32 examples

- [`example.ino`](./example.ino) — Initializes I2C on an ESP32 (GPIO21 SDA, GPIO22 SCL), reads the MPU9250, and prints computed roll, pitch, and yaw values to Serial in a 20 ms loop.
