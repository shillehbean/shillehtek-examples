# HLK-2410B

The HLK-2410B is a Doppler radar presence sensor that outputs simple ASCII status messages over UART (for example, "ON" when presence is detected and "OFF" otherwise). Developers can use it to build occupancy detectors, motion-triggered automations, or door/room presence monitors by reading its serial output and reacting to state changes.
