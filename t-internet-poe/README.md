# TTGO T-Internet-POE ESP32 Ethernet Development Board (LAN8720A)

The TTGO T-Internet-POE is an ESP32 development board that integrates a LAN8720A Ethernet PHY and supports Power-over-Ethernet. Developers can use it to build wired IoT devices, networked sensors, and controllers where reliable Ethernet connectivity and optional PoE are required.
