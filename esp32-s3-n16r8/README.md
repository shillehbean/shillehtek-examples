# ESP32-S3 N16R8 Pre-Soldered Development Board with IPEX Antenna Connector

This board carries an ESP32-S3 N16R8 module (16 MB flash, 8 MB PSRAM), an IPEX antenna connector, and pre-soldered headers. The Arduino example reports chip and memory information, while the MicroPython example displays free heap and cycles the onboard RGB LED.
