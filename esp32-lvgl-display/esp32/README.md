# Esp32 examples

- [`example_1.ino`](./example_1.ino) — TFT_eSPI configuration: defines the ILI9341 driver, screen dimensions, SPI and touch pins, SPI speeds, backlight pin state, and enabled fonts/features.
- [`example_2.ino`](./example_2.ino) — Sets up LVGL with a TFT_eSPI draw buffer and flush callback, registers the display driver, and creates a simple centered LVGL button labeled 'Hello CYD'.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/esp32-lvgl-2-8-inch-240x320-smart-display-with-resistive-touch-wifi-bluetooth-dev-board-manual)
