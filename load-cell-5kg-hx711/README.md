# 5kg Load Cell with HX711 Amplifier Weighing Sensor Kit for Arduino, Raspberry Pi & ESP32

This product combines a 5 kg strain gauge load cell with an HX711 ADC/amplifier for measuring weight or force. Developers can use it to build digital scales or force-sensing projects with Arduino, Raspberry Pi, or ESP32 and log or display measurements.
