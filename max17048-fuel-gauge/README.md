# MAX17048 Pre-Soldered Single-Cell Lithium Battery Fuel Gauge Module

The MAX17048 is a single-cell lithium battery fuel gauge that reports cell voltage and an estimated state-of-charge over I2C. Developers can use this small pre-soldered board to monitor battery level from microcontrollers or single-board computers and build battery-powered projects that need simple fuel-gauge information.
