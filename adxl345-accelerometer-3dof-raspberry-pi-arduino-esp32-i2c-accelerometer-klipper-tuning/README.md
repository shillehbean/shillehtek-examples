# ADXL345 Accelerometer 3DOF - Raspberry Pi, Arduino, ESP32 I2C Accelerometer | Klipper Tuning

The ADXL345 is a 3-axis accelerometer for measuring acceleration and motion on X, Y, and Z axes. Developers can use this board with Raspberry Pi, Arduino, or ESP32 to build motion detection, tilt sensing, inertial measurements, or to assist with Klipper tuning for 3D printers.
