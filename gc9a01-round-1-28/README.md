# 1.28" Round IPS LCD Display Module (GC9A01, 240x240) for Arduino, Raspberry Pi & ESP32

This is a 1.28" round IPS LCD based on the GC9A01 controller with a 240×240 pixel resolution. Developers can use it to build round gauges, clocks, watch faces, and small graphical UIs on Arduino, ESP32, Raspberry Pi or MicroPython platforms.
