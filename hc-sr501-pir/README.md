# HC-SR501 PIR Motion Sensor

The HC-SR501 PIR Motion Sensor is a passive infrared sensor that detects changes in IR radiance caused by moving objects. Developers can use it to build motion-activated lighting, simple alarms, or occupancy sensing projects with Arduino, ESP32, or Raspberry Pi.
