# 10K NTC Thermistor Temperature Sensor (MF52-103)

The MF52-103 is a 10K NTC thermistor intended for analog temperature sensing. Developers can use it in Arduino, ESP32, Raspberry Pi, or microcontroller projects to build temperature monitors for HVAC, batteries, 3D printers, and general environmental sensing.
