# Raspberry Pi examples

- [`example.py`](./example.py) — Uses an ADS1115 ADC on Raspberry Pi to read the divider voltage, calculates the thermistor resistance and converts it to temperature with the beta (Steinhart) equation, printing C and F periodically.
