# Micropython examples

- [`example_1.py`](./example_1.py) — Runs on an ESP32 with MicroPython: samples ADC (GPIO34) in microvolts, computes the NTC resistance and converts it to temperature (°C/°F) using the beta formula.
- [`example_2.py`](./example_2.py) — Example for a Raspberry Pi Pico running MicroPython: samples the 16-bit ADC (GP26), computes the thermistor resistance from the divider, and converts it to temperature using the beta equation.
