# DHT11 Digital Temperature and Humidity Sensor Module with Cable

The DHT11 is a low-cost digital sensor that reports temperature and relative humidity. This module includes the DHT11 sensor with a cable and is suitable for building basic weather stations, home automation sensors, or environmental logging projects.
