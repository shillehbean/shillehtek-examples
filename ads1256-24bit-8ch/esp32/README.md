# Esp32 examples

- [`example.ino`](./example.ino) — Arduino (Arduino-framework) example for ESP32/Uno that uses SPI to talk to the ADS1256, waits for DRDY, and reads all eight single-ended channels converting 24-bit samples to voltages.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/ads1256-adc-spi-24-bit-8-channel-module-manual)  
Buy the module: https://shillehtek.com/products/ads1256-adc-spi-24-bit-8-channel-module
