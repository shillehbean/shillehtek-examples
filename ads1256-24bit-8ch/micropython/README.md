# Micropython examples

- [`example.py`](./example.py) — MicroPython example for Raspberry Pi Pico (RP2040) that uses machine.SPI to send commands to the ADS1256, wait for DRDY, and read all eight inputs as single-ended voltages.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/ads1256-adc-spi-24-bit-8-channel-module-manual)
