# ADS1256 24-Bit 8-Channel ADC Module

The ADS1256 is a 24-bit delta-sigma ADC with eight inputs and a programmable gain amplifier for high-resolution sensor measurements. This repository contains simple examples (Arduino/ESP32, Raspberry Pi/Python, and MicroPython for RP2040) showing how to read single-ended channels and convert the 24-bit samples into voltages for sensors such as load cells and thermocouples.
