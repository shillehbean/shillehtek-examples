# MAX9814 Pre-Soldered Microphone AGC Amplifier Module

The MAX9814 module combines an electret microphone, an amplifier, and automatic gain control (AGC). A compatible ADC can sample its analog audio output for relative sound-level displays and sound-triggered projects. These examples report peak-to-peak readings, not calibrated sound-pressure levels.
