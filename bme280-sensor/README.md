# BME280 Environmental Sensor - Raspberry Pi, Arduino, ESP32 I2C Humidity, Pressure, and Temperature Measurement

The BME280 is a combined humidity, pressure, and temperature sensor that communicates over I2C. Developers can use this board with Raspberry Pi, Arduino, ESP32, or MicroPython boards to log environmental data, build weather stations, indoor climate monitors, or simple altimeters.
