# APDS-9960 RGB Gesture, Proximity & Color Sensor Module for Arduino, Raspberry Pi & ESP32

The APDS-9960 is a combined RGB color, ambient light, proximity, and gesture sensor. This repository contains example sketches and scripts showing how to read proximity, color/ambient light, and detect swipe gestures with Arduino, ESP32, Raspberry Pi, and MicroPython devices.
