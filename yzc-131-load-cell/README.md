# YZC-131 5kg Load Cell Weighing Sensor with Wires for Arduino, Raspberry Pi & ESP32

The YZC-131 is a 5 kg strain gauge load cell with pre-attached wires for use with an HX711 ADC/amplifier. Developers can use it to build small digital scales, force-sensing platforms, or weight-triggered projects with Arduino, Raspberry Pi, or ESP32 using an HX711 interface.
