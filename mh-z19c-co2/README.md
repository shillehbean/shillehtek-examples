# MH-Z19C NDIR Infrared CO2 Sensor Module for Arduino, Raspberry Pi & ESP32

The MH-Z19C is an NDIR infrared CO2 sensor module that reports CO2 concentration over a fixed 9600 baud UART. Developers can use it to build air-quality monitors, demand-controlled ventilation, or safety monitors with Arduino, Raspberry Pi, or ESP32.
