# 2.13" E-Paper HAT

This is a 2.13" black & white e-paper HAT for Raspberry Pi and compatible microcontrollers. Developers can use it to display static text, simple graphics, and low-power status UIs such as dashboards, labels, or clocks; examples show Raspberry Pi (Python), ESP32/Arduino, and Pico/MicroPython usage.
