# MCP23017 Pre-Soldered I2C 16-Bit I/O Port Expander for Arduino, Raspberry Pi & ESP32

The MCP23017 Pre-Soldered I2C 16-Bit I/O Port Expander provides 16 additional digital GPIO pins accessible over I2C. Use it to add LEDs, buttons, relays, or other digital sensors to Arduino, Raspberry Pi, and ESP32 projects when you need more I/O. The examples show initializing the chip, configuring pin directions and pull-ups, blinking an LED, and reading a button press.
