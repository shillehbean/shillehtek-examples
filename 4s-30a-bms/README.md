# 4S 30A BMS

This is a 4S 30A battery management / protection board for 14.8V (4-cell) Li-ion packs. Developers can use it to monitor pack voltage and implement low-battery cutoffs or logging with microcontrollers such as Arduino, ESP32, or Raspberry Pi Pico.
