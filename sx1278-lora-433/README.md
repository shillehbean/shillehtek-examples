# Ra-02 SX1278 LoRa 433MHz Wireless Transceiver Module for Arduino, ESP32, STM32 & Raspberry Pi

The Ra-02 (SX1278) is a 433 MHz LoRa transceiver breakout that interfaces over SPI and supports long-range, low-power wireless links. Developers can use it to build sensor nodes, remote controls, or simple telemetry links between Arduino, ESP32, STM32, and Raspberry Pi hosts.
