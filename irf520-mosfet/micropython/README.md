# Micropython examples

- [`example.py`](./example.py) — Configures a PWM output in MicroPython (duty_u16 resolution) and runs a sequence that slowly ramps the duty, flashes the output, then turns it off to demonstrate PWM control on boards like the RP2040 or other MicroPython-compatible targets.
