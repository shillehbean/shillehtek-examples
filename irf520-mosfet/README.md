# IRF520 MOSFET Driver Module for Arduino, Raspberry Pi & ESP32

The IRF520 MOSFET is a low-side switching driver board for PWM or on/off control of DC loads such as LED strips, small motors, and fans using logic-level inputs. This repository provides example code for driving the module from Arduino, ESP32, Raspberry Pi (gpiozero), and MicroPython so you can build dimming, speed-control, and simple switching projects.
