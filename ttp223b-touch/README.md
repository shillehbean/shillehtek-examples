# TTP223B

The TTP223B is a single-channel capacitive touch switch that provides a digital HIGH/LOW output when its pad is touched. Developers can use it as a touch button to toggle LEDs, send events, or wake systems; this repo provides Arduino, MicroPython (ESP32/Pico), and Raspberry Pi examples to get started.
