# Micropython examples

- [`example_1.py`](./example_1.py) — Monitors the TTP223 input on GPIO4 (ESP32) and prints 'Touched' or 'Released' when the input state changes.
- [`example_2.py`](./example_2.py) — Runs on a Pico to detect rising touch events from the TTP223 on GP15 and toggle the onboard LED while printing the LED state.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/digital-sensor-ttp223b-module-capacitive-touch-switch-manual)
