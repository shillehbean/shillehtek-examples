# Esp32 examples

- [`example.ino`](./example.ino) — Uses ESP32 hardware UART2 (RX=16, TX=17) with a direction pin on GPIO4 to transmit a counter message over RS‑485, then switch to receive and print incoming lines to the USB Serial.
