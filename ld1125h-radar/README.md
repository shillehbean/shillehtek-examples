# LD1125H

The LD1125H is a 24 GHz short-range FMCW radar that outputs simple ASCII frames indicating motion/occupancy and distance. Developers can use it to build presence detectors, short-range motion sensors, or proximity monitors; this repo contains example sketches for Arduino, ESP32, Raspberry Pi, and Raspberry Pi Pico/MicroPython to read the sensor and send basic configuration commands.
