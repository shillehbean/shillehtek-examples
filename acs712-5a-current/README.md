# ACS712 5A Current Sensor Module for Arduino & ESP32

The ACS712 5A current sensor is a Hall-effect based analog sensor that outputs a voltage proportional to DC current through the IP+/IP- terminals. Use it with Arduino, ESP32, Raspberry Pi (with an external ADC), or other microcontrollers to measure and log current for monitoring, protection, or power-tracking projects. Example sketches show zero-offset calibration and converting the sensor voltage to amps.
