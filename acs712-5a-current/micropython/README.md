# Micropython examples

- [`example_1.py`](./example_1.py) — ESP32 MicroPython script that reads the ACS712 via ADC (with a voltage divider), calibrates the zero offset, and prints measured voltage and DC current.
- [`example_2.py`](./example_2.py) — Raspberry Pi Pico MicroPython script that reads the ACS712 through the GP26 ADC (with a voltage divider), calibrates the zero offset, and prints measured voltage and DC current.
