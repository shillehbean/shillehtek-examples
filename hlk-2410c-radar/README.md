# HLK-2410C

The HLK-2410C is a serial-interfaced presence and distance radar sensor that speaks the LD2410-style frame protocol. Developers can use it to build occupancy detectors, proximity sensors, and motion-triggered systems by reading parsed state and distance values from a UART connection.
