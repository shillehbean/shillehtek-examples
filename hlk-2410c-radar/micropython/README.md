# Micropython examples

- [`example.py`](./example.py) — Run on a MicroPython board (e.g. Raspberry Pi Pico) to read UART frames from the HLK-2410C, find footer-terminated frames, parse state and distance values, and print them over the console.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hlk-2410c-human-presence-radar-motion-detection-module-pre-soldered-manual)
