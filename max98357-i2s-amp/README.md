# MAX98357 Pre-Soldered I2S Class D Audio Amplifier Module

The MAX98357A is a mono I2S Class D digital audio amplifier that accepts I2S (digital) audio and drives a speaker directly from a 3.3–5V supply. Use this board to add simple speaker output to microcontrollers and single-board computers — example projects include test tones, alerts, and basic audio playback from I2S-capable devices.
