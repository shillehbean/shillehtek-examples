# 50kg Half-Bridge Load Cell Strain Sensor for Body Scale

This is a 50 kg half-bridge load cell (strain sensor) intended for building digital scales, body-weight platforms, and general force-sensing projects. Use it with an HX711 ADC amplifier to read weight values and integrate with microcontrollers or a Raspberry Pi.
