# 4-Channel 5V Relay

A 4-channel 5V relay board that provides four active-LOW inputs to switch external DC or AC loads. Developers can use it to build relay-controlled projects such as lamp switching, motor on/off control, or simple home-automation interfaces with microcontrollers or single-board computers.
