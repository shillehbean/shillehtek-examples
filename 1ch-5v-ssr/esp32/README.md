# Esp32 examples

- [`example.ino`](./example.ino) — ESP32 (Arduino core) sketch that reads serial input and turns the SSR on when it receives '1' (pulls GPIO26 LOW) and off when it receives '0' (sets GPIO26 HIGH).

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/solid-state-relay-1ch-5v-active-low-manual)
