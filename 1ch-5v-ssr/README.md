# 1-Channel 5V Solid State Relay Module (Low-Level Trigger) for Arduino, Raspberry Pi & ESP32

This is a 1-channel 5V low-level-trigger solid state relay (SSR) board for quiet switching of AC or DC loads from a microcontroller or SBC GPIO. Developers can use it to control lights, fans, or other loads from Arduino, Raspberry Pi, or ESP32 while avoiding mechanical relay noise and contact wear.
