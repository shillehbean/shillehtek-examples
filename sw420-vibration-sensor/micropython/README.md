# Micropython examples

- [`example_1.py`](./example_1.py) — Use MicroPython on an ESP32 to attach an IRQ to GPIO25, increment a pulse counter on both edges, and print a per-second vibration status message.
- [`example_2.py`](./example_2.py) — On a Raspberry Pi Pico running MicroPython, attach an IRQ on GP15 to count vibration pulses and print a per-second summary of vibration strength.
