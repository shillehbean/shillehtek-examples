# SW-420 Vibration Sensor Module for Arduino

The SW-420 is a simple vibration switch sensor that detects tapping, impact, and movement. Use it to add tamper detection, impact sensing, or basic activity monitoring to Arduino, ESP32, or Raspberry Pi projects; this repo provides small examples that count vibration pulses and report intensity.
