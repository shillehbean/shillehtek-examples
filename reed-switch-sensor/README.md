# Normally Open Reed Switch Magnetic Sensor for Arduino, Raspberry Pi & ESP32

A normally open reed switch magnetic sensor that closes its contact when a magnet is nearby. Use it as a simple magnetic door, lid, or limit sensor to detect open/closed state and build door/window contacts, limit switches for small robots, or presence detectors with Arduino, Raspberry Pi, or ESP32.
