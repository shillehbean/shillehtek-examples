# Micropython examples

- [`example_1.py`](./example_1.py) — MicroPython example for an ESP32 that reads a reed switch on GPIO25 with pull-up, debounces the input, and prints OPEN/CLOSED state changes to the REPL.
- [`example_2.py`](./example_2.py) — MicroPython example for RP2040 Pico that monitors a reed switch on GP15 with pull-up, performs debounce, and prints OPEN/CLOSED events to the console.
