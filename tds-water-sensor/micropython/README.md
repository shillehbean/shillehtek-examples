# Micropython examples

- [`example_1.py`](./example_1.py) — MicroPython example for ESP32 that reads the ADC (GPIO34) averaged in microvolts, applies temperature compensation, computes TDS ppm, and prints values repeatedly.
- [`example_2.py`](./example_2.py) — MicroPython example for the Raspberry Pi Pico that reads the built-in ADC, converts to voltage, computes temperature-compensated TDS ppm, and prints a simple water-quality classification.
