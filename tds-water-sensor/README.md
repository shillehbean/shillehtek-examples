# Analog TDS Water Quality Sensor Module for Arduino, Raspberry Pi & ESP32

This is an analog TDS (Total Dissolved Solids) water quality sensor module used to estimate dissolved solids in water by measuring conductivity. Developers can use it to build simple water-quality monitors and loggers with Arduino, ESP32 (MicroPython), or a Raspberry Pi (with an ADC) for continuous measurement and temperature compensation.
