# TM1637 4-Bit LED

The TM1637 4-digit LED is a small 4-character seven-segment display driven by the TM1637 LED driver chip. Developers can use it to build simple numeric displays such as clocks, counters, timers, or sensor readouts with Arduino, ESP32, Raspberry Pi, or MicroPython boards.
