# CJMCU-64 8x8 WS2812 RGB LED Matrix Module for Arduino, Raspberry Pi & ESP32

The CJMCU-64 is an 8x8 WS2812 addressable RGB LED matrix (64 LEDs total). Developers can drive it from Arduino, Raspberry Pi, or MicroPython-enabled boards (ESP32/ESP8266) to build animations, status displays, and visual indicators.
