# Arduino examples

- [`example_1.ino`](./example_1.ino) — Plays a moving diagonal rainbow across the 8x8 WS2812 matrix (supports serpentine wiring) using the Adafruit_NeoPixel Arduino library.
- [`example_2.ino`](./example_2.ino) — Creates a breathing single-color (blue) effect across all 64 LEDs using Adafruit_NeoPixel on Arduino.
