# 3DOF DIY Robot Arm Kit with 3x MG995 Servos

A 3DOF DIY robot arm kit with three MG995 servos providing base, shoulder, and elbow joints. Example code shows how to drive the servos with PWM from Arduino, ESP32, Raspberry Pi, and MicroPython to build simple motion routines and learn basic kinematics.
