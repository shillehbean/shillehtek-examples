# TPL5110 Pre-Soldered Low-Power Timer Module

The TPL5110 is a tiny low-power timer that sits between a battery and your project, switching the project on at a fixed interval and cutting power again when the project signals completion. Developers use it to build ultra-low-power periodic tasks such as sensor readers, loggers, or remote transmitters that wake, run a job, and then allow the timer to remove power.
