# PAM8406 Stereo Class-D Audio Amplifier Module for Arduino, Raspberry Pi & ESP32

The PAM8406 is a compact stereo Class-D audio amplifier designed to drive small speakers from microcontrollers and single-board computers. This repo contains short examples showing how to feed audio into the PAM8406 from Arduino, ESP32 (DAC), Raspberry Pi (ALSA), and Raspberry Pi Pico (MicroPython PWM) for projects like portable speakers, alerts, or simple media players.
