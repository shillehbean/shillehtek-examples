# HX-2S-JH20

The HX-2S-JH20 is a 2S (two-cell) lithium battery pack voltage monitor breakout that provides a ready-made resistor divider for reading pack voltage with a microcontroller ADC. Developers can use it to build simple battery fuel gauges, low-voltage cutoffs, or pack-voltage logging and telemetry.
