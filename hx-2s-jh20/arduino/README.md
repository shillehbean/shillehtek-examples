# Arduino examples

- [`example.ino`](./example.ino) — Reads a 2S Li-ion pack voltage on A0 using a 220k/100k divider, computes the pack voltage and a percent state-of-charge (6.0–8.4V range), and prints the values to Serial every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hx-2s-jh20-2s-7-4v-18650-lithium-battery-protection-board-10a-with-balancer-manual)
