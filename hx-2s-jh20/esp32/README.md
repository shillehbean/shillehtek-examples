# Esp32 examples

- [`example.ino`](./example.ino) — Measures a 2S pack voltage on ESP32 ADC pin 34 using a 330k/100k divider (divider ratio 4.3), converts the ADC reading to pack voltage, and prints it over Serial once per second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hx-2s-jh20-2s-7-4v-18650-lithium-battery-protection-board-10a-with-balancer-manual)  
Buy the module: https://shillehtek.com/products/18650
