# Raspberry Pi examples

- [`example.py`](./example.py) — Uses gpiozero to monitor the KY-037 DO pin on a Raspberry Pi (GPIO17) and prints a notification when the module's digital output goes LOW (sound detected), with basic debounce.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/ky-037-sound-sensor-module-with-analog)
