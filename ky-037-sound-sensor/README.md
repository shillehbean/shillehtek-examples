# KY-037 Sound Sensor Module with Analog

The KY-037 is a high-sensitivity microphone sound sensor with both analog and digital outputs for measuring ambient sound level and detecting threshold events. Developers can use it to build noise detectors, clap/knock triggers, or simple voice-activated projects with Arduino, ESP32, Raspberry Pi, or other microcontrollers.
