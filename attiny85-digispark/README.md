# ATtiny85 USB Development Board (Digispark) for Arduino

The ATtiny85 Digispark is a compact USB-enabled development board built around the ATtiny85 microcontroller. It is suitable for small embedded and USB-connected projects such as simple HID devices, LED controllers, or compact sensor nodes. This repository provides basic Arduino sketches, pinout guidance, and setup tips to get started.
