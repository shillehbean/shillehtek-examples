# Arduino examples

- [`example_1.ino`](./example_1.ino) — Blink the Digispark onboard LED on pin P1 (change to P0 if your board revision uses P0).
- [`example_2.ino`](./example_2.ino) — Fade an LED on PWM-capable P0 while a button on P2 is held, using the internal pull-up on P2.
