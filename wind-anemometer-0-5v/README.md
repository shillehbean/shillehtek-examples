# Wind Speed Sensor Anemometer with 0-5V Analog Output

A wind speed anemometer that outputs a proportional 0–5V analog signal (5V = 30 m/s). Use it to measure wind speed with microcontrollers or single-board computers and build weather stations, data loggers, or wind-aware automation.
