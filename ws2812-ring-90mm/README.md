# WS2812 24-Bit RGB LED Ring 90mm for Arduino, Raspberry Pi & ESP32

The WS2812 24-Bit RGB LED Ring (90mm) is a circular board with 24 individually addressable WS2812 LEDs. Developers can use it to build animated light effects, status indicators, or simple visual clocks with Arduino, Raspberry Pi, or ESP32 projects. The examples show wiring and sample animations to get you started.
