# Micropython examples

- [`example_1.py`](./example_1.py) — MicroPython script for ESP32 that controls the 24-LED ring with a global brightness cap and provides comet, rainbow, and clock-sweep animation functions.
- [`example_2.py`](./example_2.py) — MicroPython example for the Raspberry Pi Pico that implements spinner and breathe animations on the 24-LED ring connected to GP0 and runs them in a loop.
