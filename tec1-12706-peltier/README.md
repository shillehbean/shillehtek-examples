# TEC1-12706 Thermoelectric Peltier Cooler Plate 12V 40x40mm

The TEC1-12706 is a 12V, 40×40mm thermoelectric (Peltier) cooler used for small active cooling projects. Developers can use it to build temperature-controlled plates, mini chillers, or targeted component cooling when combined with a MOSFET, a heatsink/fan, and a temperature sensor or controller.
