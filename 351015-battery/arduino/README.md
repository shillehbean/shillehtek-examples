# Arduino examples

- [`example.ino`](./example.ino) — Reads a 1S LiPo voltage on an Arduino Uno/Nano using a 100k/100k divider, averages ADC samples, converts to cell voltage, estimates state-of-charge, prints to Serial and warns on low voltage.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/351015-500mah-3-7v-lithium-rechargeable-battery-3-5-x-10-x-15mm-manual)
