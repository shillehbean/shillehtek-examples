# Esp32 examples

- [`example.ino`](./example.ino) — Measures a 1S LiPo on ESP32 GPIO34 using analogReadMilliVolts with averaging and ADC attenuation, computes cell voltage and percent state-of-charge, prints to Serial and signals low battery.
