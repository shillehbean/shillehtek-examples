# IIC I2C Logic Level Converter PRE-SOLDERED Bi-Directional

The SHILLEHTEK IIC I2C Logic Level Converter is a pre-soldered, four-channel bi-directional board that shifts signals between 3.3V and 5V logic. Developers use it to connect mixed-voltage I2C, SPI, UART, or GPIO devices and build cross-voltage sensor interfaces, bus scanners, or simple level-shifted output controls.
