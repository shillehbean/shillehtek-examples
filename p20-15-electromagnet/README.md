# P20/15 12V DC Electromagnet Solenoid Sucker 3KG

The P20/15 is a 12V DC electromagnet (sucker) with roughly 3 kg holding force. Use it as a latch/lock or simple linear actuator; this repo shows wiring notes and small example sketches for Arduino and MicroPython boards (drive via a logic‑level MOSFET and a proper flyback diode).
