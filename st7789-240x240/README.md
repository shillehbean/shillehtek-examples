# 1.3" 240x240 IPS TFT LCD Display Module (ST7789, 7-Pin) for Arduino, ESP32 & STM32

This is a 1.3-inch 240x240 IPS TFT display panel driven by the ST7789 controller over SPI. The examples demonstrate basic initialization, text and image drawing, and simple animations for Arduino, ESP32/STM32 and Raspberry Pi so you can build small GUIs, status panels, or visual demos.
