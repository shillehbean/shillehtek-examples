# Raspberry Pi examples

- [`example.py`](./example.py) — Raspberry Pi Python example using RPi.GPIO to pulse the JSN-SR04T trigger, time the echo pulse to compute distance (using a median of readings), print distance or warnings, and clean up GPIO on exit.
