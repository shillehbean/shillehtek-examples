# JSN-SR04T Waterproof Ultrasonic Distance Sensor Module for Arduino, Raspberry Pi & ESP32

The JSN-SR04T is a waterproof ultrasonic distance sensor for non-contact distance, level, and presence sensing. These examples show how to read distance in centimeters and handle the sensor's blind zone on Arduino, ESP32/Pico (MicroPython), and Raspberry Pi.
