# PDSink PD Decoy

The PDSink PD Decoy is a small board used to monitor and emulate USB Power Delivery sink voltages on VBUS. Developers can use it to read the negotiated PD output voltage, log which PD profile is active, or implement a safety cutoff (for example, opening a relay if the voltage is out of expected range).
