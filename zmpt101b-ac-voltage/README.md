# ZMPT101B AC Single-Phase Voltage Sensor Module for Arduino, Raspberry Pi & ESP32

The ZMPT101B is a small isolated AC single-phase voltage sensor for measuring mains voltage via an analog output. These examples show how to sample the sensor and compute RMS mains voltage on Arduino, ESP32, Raspberry Pi (with an ADS1115), and MicroPython devices for monitoring, logging, or control projects.
