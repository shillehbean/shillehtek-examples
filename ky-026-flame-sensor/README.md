# KY-026 Flame Sensor Module for Arduino, Raspberry Pi & ESP32

The KY-026 is a simple flame detection sensor that provides both an analog IR intensity output and a digital comparator output. Developers can use it to build flame or fire-detection projects such as alarms, safety cutoffs, or monitoring rigs with Arduino, ESP32, Raspberry Pi, or MicroPython-capable boards.
