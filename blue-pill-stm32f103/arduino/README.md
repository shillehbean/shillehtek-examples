# Arduino examples

- [`example_1.ino`](./example_1.ino) — Toggle the onboard LED (PC13) every 500 ms while sending an incrementing counter over Serial1 (PA9 TX / PA10 RX).
- [`example_2.ino`](./example_2.ino) — Read a 0–3.3 V analog input on PA0 using the STM32's 12-bit ADC and print the raw value and calculated voltage over Serial1.
