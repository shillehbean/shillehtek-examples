# Blue Pill STM32F103

The Blue Pill is a small development board based on the STM32F103C8T6 microcontroller. Use it to build embedded projects such as LED blinkers, ADC-based sensors, serial-controlled devices, or to flash custom firmware via UART or ST-Link.
