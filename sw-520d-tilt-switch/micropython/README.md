# Micropython examples

- [`example_1.py`](./example_1.py) — ESP32 MicroPython script that reads the SW-520D on GPIO27 with debounce and prints the tilt state to the REPL.
- [`example_2.py`](./example_2.py) — MicroPython script for the Raspberry Pi Pico that reads the SW-520D on GP16 with debounce, mirrors the tilt state to the onboard LED, and prints status messages.
