# SW-520D Tilt Ball Switch Vibration Sensor for Arduino, Raspberry Pi & ESP32

The SW-520D is a simple tilt/vibration ball switch that opens or closes when the board is tilted or vibrated. These examples show how to read the switch with debouncing on Arduino, ESP32 (MicroPython), Raspberry Pi, and Raspberry Pi Pico so you can build tilt detection, shake sensors, or simple orientation triggers.
