# MQ-7 Carbon Monoxide (CO) Gas Sensor Module for Arduino, Raspberry Pi & ESP32

The MQ-7 is a carbon monoxide (CO) gas sensor module that provides an analog output and a digital threshold output for CO monitoring. Developers can use it to build CO detectors, alarm systems, data-logging experiments, or integrate it into Arduino, ESP32, Raspberry Pi, and MicroPython projects.
