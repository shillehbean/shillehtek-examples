# TF-Luna 8m LiDAR Distance Sensor

The TF-Luna is a single-point LiDAR distance sensor that measures 0.2–8 m with ~1 cm resolution and (by default) updates at 100 Hz. Developers can use it for simple distance measurements, obstacle detection, robot ranging, or altitude sensing by reading and decoding the 9-byte UART frames the sensor emits.
