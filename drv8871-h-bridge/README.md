# DRV8871 Pre-Soldered H-Bridge Brushed DC Motor Driver Module

The DRV8871 is a single H-bridge driver for one brushed DC motor that accepts motor supplies from 6.5 V to 45 V and includes current limiting and thermal protection. Developers can use this board to build motor control examples such as speed ramps, direction reversal, braking, and simple robotics or actuator projects.
