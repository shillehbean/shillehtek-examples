# NEO-M8N GPS Module with Antenna & Battery for Arduino, Raspberry Pi & ESP32

This is the u-blox NEO-M8N GPS receiver board with external antenna and backup battery. It outputs standard NMEA sentences over serial and provides position, altitude, speed, satellite count and time for microcontroller and SBC projects. Use it to add location and timing to Arduino, Raspberry Pi, or ESP32 builds.
