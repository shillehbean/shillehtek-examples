# PCM5102 Pre-Soldered I2S Stereo DAC Audio Module

The PCM5102 is a stereo I2S digital-to-analog converter that converts I2S digital audio into a line-level stereo signal on a 3.5 mm jack. Use it with microcontrollers or single-board computers to add clean analog audio output for test tones, music playback, or feeding an amplifier/active speakers.
