# TTGO T-Beam ESP32 LoRa 915MHz Development Board with NEO-6M GPS

The TTGO T-Beam is an ESP32-based development board that combines a 915 MHz LoRa radio, a NEO-6M GPS, and an AXP power management unit. Developers typically use it to build GPS-tracked LoRa nodes such as beacons, asset trackers, or remote telemetry devices.
