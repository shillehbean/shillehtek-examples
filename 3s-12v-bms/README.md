# 3S 12V BMS

The 3S 12V BMS is a small battery-management/voltage-monitoring board for three-series (3S) Li-ion/LiPo packs (nominal ~12V). These examples show how to read the pack voltage on Arduino, ESP32, and Raspberry Pi (via an ADS1115), so a developer can monitor pack voltage, estimate a simple state-of-charge, and integrate the BMS into battery-powered projects.
