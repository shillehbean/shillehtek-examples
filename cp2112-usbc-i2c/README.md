# CP2112 Pre-Soldered USB-C to I2C/SMBus Adapter Module

The CP2112 Pre-Soldered USB-C to I2C/SMBus Adapter converts a USB-C port into an I2C/SMBus master so a PC or Raspberry Pi can talk directly to sensors, displays, EEPROMs and other I2C devices without a microcontroller. Developers can use it to probe I2C buses, run desktop tools or scripts that communicate with peripherals, or integrate I2C peripherals into test rigs and automation systems.
