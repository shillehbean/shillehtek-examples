# ESP32-WROVER 4MB PSRAM WiFi & Bluetooth Module

ESP32-WROVER is an ESP32 module with 4 MB of PSRAM, integrated WiFi and Bluetooth, and the same dual-core CPU found on other ESP32 family parts. Developers use it where extra RAM matters — for example large HTTP downloads, frame buffers for cameras, or memory-heavy data processing and caching in Arduino or MicroPython projects.
