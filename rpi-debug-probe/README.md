# Raspberry Pi Debug Probe USB Debugging Kit

The Raspberry Pi Debug Probe is a small USB adapter that provides an SWD debug connection and a UART serial bridge for Arm microcontrollers such as the Raspberry Pi Pico. Developers use it to flash and step through firmware with OpenOCD/GDB and to read the target's serial console output.
