# Arduino examples

- [`example_1.ino`](./example_1.ino) — Steps to configure the Arduino IDE, install the ESP32 board package, select the AI Thinker ESP32-CAM board, load the CameraWebServer example, and upload it to verify camera and Wi‑Fi streaming.
- [`example_2.ino`](./example_2.ino) — A bench-test Arduino sketch that toggles the motor driver pins to spin the left and right wheel pairs forward and reverse so you can verify wheel direction and wiring.
