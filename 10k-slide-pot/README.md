# 10K Slide Potentiometer Module for Arduino & ESP32

A 10K linear slide potentiometer breakout that provides a single analog output for ADC-capable controllers. Use it to add a fader-style input to Arduino, ESP32, Raspberry Pi (with ADC/ADC expander) and other analog-input projects such as LED dimming, simple user controls, or MIDI-style position sensing.
