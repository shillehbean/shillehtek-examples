# ShillehTek Examples

Open-source code examples for ShillehTek pre-soldered IoT modules — Arduino, ESP32, Raspberry Pi — plus code from [IoT & Beyond](https://shillehtek.com/blogs/news) tutorials.
Every example links back to the full manual or tutorial, and to the parts on [shillehtek.com](https://shillehtek.com).

## Start here

Find your module below, or browse the [tutorial index](./tutorials/) for complete projects. Open its README for the matching manual, wiring instructions, libraries, and example files.

Examples are extracted from the linked articles. Check the article for your board's voltage, pinout, and required libraries before connecting hardware; snippets may need the surrounding setup from the tutorial.
