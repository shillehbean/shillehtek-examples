# Raspberry Pi examples

- [`example.py`](./example.py) — Python script for Raspberry Pi that opens the serial port at 256000 baud, locates 30-byte frames from the HLK-LD2450, decodes signed x/y/speed values and distance, and prints any detected targets.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hlk-ld2450-24ghz-mmwave-radar-human-body-tracking-sensor-module-manual)
