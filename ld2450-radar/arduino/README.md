# Arduino examples

- [`example.ino`](./example.ino) — Arduino Mega sketch that reads the HLK-LD2450 on Serial1 (pins 18/19) at 256000 baud, parses 30-byte frames, decodes three targets, and prints x/y, speed, and distance values to Serial.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hlk-ld2450-24ghz-mmwave-radar-human-body-tracking-sensor-module-manual)
