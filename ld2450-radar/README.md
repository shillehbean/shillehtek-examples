# HLK-LD2450

The HLK-LD2450 is a 24 GHz radar sensor that reports up to three tracked targets over a UART interface in a 30-byte frame. Developers can use it to read per-target x/y positions, radial speed, and distance for projects such as presence detection, people/object tracking, or robotic sensing.
