# Micropython examples

- [`example.py`](./example.py) — MicroPython example for Raspberry Pi Pico that reads the HLK-LD2450 over UART0 at 256000 baud, finds complete frames, decodes up to three targets, and prints their x/y, speed, and distance.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/hlk-ld2450-24ghz-mmwave-radar-human-body-tracking-sensor-module-manual)
