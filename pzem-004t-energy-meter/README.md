# PZEM-004T AC Energy Meter & Power Monitor Module with Current Transformer

The PZEM-004T is an AC energy meter and power monitor that communicates over a serial Modbus-RTU interface and includes a current transformer for measuring mains current. Developers can use it to build energy monitoring, data logging, or home-automation projects that record voltage, current, power, frequency, power factor and cumulative energy. This repo contains example sketches and scripts for Arduino, ESP32, Raspberry Pi (Python) and MicroPython.
