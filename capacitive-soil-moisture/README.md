# Soil Moisture Sensor V1.2

The Capacitive Soil Moisture Sensor V1.2 is an analog, capacitive moisture probe that outputs a voltage proportional to soil moisture (AOUT). Developers can use it with microcontrollers or a Raspberry Pi (with an ADC) to build soil moisture monitors, plant watering controllers, or garden telemetry projects.
