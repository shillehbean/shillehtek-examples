# Raspberry Pi examples

- [`example.py`](./example.py) — Uses an MCP3008 over SPI to read the sensor on CH0, clamps and scales the Adafruit library 0–65535 ADC value into a 0–100% moisture percentage, and prints raw, voltage, and percent values in a loop.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/capacitive-soil-moisture-sensor-v1-2-manual)
