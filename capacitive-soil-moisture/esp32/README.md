# Esp32 examples

- [`example.ino`](./example.ino) — Reads the sensor from an ESP32 ADC pin (GPIO34) with 12-bit resolution and 11dB attenuation, converts a calibrated raw ADC value into a moisture percentage, and logs the result over Serial.
