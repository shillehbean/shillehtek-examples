# Arduino examples

- [`example.ino`](./example.ino) — Arduino sketch that uses the Adafruit DHT library to read temperature and humidity from a DHT22 on digital pin 2 and print the values over Serial every ~2 seconds.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/dht22-digital-temperature-and-humidity-sensor-module-with-cable)
