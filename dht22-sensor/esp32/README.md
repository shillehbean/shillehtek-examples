# Esp32 examples

- [`example.ino`](./example.ino) — ESP32 Arduino sketch using the Adafruit DHT library to read temperature and humidity from a DHT22 on GPIO4 and print the results to Serial at 115200 baud every ~2 seconds.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/dht22-digital-temperature-and-humidity-sensor-module-with-cable)  
Buy the module: https://shillehtek.com/products/shillehtek-dht22-with-cables
