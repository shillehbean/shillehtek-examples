# Micropython examples

- [`example.py`](./example.py) — MicroPython example for boards like the Raspberry Pi Pico that uses the built-in dht module to measure temperature and humidity from a DHT22 on Pin 15 and print readings every 2 seconds.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/dht22-digital-temperature-and-humidity-sensor-module-with-cable)
