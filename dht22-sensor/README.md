# DHT22 Digital Temperature and Humidity Sensor Module with Cable

The DHT22 is a digital temperature and humidity sensor with a single-wire data interface. Developers can use it to build basic weather stations, HVAC monitors, or environmental data loggers with microcontrollers or single-board computers.
