# HMC5883L GY-273 3-Axis Magnetometer Compass Module for Arduino, Raspberry Pi & ESP32

The HMC5883L GY-273 is a 3-axis magnetometer (I2C) used for measuring magnetic field strength and calculating compass headings. Developers can use it to build digital compasses, orientation sensing for robots/drone projects, or magnetometer-based logging on Arduino, Raspberry Pi, or ESP32 platforms.
