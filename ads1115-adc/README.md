# ADS1115, 4 Channel, I2C, IIC, Analog-to-Digital, ADC, PGA, 16 Bit, 16 Byte Converter

The ADS1115 is a 4-channel, 16-bit I2C analog-to-digital converter with a built-in programmable gain amplifier (PGA) for high-resolution measurements. Developers can use it to add precise voltage or sensor readings to projects such as data loggers, battery monitors, or multi-channel sensor interfaces for Raspberry Pi, Arduino, or ESP32.
