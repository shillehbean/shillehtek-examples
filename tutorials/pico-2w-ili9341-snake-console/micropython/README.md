# Micropython examples

- [`snake_console.py`](./snake_console.py) — Initializes SPI and the ILI9341 display on a Pico 2W, defines screen dimensions and common colors, and provides a function to show an optional raw RGB565 logo image.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pico-2w-ili9341-snake-console)
