# Pico 2W + ILI9341: Handheld Snake Console

This tutorial shows how to build a handheld Snake console using a Raspberry Pi Pico 2W, an ILI9341 SPI TFT, a PS2-style analog joystick, and a piezo buzzer, all programmed in MicroPython. The code in this folder initializes the display and hardware, defines colors and layout constants, and includes the main game logic and helper functions used by the tutorial.
