# Micropython examples

- [`pico_w_mongodb_insert.py`](./pico_w_mongodb_insert.py) — Connects the Raspberry Pi Pico W to Wi‑Fi and sends an insertOne request to the MongoDB Atlas Data API with a JSON document payload.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-mongodb-insert-data-api)
