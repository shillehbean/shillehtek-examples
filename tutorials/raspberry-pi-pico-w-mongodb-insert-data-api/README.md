# Raspberry Pi Pico W MongoDB: Insert Data via API

This tutorial shows how to use a Raspberry Pi Pico W to send sensor data to a MongoDB Atlas database using the Data API. The code connects the Pico W to Wi‑Fi and posts a JSON document to the Atlas insertOne endpoint.
