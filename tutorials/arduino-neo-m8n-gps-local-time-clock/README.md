# Arduino Uno NEO-M8N GPS: Local Time Clock Display

This tutorial builds an Arduino Uno–based GPS clock using a u-blox NEO‑M8N GPS module and a 1.3" ST7789 IPS TFT display. The provided sketch reads NMEA data from the GPS, applies a UTC offset for local time, and renders the time and date on the TFT.
