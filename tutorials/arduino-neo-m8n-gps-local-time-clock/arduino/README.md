# Arduino examples

- [`neo_m8n_gps_clock.ino`](./neo_m8n_gps_clock.ino) — Reads NMEA data from a NEO‑M8N GPS via SoftwareSerial, computes local time using a UTC offset, and displays the time and date on a 240×240 ST7789 TFT.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-neo-m8n-gps-local-time-clock)  
Parts used: [NEO-M8N GPS Module with Antenna & Battery](https://shillehtek.com/products/gps-module-neo-m8n-antenna-battery-arduino-esp32) · [1.3" 240x240 IPS TFT Display (ST7789)](https://shillehtek.com/products/tft-lcd-1-3-240x240-st7789-esp32-arduino) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
