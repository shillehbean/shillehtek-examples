# Esp32 examples

- [`esp32_oled_dht_clock.ino`](./esp32_oled_dht_clock.ino) — An ESP32 Arduino sketch that connects to Wi‑Fi, syncs local time via NTP (with timezone/DST), reads temperature and humidity from a DHT11, and updates an SSD1306 OLED with time/date and sensor readings.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-oled-dht-internet-clock)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [SSD1306 0.96" I2C OLED](https://shillehtek.com/products/0-96-i2c-white-oled-display-module-4-pin-ssd1306) · [DHT11 Temperature & Humidity Sensor](https://shillehtek.com/products/shillehtek-dht11-with-cables) · [NodeMCU with Built-in 0.96" OLED](https://shillehtek.com/products/nodemcu-esp8266-development-board-with-0-96-inch-oled-display-type-c-with-soldering-and-foam) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
