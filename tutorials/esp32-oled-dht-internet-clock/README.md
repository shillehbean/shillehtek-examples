# ESP32 OLED DHT: Build an Internet-Synced Clock

This tutorial shows how to build an ESP32-based internet-synced clock that displays the current time, date, and DHT11 temperature/humidity on a 0.96-inch SSD1306 I2C OLED. The code connects the ESP32 to Wi‑Fi, synchronizes time via NTP using a POSIX timezone string, reads the DHT sensor, and updates the OLED display.
