# Arduino examples

- [`can_dht11_sender.ino`](./can_dht11_sender.ino) — Reads DHT11 temperature and humidity and sends the values as an MCP2515 CAN frame every second.
- [`can_lcd_receiver.ino`](./can_lcd_receiver.ino) — Receives MCP2515 CAN frames and displays the transmitted temperature and humidity on a 16x2 I2C LCD.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-mcp2515-can-bus-dht11-lcd)  
Parts used: [MCP2515 Pre-Soldered CAN Bus Module with TJA1050 SPI Interface](https://shillehtek.com/products/mcp2515-can-bus-module-tja1050-receiver-spi) · [DHT11 Temperature & Humidity Sensor for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-dht11-with-cables) · [DHT22 Temperature & Humidity Sensor for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-dht22-with-cables) · [PCF8574 I2C Serial Interface Adapter Module for 1602 & 2004 LCD Displays](https://shillehtek.com/products/pcf8574-i2c-serial-interface-adapter-module-for-1602-2004-lcd) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p)
