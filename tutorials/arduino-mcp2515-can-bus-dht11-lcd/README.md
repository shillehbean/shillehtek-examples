# Arduino MCP2515 CAN Bus Module: DHT11 Data to LCD

This tutorial links two Arduinos over an MCP2515 CAN bus so one board reads DHT11 temperature and humidity and the other displays those values on a 16x2 I2C LCD. The code in this folder includes the sender sketch that reads the DHT11 and transmits CAN frames, and the receiver sketch that reads CAN frames and updates the LCD.
