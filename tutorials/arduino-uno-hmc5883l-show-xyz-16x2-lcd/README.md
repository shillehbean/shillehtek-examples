# Arduino UNO HMC5883L: Show X/Y/Z on 16x2 LCD

This tutorial builds an Arduino-based compass readout using an HMC5883L magnetometer and a 16x2 LCD. The code reads X/Y/Z magnetic field values from the HMC5883L over I2C and prints them to both the Serial monitor and the LCD.
