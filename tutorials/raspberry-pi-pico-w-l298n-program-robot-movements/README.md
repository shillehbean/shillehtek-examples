# Raspberry Pi Pico W L298N: Program robot movements

This tutorial shows how to control two DC motors using a Raspberry Pi Pico W and an L298N motor driver. The provided MicroPython script implements PWM speed control and helper functions to drive the motors forward, backward, left, right, and stop. Copy the script to the Pico W and run it to operate the motors as shown in the tutorial.
