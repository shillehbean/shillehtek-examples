# Arduino examples

- [`wcs1700_current_monitor.ino`](./wcs1700_current_monitor.ino) — Calibrates the WCS1700 zero offset, reads averaged analog samples from A0, converts the sensor voltage to current in amps, and prints values over Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-wcs1700-monitor-70a-current)  
Parts used: [WCS1700 70A Hall-Effect Current Sensor Module with Overcurrent Detection](https://shillehtek.com/products/wcs1700-70a-hall-current-sensor-module-overcurrent-detect) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [Micro SD TF Card Adapter Reader Module SPI Interface for Arduino](https://shillehtek.com/products/micro-sd-tf-card-adapter-reader-module-spi-interface-for-arduino) · [1-Channel 5V Relay Board for Arduino & Raspberry Pi](https://shillehtek.com/products/1-channel-5v-relay-module) · [ESP32 Dev Board 4MB CP2102 USB-C Pre-Soldered 38-Pin](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb)
