# Arduino WCS1700 Current Sensor: Monitor 70A Loads

This tutorial shows how to build a DC current monitor using the WCS1700 70A Hall-effect current sensor and an Arduino Nano. The code in this folder calibrates the sensor zero offset, reads averaged analog samples, converts voltage to amps, and prints live current values over serial.
