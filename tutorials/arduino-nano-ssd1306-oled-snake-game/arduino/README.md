# Arduino examples

- [`snake_oled.ino`](./snake_oled.ino) — Implements the Snake game: initializes the SSD1306 OLED, reads joystick input, manages snake movement, food placement, scoring, speed, and game over behavior with buzzer feedback.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ssd1306-oled-snake-game)  
Parts used: [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [SSD1306 0.96" I2C OLED](https://shillehtek.com/products/0-96-i2c-white-oled-display-module-4-pin-ssd1306) · [KY-006 Passive Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
