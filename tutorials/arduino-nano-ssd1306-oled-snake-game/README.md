# Arduino Nano SSD1306 OLED: Build Snake Game

This tutorial builds a Snake game on an Arduino Nano using a 0.96" SSD1306 I2C OLED, a joystick, and a passive buzzer. The code implements the game logic, rendering to the OLED, input reading, scoring, and speed progression.
