# Arduino examples

- [`millis_multitask.ino`](./millis_multitask.ino) — Non-blocking multitask example: blink LED_A at a fixed 1s rate, blink LED_B at a potentiometer-controlled rate (50–1000 ms), read a button that forces both LEDs on, and periodically report status over Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-millis-blink-leds-read-button)
