# Arduino Nano millis(): Blink two LEDs and read button

This example demonstrates using millis() for cooperative multitasking on an Arduino Nano. The sketch blinks two LEDs at different rates, reads a button with instant response, lets you tune one LED's speed with a potentiometer, and prints periodic status over Serial.
