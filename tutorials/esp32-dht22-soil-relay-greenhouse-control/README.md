# ESP32 DHT22: Automate Greenhouse Fan and Pump

This project builds an ESP32-based greenhouse controller that reads temperature, humidity, and soil moisture then automates a fan and water pump via relays. The code sample reads a DHT22 and an analog soil sensor, drives two relay outputs for pump and fan, prints values to the serial console, and attempts to join a Wi-Fi network.
