# Raspberry Pi Pico BMP280: Read temp and pressure

This tutorial shows how to connect a BMP280 temperature and pressure sensor to a Raspberry Pi Pico or Pico W and read measurements using MicroPython over I2C. The code in this folder demonstrates initializing the I2C bus, creating a BMP280 driver instance, and printing temperature and pressure readings in a loop.
