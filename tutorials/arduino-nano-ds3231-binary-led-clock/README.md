# Arduino Nano DS3231: Build a Binary LED Clock

This project builds a binary LED clock using an Arduino Nano and a DS3231 real-time clock module. The code reads the current time from the DS3231 and drives 12 LEDs to display hours and minutes in binary, with an additional LED blinking as a seconds heartbeat.
