# ESP32 HC-SR04: Telegram door alerts

This tutorial shows how to build a low-cost door alert using an ESP32, an HC-SR04 ultrasonic distance sensor, and Telegram notifications. The code in this folder connects the ESP32 to Wi‑Fi, measures distance, and sends Telegram messages when something is within about 1 meter for 3 seconds, with a 30 second cooldown.
