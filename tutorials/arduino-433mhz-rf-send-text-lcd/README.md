# Arduino 433MHz RF Modules: Send Text to LCD

This tutorial shows how to build a simple 433MHz RF link between two Arduinos to send text from the Serial Monitor and display it on a 16x2 LCD. The code folder contains the transmitter sketch (reads serial input and sends it over RF) and the receiver sketch (receives RF messages and prints them to the LCD), plus a small LCD pin declaration used in the examples.
