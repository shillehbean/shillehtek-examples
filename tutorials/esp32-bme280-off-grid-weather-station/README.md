# ESP32 BME280: Build an Off-Grid Weather Station

This tutorial shows how to build a solar-powered off-grid weather station using an ESP32 and a BME280 sensor. The code in this folder reads temperature, humidity and pressure from the BME280, posts the data to a cloud endpoint (ThingSpeak in the example), and uses deep sleep to minimize power consumption for reliable off-grid operation.
