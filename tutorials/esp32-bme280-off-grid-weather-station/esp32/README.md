# Esp32 examples

- [`esp32_bme280_thingspeak.ino`](./esp32_bme280_thingspeak.ino) — ESP32 Arduino sketch that reads temperature, humidity, and pressure from a BME280, sends the values to ThingSpeak via HTTP, then puts the ESP32 into deep sleep for a defined interval.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-bme280-off-grid-weather-station)
