# ESP32 Capacitive Soil Moisture: Smart Auto Watering

This tutorial shows how to build an ESP32-based capacitive soil moisture monitor that automatically waters a plant when the soil is dry, supports deep-sleep for battery operation, and can send alerts. The code in this folder reads a capacitive moisture sensor, maps the ADC reading to a percent moisture value, and drives a relay to run a pump when moisture falls below a threshold.
