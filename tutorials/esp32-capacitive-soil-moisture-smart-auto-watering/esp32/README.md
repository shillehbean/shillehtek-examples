# Esp32 examples

- [`esp32_soil_moisture_auto_watering.ino`](./esp32_soil_moisture_auto_watering.ino) — ESP32 Arduino sketch that reads a capacitive soil moisture sensor, converts the ADC value to a percentage, and activates a relay to run a pump when moisture is below a set threshold.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-capacitive-soil-moisture-smart-auto-watering)
