# Arduino Nano DS3231: Timed pill dispenser alerts

This tutorial builds an Arduino Nano-based timed pill dispenser using a DS3231 RTC, a micro servo to index a pill carousel, and a buzzer for audible alerts. The code in this folder contains the Arduino sketch that checks the RTC for scheduled dose times, moves the servo to the next slot, and sounds the buzzer as a reminder.
