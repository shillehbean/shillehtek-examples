# Arduino examples

- [`ds3231_pill_dispenser.ino`](./ds3231_pill_dispenser.ino) — Arduino sketch that uses a DS3231 RTC to trigger servo indexing and a buzzer at scheduled hours, with a button input for interactions.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ds3231-pill-dispenser-alerts)
