# Arduino vs ESP32 vs ESP8266 vs STM32: Speed results

This folder contains the benchmark sketch used in the ShillehTek "Arduino vs ESP32 vs ESP8266 vs STM32: Speed results" tutorial. The code measures how long a tight integer loop takes using micros() and prints the elapsed microseconds to Serial for comparing raw execution speed across boards.
