# Raspberry Pi Pico W AP Mode: Host a Web Server

This tutorial shows how to run a Raspberry Pi Pico W in Access Point (AP) mode and host a simple web server. The code creates a Wi‑Fi network from the Pico W, listens for HTTP connections, and serves a basic HTML page.
