# Arduino ILI9341 Touchscreen: Build a Touch UI

This tutorial shows how to build a simple touch user interface on an Arduino using a 2.8" ILI9341 SPI TFT with a resistive touch panel. The code examples draw on-screen buttons and demonstrate reading touch coordinates to detect taps and map them to UI controls. Use these sketches as a starting point for wiring the display and implementing simple menus and buttons.
