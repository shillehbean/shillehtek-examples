# Arduino 433 MHz RF: Decode and Replay Remote Codes

This tutorial shows how to decode 433 MHz RF remote-control signals with an Arduino using a receiver module and the RCSwitch library, then replay those codes with a transmitter module. The code folder contains two Arduino sketches: one to listen and print received codes over serial, and another to send stored codes to control remote sockets.
