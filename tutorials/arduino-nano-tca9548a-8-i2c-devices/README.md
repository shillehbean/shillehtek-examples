# Arduino Nano TCA9548A: Run 8 Identical I2C Devices

This tutorial shows how to connect an Arduino Nano to a TCA9548A I2C multiplexer so you can run up to eight identical I2C devices (for example SSD1306 OLEDs) without address collisions. The code in this folder demonstrates selecting mux channels, initializing an SSD1306 display on each channel, and updating each display with a channel label and uptime.
