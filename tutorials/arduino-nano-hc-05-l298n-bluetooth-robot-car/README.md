# Arduino Nano HC-05: Bluetooth Robot Car Control

This tutorial shows how to build an Arduino Nano robot car controlled from a phone using an HC-05 Bluetooth module and an L298N motor driver. The code in this folder reads single-character commands over serial/Bluetooth and drives two DC motors (forward, back, left, right, stop) using the L298N enable and input pins.
