# Arduino G1/2 Flow Sensor: Measure L/min and Liters

This tutorial shows how to build an Arduino water flow meter using a G1/2 hall-effect flow sensor (ZJ-S201) to measure flow rate in L/min and accumulate total liters. The included Arduino sketch counts sensor pulses via an interrupt, computes the flow rate and total volume, and prints the results to the serial console.
