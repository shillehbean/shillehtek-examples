# Esp32 examples

- [`esp8266_udp_smartplug.ino`](./esp8266_udp_smartplug.ino) — An Arduino-style ESP8266 sketch that connects to Wi-Fi, listens for UDP packets on port 4210, and toggles one of four SSR channels when it receives the characters '1'..'4'.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp8266-solid-state-relay-udp-smart-plug)  
Parts used: [4-Channel 5V Solid State Relay Module](https://shillehtek.com/products/4-channel-5v-ssr-module-arduino-esp32-raspberry) · [1-Channel SSR](https://shillehtek.com/products/solid-state-relay-1ch-5v-active-low) · [ESP8266 NodeMCU Dev Board (with OLED)](https://shillehtek.com/products/nodemcu-esp8266-development-board-with-0-96-inch-oled-display-type-c-with-soldering-and-foam) · [LM2596 Adjustable Step-Down Converter with Voltmeter](https://shillehtek.com/products/shillehtek-lm2596-dc-dc-adjustable-step-down-power-supply-module) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
