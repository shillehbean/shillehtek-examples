# ESP8266 Solid State Relay: Build a UDP Smart Plug

This project builds an ESP8266 (NodeMCU) based 4-channel solid state relay smart plug that toggles AC outlets silently over WiFi using simple UDP commands. The code in this folder implements a UDP listener that receives single-character commands to toggle each relay channel and drives the SSR module pins accordingly.
