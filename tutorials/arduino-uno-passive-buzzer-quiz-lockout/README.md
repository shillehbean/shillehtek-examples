# Arduino Uno Passive Buzzer: Four-Player Lockout Quiz

This project builds a four-player quiz buzzer lockout with an Arduino Uno, four player buttons and LEDs, a host reset button, and a passive buzzer. The Arduino sketch monitors the player buttons, locks out after the first press, lights the winning player's LED and plays a tone, and supports a host reset to re-arm the game.
