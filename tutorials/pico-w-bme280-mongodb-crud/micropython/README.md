# Micropython examples

- [`pico_w_bme280_mongodb.py`](./pico_w_bme280_mongodb.py) — MicroPython script for the Raspberry Pi Pico W that initializes I2C for a BME280 sensor, manages Wi‑Fi connectivity, and defines a findOne function to query a MongoDB Data API endpoint.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pico-w-bme280-mongodb-crud)
