# Raspberry Pi Pico W BME280: MongoDB Data API CRUD

This tutorial shows how to connect a Raspberry Pi Pico W to a BME280 sensor and use the MongoDB Data API to perform CRUD operations. The code in this folder contains MicroPython scripts that initialize I2C, connect the Pico W to Wi‑Fi, read the BME280, and call MongoDB Data API endpoints (example: findOne).
