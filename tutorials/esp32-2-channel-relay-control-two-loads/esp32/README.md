# Esp32 examples

- [`esp32_2ch_relay.ino`](./esp32_2ch_relay.ino) — Controls two relays connected to GPIO25 and GPIO26 (active-low), providing a safe startup state and cycling through several relay on/off combinations.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-2-channel-relay-control-two-loads)  
Parts used: [2-Channel 5V Relay Module for Arduino & Raspberry Pi](https://shillehtek.com/products/2-channel-5v-relay-module) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [ESP-WROOM-32 (ESP-32S) ESP32 Dev Board CP2102 USB-C Pre-Soldered](https://shillehtek.com/products/esp32-wroom-dev-board-cp2102-usb-c-presoldered)
