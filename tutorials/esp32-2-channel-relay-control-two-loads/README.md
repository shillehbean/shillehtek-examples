# ESP32 2-Channel Relay Module: Control Two Loads

This tutorial builds an ESP32-based 2-channel relay controller to switch two loads reliably using a 5V relay module. The code in this folder demonstrates how to control two relay inputs (active-low) from ESP32 GPIO pins and includes a safe startup state and a simple toggle sequence. Follow the tutorial for wiring notes like shared ground and stable 5V power recommendations.
