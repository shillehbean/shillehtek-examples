# Arduino Nano PIR Sensor: Animated Skull Control

This tutorial shows how to build a hands-free Halloween prop using an Arduino Nano, an HC-SR501 PIR motion sensor, a micro servo for a skull jaw, LED eyes, and a piezo buzzer. The code in this folder reads the PIR sensor and, when motion is detected, animates the servo jaw, flashes the LEDs, and sounds the buzzer.
