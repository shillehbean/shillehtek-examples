# ESP32 SX1262: Offline Mesh Messaging

This tutorial shows how to set up a private Meshtastic mesh network using ESP32 + SX1262 LoRa devices so you can send offline messages miles without Wi‑Fi. The code examples here are the CLI commands used to install the Meshtastic tools, configure a primary channel, point a second node at that channel, reboot nodes, and send/test messages.
