# Arduino examples

- [`max30102_oled.ino`](./max30102_oled.ino) — Arduino sketch that reads the MAX30105/MAX30102 sensor, detects beats to calculate BPM (and averaged BPM), and displays readings on an SSD1306 OLED (also prints to Serial).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-max30102-oled-heart-rate-spo2)
