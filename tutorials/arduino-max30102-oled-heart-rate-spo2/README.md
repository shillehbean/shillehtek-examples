# Arduino MAX30102: Heart Rate and SpO2 on OLED

This tutorial shows how to build a simple pulse oximeter using an Arduino Nano, a MAX30102 pulse oximeter sensor, and an SSD1306 I2C OLED. The provided Arduino sketch reads IR/RED data from the MAX30102, detects heart beats, computes BPM (and an averaged BPM), and displays the values on the OLED. Wiring notes and the primary Arduino sketch are included in this folder.
