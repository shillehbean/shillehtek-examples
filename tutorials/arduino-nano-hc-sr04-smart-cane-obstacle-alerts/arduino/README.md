# Arduino examples

- [`smart_cane_ultrasonic.ino`](./smart_cane_ultrasonic.ino) — Reads distance from an HC-SR04 ultrasonic sensor, averages readings, and drives a buzzer and vibration motor with three distance-based alert zones and a mute switch.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-hc-sr04-smart-cane-obstacle-alerts)  
Parts used: [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [JSN-SR04T Waterproof Ultrasonic](https://shillehtek.com/products/jsn-sr04t-waterproof-ultrasonic-distance-sensor-arduino-esp32) · [KY-006 Passive Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [TP4056 Li-ion Charger Board](https://shillehtek.com/products/18650-tp4056-1a-3-7-4-2v-lipo-battery-charging-board-micro-usb-with-current-protection) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
