# Arduino Nano HC-SR04: Smart Cane Obstacle Alerts

This tutorial shows how to build a smart cane using an Arduino Nano and an ultrasonic distance sensor to provide obstacle alerts via a vibration motor and a buzzer. The code reads the HC-SR04, averages multiple pings, classifies distance into three warning zones, and drives a buzzer and vibration motor with a mute switch for quiet mode.
