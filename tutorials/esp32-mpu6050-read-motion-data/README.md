# ESP32 MPU6050: Wire and read motion data

This tutorial shows how to wire an MPU6050 (GY-521) IMU to an ESP32 and read accelerometer and gyroscope data using the Arduino framework and Adafruit MPU6050 library. The code here initializes the sensor, configures ranges, and outputs motion data over the serial console for use in IoT or embedded projects.
