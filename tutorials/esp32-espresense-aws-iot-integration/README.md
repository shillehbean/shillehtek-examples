# ESP32 ESPresense: Send device data to AWS IoT

This folder contains shell commands and an example Mosquitto configuration used in the tutorial to run a local Mosquitto MQTT broker and bridge it to AWS IoT. The scripts show how to install, start, configure user authentication, edit and restart the Mosquitto service for macOS, Linux, and Windows. The mosquitto.conf example demonstrates how to forward espresense topics to an AWS IoT endpoint using a TLS bridge.
