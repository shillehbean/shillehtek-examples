# Bash examples

- [`install_mosquitto_mac.sh`](./install_mosquitto_mac.sh) — Install Mosquitto via Homebrew and start the service on macOS.
- [`install_mosquitto_ubuntu.sh`](./install_mosquitto_ubuntu.sh) — Update apt package lists, install Mosquitto and its clients on Debian/Ubuntu, enable and start the Mosquitto systemd service.
- [`mosquitto_add_user.sh`](./mosquitto_add_user.sh) — Create a Mosquitto password file and add a user account (examples for macOS, Linux, and Windows paths).
- [`edit_mosquitto_conf.sh`](./edit_mosquitto_conf.sh) — Open the Mosquitto configuration file in an editor (nano on macOS/Linux, note reference to Notepad on Windows).
- [`restart_mosquitto.sh`](./restart_mosquitto.sh) — Restart the Mosquitto service after configuration changes (commands for macOS, Linux, and Windows).
- [`stop_mosquitto.sh`](./stop_mosquitto.sh) — Stop or disable the Mosquitto service on macOS, Linux, and Windows.
