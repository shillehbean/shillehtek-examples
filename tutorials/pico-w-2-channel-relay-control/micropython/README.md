# Micropython examples

- [`pico_w_2ch_relay.py`](./pico_w_2ch_relay.py) — MicroPython script for Raspberry Pi Pico W that controls two relay outputs with active-low logic and cycles through several on/off combinations while ensuring a safe startup state.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pico-w-2-channel-relay-control)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
