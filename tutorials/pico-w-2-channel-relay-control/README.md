# Pico W 2-Channel Relay: Control two loads

This tutorial shows how to build a Raspberry Pi Pico W based 2-channel relay controller using MicroPython. The code in this folder runs on the Pico W, handles active-low relay modules, ensures a safe startup state, and cycles the two relays through several on/off combinations.
