# ESP8266 SW-420: Build a WiFi Fish Bite Alarm

This project builds a WiFi-enabled fish bite alarm using an ESP8266 board and an SW-420 vibration sensor. The firmware reads the vibration sensor, exposes simple HTTP endpoints to start/stop or query the alarm, and logs events over serial. Use the included sketch on an ESP8266-based board (D1 Mini / NodeMCU) to integrate with an Android app or HTTP poller.
