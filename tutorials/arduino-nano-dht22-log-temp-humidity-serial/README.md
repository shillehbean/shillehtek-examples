# Arduino Nano DHT22: Log Temp and Humidity to Serial

This tutorial shows how to build an Arduino Nano temperature and humidity logger using a DHT22 sensor. The example sketch reads the DHT22 every 2 seconds and prints stable temperature and humidity readings to the Serial monitor.
