# Arduino examples

- [`adxl345_bike_alarm.ino`](./adxl345_bike_alarm.ino) — Reads acceleration from an ADXL345, compares magnitude to a baseline, triggers a piezo buzzer and sends a Bluetooth alert when movement exceeds a threshold.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-adxl345-bike-theft-alarm-alerts)
