# Arduino ADXL345: Bike theft alarm alerts

This project builds a simple bike theft alarm using an ADXL345 accelerometer, an Arduino Nano, a piezo buzzer, and a Bluetooth module. The included Arduino sketch monitors acceleration, sounds a buzzer when movement exceeds a threshold, and sends an alert string over Bluetooth.
