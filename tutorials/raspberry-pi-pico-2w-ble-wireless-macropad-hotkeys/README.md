# Raspberry Pi Pico 2W BLE: Build a Wireless Macropad

This project builds a Raspberry Pi Pico 2W BLE macropad that sends six wireless hotkeys over BLE using CircuitPython. The code in this folder contains the wiring reference and the CircuitPython script that advertises as a BLE HID keyboard and maps six GPIO-connected switches to hotkey combinations.
