# Esp32 examples

- [`esp32_pir_telegram.ino`](./esp32_pir_telegram.ino) — Connects an ESP32 to Wi‑Fi, reads a PIR motion sensor input, and sends a Telegram message when motion is detected (with a one‑minute debounce).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-pir-telegram-mailbox-alerts)
