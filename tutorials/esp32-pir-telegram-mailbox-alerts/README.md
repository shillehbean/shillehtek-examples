# ESP32 HC-SR501 PIR: Telegram mailbox alerts

This project builds an ESP32-based mailbox notifier using an HC-SR501 PIR sensor to detect activity and send Telegram alerts so you don't make unnecessary trips. The code in this folder connects the ESP32 to Wi‑Fi and uses the UniversalTelegramBot library to push a message when the PIR sensor is triggered.
