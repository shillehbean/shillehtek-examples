# Arduino R307 Fingerprint Sensor: Enroll and Match IDs

This tutorial shows how to build an Arduino-based fingerprint enrollment and matching system using an R307 optical fingerprint sensor. The repository contains two Arduino sketches: one to enroll fingerprints into the sensor's template database and one to continuously scan and match fingerprints (with LED indicators). Wiring uses SoftwareSerial on pins D2 (RX) and D3 (TX) with the sensor powered by 5V.
