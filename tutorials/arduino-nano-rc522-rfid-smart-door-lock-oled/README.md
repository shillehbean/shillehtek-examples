# Arduino Nano RC522 RFID: Smart Door Lock with OLED

This tutorial builds an Arduino Nano-based smart door lock using an RC522 RFID reader, an SSD1306 OLED for status, and a servo as the latch. The code in this folder reads RFID tags, shows access status on the OLED, and moves the servo to unlock for authorized tags.
