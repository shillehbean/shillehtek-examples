# ESP32-S3-DevKitC-1 N16R8 PSRAM: Verify 16MB + 8MB

This tutorial shows how to set up the ESP32-S3-DevKitC-1 N16R8 in the Arduino IDE, enable OPI PSRAM, and verify a 16 MB flash plus 8 MB PSRAM configuration. The code examples include a small utility that prints CPU, flash and PSRAM information over Serial and a USB HID keyboard example to exercise the ESP32-S3 USB functionality.
