# AWS Lambda Docker: Install pip packages via ECR

This tutorial shows how to package Python pip dependencies into an AWS Lambda image using Docker and publish that image to Amazon ECR, then update a Lambda function to use the image. The files in this folder include the Dockerfile for building the Lambda image, a .dockerignore, and shell helper scripts for installing the AWS CLI, creating the ECR repo, logging in, building/tagging/pushing the image, and updating the Lambda function.
