# Raspberry Pi KY-037: Toggle an LED with sound

This tutorial shows how to connect a KY-037 sound sensor to a Raspberry Pi and use a simple Python script to toggle an LED when sound is detected. The provided code monitors the sensor's digital output and flips the LED state on each detected sound, with a short debounce delay.
