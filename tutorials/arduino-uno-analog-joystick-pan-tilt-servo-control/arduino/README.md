# Arduino examples

- [`pan_tilt_joystick.ino`](./pan_tilt_joystick.ino) — Reads an analog joystick (X, Y, and switch) and drives two servos for pan and tilt with a dead zone, proportional speed, and click-to-recenter.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-analog-joystick-pan-tilt-servo-control)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Pan-Tilt Servo Bracket Kit](https://shillehtek.com/products/pan-tilt-servo-bracket-kit-sg90-mg90s) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [Servo Tester](https://shillehtek.com/products/servo-tester-rc-ccpm-checker) · [MB102 Breadboard Power Supply](https://shillehtek.com/products/shillehtek-universal-power-supply-module) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
