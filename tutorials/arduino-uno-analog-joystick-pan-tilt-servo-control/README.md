# Arduino Uno Analog Joystick: Control a Pan-Tilt Servo Mount

This project builds an Arduino Uno–based pan‑tilt servo mount controlled by an analog joystick. The joystick provides proportional speed and a dead zone, and its push‑button recenters the servos. The code here reads the joystick and drives two servos to pan and tilt the bracket accordingly.
