# Arduino UNO Joystick Shield: USB Gamepad or nRF24 TX

This tutorial shows how to read every input from a Joystick Shield V1.A and use the board as either a USB HID gamepad or an nRF24L01 wireless transmitter. The code samples include a serial monitor demo, an axis normalization helper, a USB joystick (HID) sketch, and an nRF24L01 transmitter sketch for sending joystick state wirelessly.
