# ESP32 MQ-135: Air Quality Dashboard with OLED

This project builds an ESP32-based air quality dashboard using an MQ-135 gas sensor, a DHT22 temperature/humidity sensor, and an SSD1306 I2C OLED display. The code reads sensors, updates the OLED with live values, and serves a simple web page with the current readings over Wi‑Fi.
