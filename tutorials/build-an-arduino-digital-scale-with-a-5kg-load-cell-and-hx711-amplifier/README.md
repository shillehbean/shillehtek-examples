# Build an Arduino Digital Scale with a 5kg Load Cell and HX711 Amplifier

This tutorial shows how to build an Arduino digital scale using a 5kg bar load cell and an HX711 amplifier. The code examples include a calibration sketch to determine an appropriate calibration factor and a demo sketch that prints weight readings to the Serial monitor.
