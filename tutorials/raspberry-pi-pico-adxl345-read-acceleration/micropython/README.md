# Micropython examples

- [`adxl345_pico_read.py`](./adxl345_pico_read.py) — Initializes the ADXL345 over I2C on a Raspberry Pi Pico, reads raw 3-axis acceleration data, converts it to g units, and prints the values in a loop.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-adxl345-read-acceleration)
