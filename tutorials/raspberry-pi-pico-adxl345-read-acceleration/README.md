# Raspberry Pi Pico ADXL345: Read Acceleration in MicroPython

This tutorial shows how to connect an ADXL345 accelerometer to a Raspberry Pi Pico and read 3-axis acceleration using MicroPython. The code initializes the sensor over I2C, configures measurement mode and data format, and continuously prints raw and g-scaled acceleration values.
