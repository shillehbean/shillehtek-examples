# Arduino examples

- [`mfrc522_access_control.ino`](./mfrc522_access_control.ino) — Reads RFID card UIDs with an MFRC522 connected over SPI, prints the UID to Serial, and grants or denies access by comparing the UID to a hard-coded authorized value.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-mfrc522-rfid-access-control)  
Parts used: [RC522 RFID Reader Writer Module 13.56MHz SPI Kit for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/rc522-rfid-reader-writer-module-13-56mhz-spi-kit-for-arduino)
