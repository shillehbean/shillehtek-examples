# Arduino MFRC522 RFID: Build Access Control System

This tutorial shows how to build a simple Arduino-based access control system using an MFRC522 13.56 MHz RFID reader. The code in this folder reads RFID card UIDs via SPI, prints the UID to the serial console, and compares it to a hard-coded authorized UID to display "Authorized access" or "Access denied".
