# Arduino 49E Hall Effect Sensor: Read Analog and Digital

This tutorial shows how to build a simple Arduino reader for a 49E linear Hall effect sensor to monitor magnetic field strength and detect when a threshold is crossed. The included code reads the sensor's analog output and the module's digital threshold output and prints their values over the Serial console.
