# Arduino Nano PIR vs Radar: Choose the Right Motion Sensor

This tutorial compares PIR (HC-SR501) and microwave radar (RCWL-0516 / HLK-2410) motion sensors using an Arduino Nano test circuit. The included code reads a sensor's digital output, mirrors it to the onboard LED, and logs motion events over Serial so you can evaluate sensor behavior side-by-side.
