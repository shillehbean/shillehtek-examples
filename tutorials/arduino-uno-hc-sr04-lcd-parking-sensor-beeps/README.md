# Arduino Uno HC-SR04: LCD Parking Sensor with Beeps

This project implements a simple parking sensor using an Arduino Uno, a JSN-SR04T ultrasonic distance sensor, a 16x2 I2C LCD (PCF8574 backpack), and a passive buzzer. The code measures distance, filters out invalid readings, displays the distance on the LCD, and produces proximity beeps that become faster as you approach a set stop distance, with a solid tone when too close.
