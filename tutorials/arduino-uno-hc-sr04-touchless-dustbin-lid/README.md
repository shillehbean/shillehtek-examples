# Arduino Uno HC-SR04: Touchless Dustbin Lid Control

This tutorial shows how to build a touchless smart dustbin using an Arduino Uno, an HC-SR04 ultrasonic distance sensor, and a servo to operate the lid. The code in this folder reads distance, opens the lid when an object is detected within a set range, and keeps it open for a configurable hold time before closing smoothly.
