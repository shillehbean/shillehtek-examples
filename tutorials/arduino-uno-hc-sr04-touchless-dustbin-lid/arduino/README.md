# Arduino examples

- [`touchless_dustbin.ino`](./touchless_dustbin.ino) — Reads distance from an HC-SR04 and controls a servo to open the dustbin lid when an object is detected, keeping it open for a set hold time and moving the servo slowly to avoid slamming.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-hc-sr04-touchless-dustbin-lid)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [Servo Tester](https://shillehtek.com/products/servo-tester-rc-ccpm-checker) · [MB102 Breadboard Power Supply](https://shillehtek.com/products/shillehtek-universal-power-supply-module) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
