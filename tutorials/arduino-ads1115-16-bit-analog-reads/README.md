# Arduino ADS1115: 16-bit Precision Analog Reads

This tutorial shows how to build a 16-bit I2C analog reader using an ADS1115 connected to an Arduino Nano. The code in this folder reads all four ADS1115 channels and prints both raw ADC counts and converted voltages over the serial console for sensor or battery monitoring.
