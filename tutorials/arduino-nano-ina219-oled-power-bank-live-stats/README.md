# Arduino Nano + INA219 OLED: Power Bank Live Stats

This project builds an Arduino Nano-based power bank monitor using an INA219 current/power sensor and a 0.96" SSD1306 OLED. The code reads live voltage, current, and power from the INA219 and updates the OLED display every half second.
