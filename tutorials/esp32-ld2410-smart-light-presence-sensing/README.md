# ESP32 HLK-LD2410: Smart light with presence sensing

This tutorial shows how to build a smart light using an ESP32 and an HLK-LD2410 24GHz mmWave presence sensor so lights stay on while you sit still. The repository contains a wiring reference, a minimal Arduino/ESP32 sketch to drive a relay from the sensor output, and an ESPHome YAML example to integrate the LD2410 as a binary sensor.
