# Raspberry Pi Pico W MQ135: Read Live ADC Values

This example shows how to connect an MQ-135 air quality sensor to a Raspberry Pi Pico W and read raw ADC values using MicroPython. The code continuously reads the sensor on GP26 (ADC0) and prints the 16-bit ADC values to the serial console once per second.
