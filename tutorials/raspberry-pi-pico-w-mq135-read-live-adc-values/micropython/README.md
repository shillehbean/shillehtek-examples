# Micropython examples

- [`mq135_adc_live.py`](./mq135_adc_live.py) — Reads raw ADC values from an MQ-135 sensor connected to GP26 on a Raspberry Pi Pico W and prints them to the serial console once per second.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-mq135-read-live-adc-values)  
Parts used: [MQ-135 Air Quality Hazardous Gas Sensor Module for Arduino](https://shillehtek.com/products/mq-135-air-quality-hazardous-gas-sensor-module-for-arduino) · [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
