# Arduino Nano JSN-SR04T: OLED Distance Readout

This tutorial shows how to build a simple distance meter using an Arduino Nano, a JSN-SR04T waterproof ultrasonic sensor, and a 0.96" SSD1306 I2C OLED. The provided sketch measures distance with the ultrasonic sensor and prints the value to the serial console and the OLED display.
