# Raspberry Pi Pico 2 W + Arducam OV2640: Capture JPEGs locally

This example shows how to capture JPEG photos with a Raspberry Pi Pico 2 W and an Arducam OV2640 using CircuitPython. The included code initializes the camera, configures storage and USB CDC, and saves captured JPEG files into an /images directory on the Pico filesystem.
