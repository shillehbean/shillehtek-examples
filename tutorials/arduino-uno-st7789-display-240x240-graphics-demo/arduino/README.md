# Arduino examples

- [`st7789_240x240_demo.ino`](./st7789_240x240_demo.ino) — Arduino sketch that initializes a 240x240 ST7789 SPI display using Adafruit_GFX and Adafruit_ST7789, clears the screen, sets rotation, and prints a "Hello, world!" message.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-st7789-display-240x240-graphics-demo)  
Parts used: [1.3" 240x240 IPS TFT LCD Display (ST7789, 7-Pin)](https://shillehtek.com/products/tft-lcd-1-3-240x240-st7789-esp32-arduino) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard)
