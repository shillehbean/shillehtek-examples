# Arduino Uno ST7789 Display: Run 240x240 Graphics Demo

This tutorial shows how to wire a 1.3" 240x240 ST7789 IPS TFT to an Arduino Uno and run a basic graphics demo using the Adafruit GFX/ST7789 libraries. The code here initializes the display, sets rotation, clears the screen, and prints a simple "Hello, world!" as a starting point for custom UI screens.
