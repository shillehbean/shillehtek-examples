# Arduino Uno LDR: Build an Automatic Night Light

This tutorial builds an automatic night light using an LDR (light-dependent resistor) and an Arduino Uno. The code reads ambient light, prints readings to the serial monitor, and turns an LED or relay on/off using a calibrated threshold with hysteresis to prevent flicker.
