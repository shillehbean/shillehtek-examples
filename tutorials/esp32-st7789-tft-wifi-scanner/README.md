# ESP32 ST7789 TFT: Scan Nearby Wi-Fi Networks

This tutorial builds an ESP32-based Wi‑Fi scanner that displays nearby SSIDs, signal strength, channel, and security on a 1.3" 240×240 ST7789 TFT. The code performs periodic Wi‑Fi scans and renders results either as a bar chart of strongest networks or as a list view on the display.
