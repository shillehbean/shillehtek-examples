# Arduino examples

- [`blink_pa0.ino`](./blink_pa0.ino) — Blinks an LED connected to pin PA0 with a 500 ms on/off period.
- [`float_benchmark.ino`](./float_benchmark.ino) — Runs a 1,000,000-iteration floating-point multiply/add loop, measures the elapsed microseconds, and prints the timing to Serial every second.
