# STM32H723ZGT6 STM32duino: Install and benchmark

This tutorial shows how to set up the STM32H723ZGT6 with the STM32duino core in the Arduino IDE, run a basic LED blink test, and measure CPU performance with a floating-point benchmark. The code in this folder provides a simple blink example for PA0 and a microsecond-timed floating-point loop benchmark that prints results over Serial.
