# Arduino MQ-135: Print Indoor Air Quality Readings

This tutorial shows how to build a simple indoor air-quality monitor using an MQ-135 gas sensor, a DHT22, an Arduino Nano, and a relay for control. The code in this folder reads the MQ-135 analog output and prints raw and voltage readings to the Serial console for logging and inspection.
