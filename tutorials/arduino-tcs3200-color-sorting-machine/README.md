# Arduino TCS3200: Build a Color-Sorting Machine

This project builds an Arduino Nano-based color-sorting machine using a TCS3200 color sensor and a servo to route items into bins. The code in this folder reads color frequencies from the TCS3200 and positions a servo to direct detected colors to different bins.
