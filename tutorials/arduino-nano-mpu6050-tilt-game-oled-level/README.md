# Arduino Nano MPU6050: Tilt Game and OLED Level

This tutorial builds an Arduino Nano project that uses an MPU6050 IMU and an SSD1306 OLED to create a tilt-controlled game and a digital bubble level. The code reads accelerometer and gyro data, fuses them with a complementary filter for stable pitch/roll, draws the game and level on the OLED, and handles button and buzzer feedback.
