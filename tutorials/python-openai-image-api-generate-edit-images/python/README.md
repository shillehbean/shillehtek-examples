# Python examples

- [`image_generate.py`](./image_generate.py) — Generate an image from a text prompt using OpenAI's Image.create and print the resulting image URL.
- [`image_edit_mask.py`](./image_edit_mask.py) — Edit an existing image using a mask and a prompt via OpenAI's Image.create_edit, uploading local image and mask files and printing the resulting image URL.
- [`image_variation.py`](./image_variation.py) — Create a variation of an existing image using OpenAI's Image.create_variation and print the resulting image URL.
