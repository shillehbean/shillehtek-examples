# Micropython examples

- [`pico_chatgpt.py`](./pico_chatgpt.py) — Connects the Raspberry Pi Pico W to a WiFi network and calls the OpenAI ChatGPT API to send a prompt and print the response.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-chatgpt-api-prompts)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
