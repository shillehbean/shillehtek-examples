# How to Use the KY-006 Passive Buzzer Module with Arduino

This tutorial shows how to connect a KY-006 passive piezo buzzer to an Arduino Uno and play simple tones by manually toggling a GPIO pin. The code in this folder toggles pin 8 with different on/off timings to produce two distinct beeps.
