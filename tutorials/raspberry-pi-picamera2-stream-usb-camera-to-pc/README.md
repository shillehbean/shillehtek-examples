# Raspberry Pi Picamera2: Stream USB Camera to PC

This tutorial shows how to stream video from a USB camera attached to a Raspberry Pi using Picamera2 and Flask. The code in this folder runs a small Flask app that captures frames from the Picamera2 API, encodes them as JPEG, and serves an MJPEG stream at /video_feed.
