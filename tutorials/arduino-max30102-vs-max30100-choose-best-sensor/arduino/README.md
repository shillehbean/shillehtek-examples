# Arduino examples

- [`max30100_vs_max30102_examples.ino`](./max30100_vs_max30102_examples.ino) — Two minimal Arduino sketches: one using the MAX30100_PulseOximeter library to initialize the MAX30100 and print heart rate / beat events, and one using the MAX30105 library to initialize the MAX30102, read IR values, and detect beats.
