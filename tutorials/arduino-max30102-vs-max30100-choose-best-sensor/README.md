# Arduino MAX30102 vs MAX30100: Choose the best sensor

This tutorial compares the Arduino usage of the MAX30102 and MAX30100 pulse oximeter modules and explains the hardware differences and library behavior. The code in this folder includes the wiring/pin mapping for an Arduino Nano and two minimal example sketches: one showing a MAX30100 pulse oximeter usage and one showing a MAX30102 usage with beat detection and heart rate output.
