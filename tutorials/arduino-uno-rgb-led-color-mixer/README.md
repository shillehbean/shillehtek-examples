# Arduino Uno RGB LED: Mix Colors with Three Knobs

This project builds an Arduino Uno RGB LED color mixer using three potentiometers to control the red, green, and blue channels and a button to toggle the LED on/off. The code reads the analog values, maps them to PWM outputs for the LED, and prints the live RGB values to the Serial monitor so you can copy them into design tools.
