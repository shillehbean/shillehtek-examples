# Arduino 4-Channel Relay Module: Reverse a DC Motor

This tutorial shows how to build a high-current DC motor reverser using a 4-channel relay module and an Arduino. The code in this folder provides the relay-control sketch that implements forward, reverse, brake and coast states with dead-time, plus a small example for adding limit-switch safety interlocks.
