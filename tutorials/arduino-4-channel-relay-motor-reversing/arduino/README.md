# Arduino examples

- [`relay_reverser.ino`](./relay_reverser.ino) — Arduino sketch that drives four active-LOW relay outputs to control motor direction (forward, reverse), implement a brake state, and demonstrate a timed forward/reverse cycle with dead-time between switching.
- [`limit_switch_interlock.ino`](./limit_switch_interlock.ino) — Arduino snippet that configures two limit switches using INPUT_PULLUP and triggers brake() when either limit is reached as a safety interlock.
