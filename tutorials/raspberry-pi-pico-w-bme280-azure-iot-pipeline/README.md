# Raspberry Pi Pico W BME280: Stream data to Azure IoT

This tutorial shows how to build a real-time Azure IoT pipeline using a Raspberry Pi Pico W and a BME280 sensor. The included code connects the Pico W to Wi‑Fi, reads temperature/humidity/pressure from the BME280, and sends the measurements to Azure IoT Hub. The folder also contains Azure CLI and Kusto/ADX queries for creating the ingestion table and mapping, and for querying and visualizing the ingested data.
