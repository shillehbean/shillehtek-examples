# Arduino MAX7219 Dot Matrix: Scrolling LED Marquee

This tutorial shows how to build a scrolling LED marquee using MAX7219 8x8 dot-matrix modules controlled from an Arduino. The included code examples demonstrate a simple static display on a single matrix and a scrolling message across a 4-module (32×8) display using the MD_Parola/MD_MAX72xx libraries.
