# Arduino Nano HC-SR04 vs VL53L0X: Pick right sensor

This tutorial compares two distance sensors (HC-SR04 ultrasonic and VL53L0X ToF) connected to an Arduino Nano and shows simple example sketches to read their distances over Serial. The code examples here provide minimal sketches: one to trigger and read the HC-SR04, and one to initialize and read the VL53L0X using the common Pololu/Adafruit-style library.
