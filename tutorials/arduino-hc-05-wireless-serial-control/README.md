# Arduino HC-05 Bluetooth Module: Wireless Serial Control

This tutorial shows how to add a Bluetooth Classic (HC-05) serial link to an Arduino and use it to remotely control the board from a phone. The code examples include a simple serial passthrough and a small command parser to turn the onboard LED on/off and query its status.
