# Arduino examples

- [`serial_bridge.ino`](./serial_bridge.ino) — Create a bidirectional serial bridge between the Arduino's USB Serial and an HC-05 connected via SoftwareSerial (pins 2 RX, 3 TX) at 9600 baud.
- [`bt_led_control.ino`](./bt_led_control.ino) — Read newline-terminated text commands from the HC-05 and control the onboard LED (pin 13) with commands: "on", "off", and "status".

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-hc-05-wireless-serial-control)  
Parts used: [HC-05 6-Pin Bluetooth Module, No Button](https://shillehtek.com/products/hc-05-6pin-bluetooth-module-no-button) · [820PCS 1/4W 1% Metal Film Resistors Kit, 41 Values, 20pcs Each (Plastic Box)](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box)
