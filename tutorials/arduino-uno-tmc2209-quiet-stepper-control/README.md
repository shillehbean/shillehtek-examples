# Arduino UNO TMC2209: Quiet NEMA 17 Step Control

This tutorial shows how to wire a TMC2209 stepper driver to an Arduino UNO and quietly drive a NEMA 17 stepper using simple STEP/DIR/EN control. The code provided here is a minimal Arduino sketch that pulses the STEP pin, toggles direction, and enables the driver for forward and reverse sweeps.
