# Arduino Nano VL53L1X: Build a Servo Radar Scanner

This project builds an Arduino Nano-based radar scanner using a VL53L1X time-of-flight sensor mounted on a servo-driven pan bracket. The code sweeps the sensor across a 60° arc, streams angle and distance readings over serial, and triggers a buzzer when an object is closer than a configured threshold.
