# Arduino examples

- [`vl53l1x_servo_radar.ino`](./vl53l1x_servo_radar.ino) — Sweeps a servo across a 60° arc while reading distances from a VL53L1X sensor, outputs comma-separated angle,distance over serial, and activates a buzzer when distance is below a threshold.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-vl53l1x-servo-radar-scanner)  
Parts used: [VL53L1X Pre-Soldered Time-of-Flight Laser Distance Sensor (400cm)](https://shillehtek.com/products/vl53l1x-tof-sensor-4m-pre-soldered-esp32) · [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [Pan-Tilt Servo Bracket Kit](https://shillehtek.com/products/pan-tilt-servo-bracket-kit-sg90-mg90s) · [8x8 WS2812 RGB LED Matrix](https://shillehtek.com/products/ws2812-8x8-led-matrix-arduino-esp32-raspberry-pi) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
