# Raspberry Pi Pico W HC-SR04: Obstacle Detection LEDs

This tutorial shows how to build an obstacle detection demo using a Raspberry Pi Pico W, an HC-SR04 ultrasonic distance sensor, and a strip of Neopixel LEDs. The code measures distance with the HC-SR04 and updates LED colors based on proximity, plus it includes a function to light random colors on the LEDs.
