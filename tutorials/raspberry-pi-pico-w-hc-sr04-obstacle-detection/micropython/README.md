# Micropython examples

- [`pico_hcsr04_neopixel.py`](./pico_hcsr04_neopixel.py) — MicroPython script for a Raspberry Pi Pico W that measures distance with an HC-SR04 and updates Neopixel LEDs to indicate proximity and display random color patterns.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-hc-sr04-obstacle-detection)
