# Arduino examples

- [`ina219_mains_monitor.ino`](./ina219_mains_monitor.ino) — Reads mains presence on an analog pin, measures battery voltage and current via an INA219, prints values over serial, and toggles a GPIO to signal the Raspberry Pi to shut down when battery voltage is low.
