# Raspberry Pi TP4056 INA219: Build a Mini UPS Backup

This tutorial shows how to build a small Raspberry Pi UPS using a TP4056 charger, INA219 current/voltage sensor, boost converter, and 18650 cells. The code in this folder monitors mains presence, battery voltage and load current, prints readings over serial, and signals the Pi to shut down on low battery.
