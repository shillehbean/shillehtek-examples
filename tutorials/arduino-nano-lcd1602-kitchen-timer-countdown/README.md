# Arduino Nano LCD1602: Kitchen Timer Countdown Build

This tutorial builds a kitchen countdown timer using an Arduino Nano, an I2C LCD1602 display with a PCF8574 backpack, a potentiometer to set the time, Start/Reset buttons, and a passive buzzer. The provided code implements a simple state machine (SETTING, RUNNING, ALARM) that updates the LCD, reads inputs, counts down seconds, and drives the buzzer when time elapses.
