# Arduino Nano DRV8825: Smooth NEMA 17 Motor Control

This example folder shows how to wire an Arduino Nano to a DRV8825 stepper driver and run a NEMA 17 stepper with correct microstepping and current-limited control. The code includes a minimal stepping sketch and a smoother motion example using the AccelStepper library; non-code blocks contain the wiring pinout and the microstepping truth table.
