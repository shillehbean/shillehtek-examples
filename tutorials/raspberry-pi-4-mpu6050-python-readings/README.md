# Raspberry Pi 4 MPU6050: Read Motion Data in Python

This tutorial shows how to connect an MPU6050 IMU to a Raspberry Pi (including Pi 4), enable I2C, and read accelerometer and gyroscope data using Python. The code in this folder provides the setup steps and examples to install required system and Python packages and to read sensor data with the mpu6050-raspberrypi library.
