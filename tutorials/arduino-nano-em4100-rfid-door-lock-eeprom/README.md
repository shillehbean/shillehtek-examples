# Arduino Nano EM4100 RFID: EEPROM multi-card door lock

This tutorial builds an Arduino Nano-based 125 kHz EM4100/RDM6300 RFID door lock with multi-card access stored in EEPROM and a relay-driven electric strike. The code examples include a serial RFID reader snippet, an EEPROM authorization helper, and the door lock control loop that operates the relay and status LEDs.
