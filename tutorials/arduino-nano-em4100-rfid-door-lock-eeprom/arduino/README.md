# Arduino examples

- [`rdm6300_reader.ino`](./rdm6300_reader.ino) — Reads RDM6300 125 kHz RFID serial packets over SoftwareSerial and prints the 10-character card ID to the Serial monitor.
- [`eeprom_authorize.ino`](./eeprom_authorize.ino) — Checks a 10-character card ID against up to MAX_CARDS stored entries in the AVR EEPROM and returns whether it's authorized.
- [`door_lock_control.ino`](./door_lock_control.ino) — Main loop that reads RFID tags, uses the EEPROM authorization helper, and drives the lock relay and OK/FAIL LEDs to unlock/relock or indicate denial.
