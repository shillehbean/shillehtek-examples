# Raspberry Pi MPU6050: Smooth Sensor Data in MicroPython

This tutorial demonstrates reading accelerometer data from an MPU6050 and applying an exponential low-pass filter in MicroPython to produce smoother sensor values. The code example connects to the MPU6050 over I2C and prints raw and filtered X-axis acceleration at 10 Hz.
