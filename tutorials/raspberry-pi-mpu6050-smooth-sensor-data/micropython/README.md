# Micropython examples

- [`mpu6050_lowpass.py`](./mpu6050_lowpass.py) — Connects to an MPU6050 over I2C, reads the accelerometer X axis, applies an exponential low-pass filter, and prints the raw and filtered values at 10 Hz.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-mpu6050-smooth-sensor-data)
