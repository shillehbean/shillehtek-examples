# Arduino NRF24L01: Build Wireless Communication Link

This tutorial demonstrates how to build a wireless communication link between Arduino-compatible boards using NRF24L01+ modules over SPI. The code examples include a simple transmitter, a simple receiver, and a small snippet showing how to set up matching RX/TX pipe addresses for two nodes.
