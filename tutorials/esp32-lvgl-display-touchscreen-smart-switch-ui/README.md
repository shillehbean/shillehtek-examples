# ESP32 LVGL Display: Touchscreen Smart Switch UI

This tutorial builds an ESP32-based touchscreen smart switch UI using LVGL on a 2.8" 240x320 TFT with resistive touch, controlling one or more 5V relays and optionally reporting temperature/humidity via DHT22 and MQTT to Home Assistant. The code examples in this folder show how to initialize LVGL with the TFT_eSPI driver and implement a simple LVGL button that toggles a GPIO relay and updates its label.
