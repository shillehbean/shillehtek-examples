# Esp32 examples

- [`esp32_lvgl_display.ino`](./esp32_lvgl_display.ino) — Initializes LVGL with TFT_eSPI, implements the display flush callback, registers the LVGL display driver, and creates a centered button labeled "Hello LVGL!".
- [`lvgl_relay_control.ino`](./lvgl_relay_control.ino) — Implements a relay toggle callback for an LVGL button that flips a relay on GPIO32 and updates the button label between "Light ON" and "Light OFF".
