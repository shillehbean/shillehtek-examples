# Raspberry Pi USB Microphone: Stream Audio with Icecast

This tutorial shows how to stream live audio from a USB microphone connected to a Raspberry Pi to an Icecast server. The code examples here include the command used to install Icecast and a sample DarkIce configuration file that captures audio from the Pi and pushes it to Icecast. Edit the configuration values (device, server, port, password, mountPoint) to match your setup before running.
