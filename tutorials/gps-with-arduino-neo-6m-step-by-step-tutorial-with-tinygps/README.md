# GPS With Arduino: NEO-6M Step-by-Step Tutorial With TinyGPS++

This tutorial demonstrates wiring a GT-U7 NEO-6M GPS module to an Arduino and using the TinyGPS++ library to parse NMEA sentences and stream latitude/longitude to the Serial monitor. The folder contains small code snippets showing the includes, object setup, setup() initialization, the read/parse loop and a complete ready-to-upload Arduino sketch.
