# Arduino HX711 Load Cell: Build a Calibrated Digital Scale

This tutorial shows how to build a calibrated digital scale using an HX711 load cell amplifier and an Arduino Nano. The code here reads weight from the HX711, tares on startup, and prints calibrated gram readings over Serial so you can tune the calibration factor with a known weight.
