# ESP32 + LCD1602: Blink Hello World with Logic Level Shifter

This tutorial shows how to wire an ESP32 development board to a 16x2 LCD1602 display using a bi-directional 3.3V↔5V logic level shifter and the LiquidCrystal library. The example code below flashes a "Hello, World!" message on the LCD, turning the message on and off at a one-second interval. Use the wiring and code to verify the display and level shifting are working with your ESP32.
