# Esp32 examples

- [`esp32_bme280_st7735.ino`](./esp32_bme280_st7735.ino) — ESP32 Arduino sketch that reads BME280 sensor data, fetches outdoor temperature from OpenWeatherMap, and drives an ST7735 display to show weather information.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-bme280-st7735-wifi-weather-station)
