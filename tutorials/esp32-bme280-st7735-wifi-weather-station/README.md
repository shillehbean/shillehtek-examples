# ESP32 BME280 + ST7735: Wi-Fi Weather Station Display

This project builds an ESP32-based Wi‑Fi weather station that reads indoor temperature, humidity and pressure from a BME280 sensor and displays them alongside outdoor data fetched from OpenWeatherMap on a ST7735 TFT. The code in this folder contains the ESP32 Arduino sketch that handles sensor reads, Wi‑Fi and HTTP requests, and updates the display.
