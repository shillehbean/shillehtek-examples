# ESP32 HX711: Beehive Weight and Climate Dashboard

This tutorial shows how to build an ESP32-based beehive monitor that measures hive weight (HX711 + load cell) and climate (DS18B20 and DHT22) and reports readings for remote dashboarding. The code in this folder reads the sensors, prints values to Serial, and includes a placeholder for pushing data to a server or ThingSpeak.
