# Arduino examples

- [`max30102_stream.ino`](./max30102_stream.ino) — Reads IR data from a MAX30102/MAX30105 sensor, detects beats, computes BPM and a rolling average, and prints IR/BPM/Avg to the Serial Monitor.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-max30102-stream-heart-rate-serial)
