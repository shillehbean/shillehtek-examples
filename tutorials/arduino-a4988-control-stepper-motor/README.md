# Arduino A4988 Stepper Driver: Control a Stepper Motor

This example demonstrates how to wire and control a ShillehTek A4988 stepper motor driver from an Arduino using the STEP and DIR pins. The sketch toggles the STEP pin to move the motor for a set number of steps and flips the DIR pin to reverse direction. It also shows simple speed control by adjusting the microsecond delay between steps.
