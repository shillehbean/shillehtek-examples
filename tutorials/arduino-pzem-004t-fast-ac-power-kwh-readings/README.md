# Arduino PZEM-004T: Fast AC Power and kWh Readings

This tutorial shows how to build an Arduino-based AC energy monitor using the PZEM-004T power meter module and an Arduino (Uno, Nano, or Uno R4). The provided sketch reads voltage, current and power quickly from the PZEM and streams the values over the serial console. The code in this folder is the Arduino sketch used to perform the readings and print them to Serial.
