# Arduino examples

- [`pzem_fast_readings.ino`](./pzem_fast_readings.ino) — Reads voltage, current and power from a PZEM-004T module using the PZEM004Tv40_R4 library and prints the values over the serial console.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-pzem-004t-fast-ac-power-kwh-readings)  
Parts used: [PZEM-004T AC Energy Meter & Power Monitor Module with Current Transformer](https://shillehtek.com/products/pzem-004t-ac-energy-meter-current-transformer) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
