# Seeeduino XIAO SAMD21 USB-HID: Build a Macro Numpad

This tutorial shows how to build a compact USB-HID macro numpad using a Seeeduino XIAO SAMD21 and a 4x4 membrane keypad. The included code examples demonstrate sending USB keyboard output from the XIAO: a minimal hello example, a 4x4 matrix-scanning numpad sketch, and a CircuitPython button example that sends Ctrl+C over USB.
