# Arduino Nano INA219: Measure Voltage, Current, Power

This tutorial shows how to build an Arduino Nano wattmeter using an INA219 I2C current/power sensor. The code in this folder reads shunt voltage, bus voltage, current and power from the INA219 and prints the measurements over Serial.
