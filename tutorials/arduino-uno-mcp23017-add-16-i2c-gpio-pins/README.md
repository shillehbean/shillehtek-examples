# Arduino Uno MCP23017: Add 16 I2C GPIO Pins

This tutorial shows how to add a 16-bit MCP23017 I2C GPIO expander to an Arduino Uno to gain 16 additional digital I/O pins. The example code demonstrates initializing the expander and running a simple LED chase on the second bank of 8 pins (GPB0–GPB7).
