# Arduino examples

- [`mcp23017_chase.ino`](./mcp23017_chase.ino) — Initializes an Adafruit MCP23017 I2C expander and runs a simple LED chase on pins 8–15 (GPB0–GPB7).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-mcp23017-add-16-i2c-gpio-pins)  
Parts used: [MCP23017 Pre-Soldered I2C 16-Bit I/O Port Expander](https://shillehtek.com/products/mcp23017-i2c-16bit-io-port-expander-presoldered) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [8-Channel USB Logic Analyzer](https://shillehtek.com/products/24mhz-8-channel-usb-logic-analyzer-digital-debugger-for-arduino) · [830-Point Breadboard](https://shillehtek.com/products/shillehtek-830-point-breadboard-for-arduino-raspberry-pi-esp32-and-other-microcontrollers) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
