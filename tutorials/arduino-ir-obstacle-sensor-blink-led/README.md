# Arduino IR Obstacle Sensor: Blink LED on Detect

This tutorial shows how to use a simple infrared (IR) obstacle avoidance sensor with an Arduino to blink the onboard LED and print detection messages over Serial. The code in this folder reads the sensor's digital output, lights the built-in LED when an obstacle is detected, and sends a short message to the serial monitor.
