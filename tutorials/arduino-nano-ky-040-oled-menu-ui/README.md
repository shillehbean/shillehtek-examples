# Arduino Nano KY-040 Rotary Encoder: OLED Menu UI

This tutorial shows how to build a simple menu UI on an Arduino Nano using a KY-040 rotary encoder and a 0.96" SSD1306 I2C OLED. The provided files include wiring information and an Arduino sketch that implements smooth scroll-and-click navigation and a basic menu on the OLED.
