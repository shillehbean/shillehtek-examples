# Arduino UNO MAX30102: Measure Heart Rate BPM

This tutorial shows how to build a heart rate monitor using an Arduino UNO and a MAX30102 pulse oximeter sensor. The code reads the IR photodiode signal, detects beats, and calculates current and averaged BPM values which are printed over the serial port.
