# Arduino Nano GSR Electrodes: OLED Reaction Meter

This tutorial builds a simple galvanic skin response (GSR) meter using an Arduino Nano, two skin electrodes, an SSD1306 I2C OLED for a needle-style display, and a piezo buzzer for alerts. The code reads the analog GSR sensor, computes a fast-following value and a slow baseline to detect reactions, shows the result on the OLED, and prints telemetry over serial.
