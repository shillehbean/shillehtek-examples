# Arduino MLX90614: Read Non-Contact Temperature Values

This tutorial builds a non-contact IR thermometer using the MLX90614 IR temperature sensor and an Arduino Nano. The included code reads ambient and object temperatures over I2C and prints the values to the serial console for monitoring.
