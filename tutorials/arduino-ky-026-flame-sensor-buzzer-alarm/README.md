# Arduino KY-026 Flame Sensor: Build a Buzzer Alarm

This tutorial builds a simple flame-detection alarm using an Arduino Nano, a KY-026 flame sensor, and a KY-006 passive piezo buzzer. The code in this folder reads the sensor's analog output and sounds the buzzer when a flame (or strong combustion light) is detected; a wiring note is provided for connecting the modules to the Arduino.
