# Arduino examples

- [`ky026_buzzer_alarm.ino`](./ky026_buzzer_alarm.ino) — Arduino sketch that reads the analog value from the KY-026 flame sensor on A0, prints the value to serial, and toggles a buzzer on digital pin 11 when a flame is detected (analog value < 500).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ky-026-flame-sensor-buzzer-alarm)  
Parts used: [KY-026 Flame Sensor Module for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/flame-sensor-ky-026-arduino-esp32-raspberry-pi) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [KY-006 Passive Piezo Buzzer Module for Arduino](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
