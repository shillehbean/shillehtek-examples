# ESP32 ArduinoOTA: Wireless sketch updates over Wi-Fi

This tutorial builds an OTA-capable ESP32 that receives wireless sketch updates over Wi‑Fi using the ArduinoOTA library. The code connects the board to your Wi‑Fi network, sets a hostname and OTA password, and reports upload progress over Serial while handling OTA updates. It also includes a placeholder for your application code (for example, a blinking LED) that demonstrates the OTA update took effect.
