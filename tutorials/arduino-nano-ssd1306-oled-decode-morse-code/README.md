# Arduino Nano SSD1306 OLED: Decode Morse Code Live

This project builds an Arduino Nano–based Morse code practice tool that decodes live key presses into text and shows progress on a 0.96" SSD1306 I2C OLED. The code reads a tactile button as a Morse key, plays a buzzer sidetone while pressing, decodes dots/dashes into letters and digits, and displays the decoded text and current symbol on the OLED.
