# Arduino Uno LM35: LCD Thermometer With C/F Toggle

This project builds an Arduino Uno thermometer using an LM35 analog temperature sensor, an I2C LCD1602 display, and a tactile pushbutton to toggle between Celsius and Fahrenheit. The included sketch reads and averages multiple ADC samples for a stable temperature, converts the reading to degrees, and shows it on the LCD while allowing unit toggling with the button.
