# Arduino examples

- [`ble_advertise.ino`](./ble_advertise.ino) — Starts the Adafruit Bluefruit BLE stack, sets the device name and TX power, and begins advertising indefinitely.
- [`bme280_env_ble.ino`](./bme280_env_ble.ino) — Reads temperature from a BME280 sensor over I2C and publishes it via BLE using the Environmental Sensing Service (UUID 181A) and the temperature characteristic (UUID 2A6E) as a 16-bit value in hundredths of degrees Celsius.
