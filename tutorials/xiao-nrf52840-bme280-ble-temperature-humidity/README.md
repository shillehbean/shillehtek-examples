# XIAO nRF52840 BME280: Build a BLE Temp Sensor

This tutorial shows how to build a battery-powered BLE temperature and humidity sensor using a Seeed XIAO nRF52840 and a BME280 sensor. The code here demonstrates basic BLE advertising and an Environmental Sensing Service that publishes temperature readings from the BME280 over BLE.
