# Arduino Nano HC-SR04 Theremin: Gesture Pitch Control

This tutorial shows how to build a simple ultrasonic theremin using an Arduino Nano, an HC-SR04 distance sensor, and a KY-006 passive piezo buzzer. The code in this folder measures hand distance with the HC-SR04 and maps that distance to a pitch played on the buzzer for gesture-controlled pitch.
