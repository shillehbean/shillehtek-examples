# Arduino examples

- [`nano_hcsr04_theremin.ino`](./nano_hcsr04_theremin.ino) — Reads distance from an HC-SR04 ultrasonic sensor and plays a mapped pitch on a piezo buzzer (theremin-style).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-hc-sr04-theremin-gesture-pitch)
