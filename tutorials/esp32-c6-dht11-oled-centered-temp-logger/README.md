# ESP32-C6 DHT11 + OLED: Centered Temp Logger Display

This tutorial shows how to build a simple temperature and humidity logger using an ESP32-C6 board, a DHT11 sensor, and an SSD1306 I2C OLED display. The included code reads DHT11 data, prints it to the serial console, and draws centered temperature and humidity lines on the OLED.
