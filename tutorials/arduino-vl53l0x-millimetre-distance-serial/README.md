# Arduino VL53L0X: Millimetre Distance Over Serial

This tutorial builds an Arduino Nano-based distance reader using the VL53L0X Time-of-Flight (ToF) sensor. The code here reads millimetre-precision distance measurements from the sensor and streams them over the serial connection.
