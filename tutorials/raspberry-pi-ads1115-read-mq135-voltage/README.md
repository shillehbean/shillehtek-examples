# Raspberry Pi ADS1115: Read MQ-135 Analog Voltage

This tutorial shows how to wire an MQ-135 air-quality sensor to an ADS1115 ADC and read precise analog voltages from a Raspberry Pi. The included code installs the required Python library and runs a small script that reads the ADS1115 channel connected to the MQ-135 and prints the measured voltage.
