# Esp32 examples

- [`esp32_st7789_weather.ino`](./esp32_st7789_weather.ino) — ESP32 Arduino sketch that connects to Wi‑Fi, fetches current weather and forecast JSON from OpenWeatherMap, parses it with ArduinoJson, and prepares data for display on an ST7789 TFT.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-st7789-weather-forecast)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [1.3" 240x240 ST7789 TFT](https://shillehtek.com/products/tft-lcd-1-3-240x240-st7789-esp32-arduino) · [830-Point Breadboard](https://shillehtek.com/products/shillehtek-830-point-breadboard-for-arduino-raspberry-pi-esp32-and-other-microcontrollers) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
