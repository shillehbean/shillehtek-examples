# ESP32 ST7789: Live weather and 5-day forecast

This tutorial builds an ESP32-based weather station that displays live conditions and a 5-day forecast on a 1.3" ST7789 TFT. The code connects the ESP32 to Wi‑Fi, calls the OpenWeatherMap API, parses JSON results, and updates the display periodically.
