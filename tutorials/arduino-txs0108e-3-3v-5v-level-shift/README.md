# Arduino TXS0108E: Safe 3.3V to 5V Level Shifting

This tutorial shows how to build a safe 3.3V ↔ 5V interface using the TXS0108E eight-channel level shifter to protect 3.3V devices while passing fast digital signals. The code examples in this folder provide small test sketches to verify signal pass-through; the included Arduino sketch toggles a 5V-side pin so you can observe the reflected signal on the 3.3V side.
