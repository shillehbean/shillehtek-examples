# Arduino Uno AD8232 ECG Sensor: Plot ECG Waveforms

This tutorial shows how to build a simple ECG monitor using an Arduino (or Nano) and the AD8232 ECG module. The Arduino sketch reads the AD8232 analog output and lead-off pins, sending data over serial; the Processing sketch receives that serial data and plots real-time ECG waveforms and basic lead-off detection.
