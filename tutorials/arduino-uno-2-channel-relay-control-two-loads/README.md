# Arduino UNO 2-Channel Relay Module: Control Two Loads

This tutorial shows how to wire an Arduino UNO to a 2-channel 5V relay module and control two separate loads. The example sketch in this folder provides safe startup state handling and toggles the two relays in a simple sequence, with support for active-low relay modules.
