# Arduino examples

- [`arduino_2ch_relay.ino`](./arduino_2ch_relay.ino) — Arduino sketch to control a 2-channel relay module: toggles two relays in sequence and includes helper functions plus ACTIVE_LOW support and safe startup.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-2-channel-relay-control-two-loads)  
Parts used: [2-Channel 5V Relay Module for Arduino & Raspberry Pi](https://shillehtek.com/products/2-channel-5v-relay-module) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
