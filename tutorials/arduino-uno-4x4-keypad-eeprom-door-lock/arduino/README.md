# Arduino examples

- [`doorlock_eeprom.ino`](./doorlock_eeprom.ino) — Arduino sketch implementing a 4x4 keypad door lock: reads keypad input, masks entry on an LCD1602, verifies the 4-digit code against EEPROM-stored password, and triggers a relay to operate a lock.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-4x4-keypad-eeprom-door-lock)  
Parts used: [4x4 Membrane Matrix Keypad](https://shillehtek.com/products/4x4-membrane-matrix-keypad-16-key-switch-module-for-arduino-diy) · [LCD1602 16x2 Display](https://shillehtek.com/products/shillehtek-lcd1602-16x2-character-display-module) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
