# Arduino Uno 4x4 Keypad: EEPROM Door Lock Build

This tutorial shows how to build a keyless door lock using an Arduino Uno, a 4x4 membrane keypad, a 16x2 LCD, and a 1-channel relay. The included code reads keypad input, masks entries on the LCD, compares the 4-digit code against a password stored in EEPROM, and activates a relay to unlock when the code matches.
