# Arduino examples

- [`ir_dump_hex.ino`](./ir_dump_hex.ino) — Reads incoming IR remote codes with the IRremote library and prints the received values in hexadecimal to the Serial monitor.
- [`relay_toggle_ir.ino`](./relay_toggle_ir.ino) — Listens for a specific IR remote code and toggles a 5V relay output when the POWER code is received.
