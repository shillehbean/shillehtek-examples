# Arduino HC-SR04: Stream Distance to Serial Monitor

This tutorial builds an Arduino-based ultrasonic distance meter using the HC-SR04 sensor and an Arduino Nano. The included sketch triggers the sensor and streams live distance readings in centimetres to the Serial Monitor. Upload the .ino file to your Nano and open the Serial Monitor at 9600 baud to see the measurements.
