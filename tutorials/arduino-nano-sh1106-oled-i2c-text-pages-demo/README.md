# Arduino Nano SH1106 OLED: I2C Text Pages Demo

This tutorial shows how to wire a 1.3" SH1106 I2C OLED to an Arduino Nano and use U8glib to cycle simple text pages. The code folder contains the wiring notes, a short OLED instantiation line, and a complete Arduino sketch that displays two text pages and swaps between them every few seconds.
