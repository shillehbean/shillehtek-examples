# Arduino Uno AMG8833: Stream Thermal Heat Map to PC

This tutorial builds a small thermal camera using an AMG8833 8x8 IR sensor connected to an Arduino Uno or Nano and streams the temperature matrix to a Windows PC. The code included here reads the AMG8833 sensor over I2C and outputs the 8x8 temperature heatmap over the serial port for visualization (for example with VirtualPanel on the PC).
