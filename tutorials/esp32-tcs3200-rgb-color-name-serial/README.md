# ESP32 TCS3200: Print RGB and Color Names

This tutorial shows how to connect a TCS3200 (GY-31) color sensor to an ESP32, calibrate it on black and white, and print normalized RGB values and simple color names to Serial. The code in this folder implements the sensor pin definitions, reading raw pulse widths, calibration storage, and normalization routines used by the tutorial sketch.
