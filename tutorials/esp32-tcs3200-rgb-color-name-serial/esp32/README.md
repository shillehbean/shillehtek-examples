# Esp32 examples

- [`esp32_tcs3200.ino`](./esp32_tcs3200.ino) — Defines ESP32 pin connections, a calibration struct, and functions to set TCS3200 scaling, read raw red/green/blue pulse widths, clamp/normalize readings between black and white calibration, and begins a color detection routine.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-tcs3200-rgb-color-name-serial)
