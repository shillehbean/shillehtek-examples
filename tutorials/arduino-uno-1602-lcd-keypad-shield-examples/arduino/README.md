# Arduino examples

- [`lcd_keypad_read_buttons.ino`](./lcd_keypad_read_buttons.ino) — Reads the analog input from the LCD keypad shield and displays which button (Right, Up, Down, Left, Select) is pressed on the 16x2 LCD.
- [`lcd_scroll_demo.ino`](./lcd_scroll_demo.ino) — Demonstrates scrolling a text string left and right on the 16x2 LCD using lcd.scrollDisplayLeft() and lcd.scrollDisplayRight().
- [`lcd_custom_chars.ino`](./lcd_custom_chars.ino) — Defines several custom 5x8 characters (smiley, battery, arrows, ohm, heart) and writes them to the LCD to show how to render custom glyphs.
