# Arduino Uno 1602 LCD Keypad Shield: Read Buttons

This tutorial shows how to use the Arduino 1602 LCD Keypad Shield to read button presses, scroll text, and render custom characters. The example sketches initialize the shield, read the analog button values to detect presses, demonstrate display scrolling, and create custom glyphs for simple UIs.
