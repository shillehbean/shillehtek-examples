# ESP32-CAM OV2640: Build a WiFi Surveillance Robot

This tutorial shows how to build an ESP32-CAM OV2640 WiFi surveillance robot with live video streaming, mobile app driving, and a pan-tilt camera. The code in this folder contains the ESP32 sketch components used by the robot, including Wi‑Fi credentials and peripheral control snippets needed to compile and run the project.
