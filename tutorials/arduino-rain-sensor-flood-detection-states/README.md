# Arduino Rain Sensor Module: Flood Detection States

This tutorial shows how to build an Arduino-based rain/flood detector using a rain and water level detection sensor module. The Arduino reads the module's analog output on A0 and classifies the reading as Not Raining, Rain Warning, or Flood. The code folder contains the wiring notes and the Arduino sketch that implements the three-state detection.
