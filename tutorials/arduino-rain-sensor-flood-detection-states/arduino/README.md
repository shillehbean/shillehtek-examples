# Arduino examples

- [`rain_sensor_three_state.ino`](./rain_sensor_three_state.ino) — Reads the rain sensor on analog pin A0, maps the reading into three zones, and prints Flood / Rain Warning / Not Raining to the serial console.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-rain-sensor-flood-detection-states)  
Parts used: [Rain and Water Level Detection Sensor Module for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/sensor-rain-water-level-arduino-raspberry-pi-esp32) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
