# Arduino Nano Soil Moisture Sensors: Pick Capacitive

This tutorial compares resistive and capacitive soil moisture sensors and shows how to wire and read a capacitive sensor with an Arduino Nano. The code examples included convert raw analog readings into a calibrated percentage value for moisture reporting.
