# Arduino Nano LCD1602: Autorange capacitance meter

This tutorial shows how to build an autoranging capacitance meter using an Arduino Nano and an LCD1602 (I2C) display. The provided Arduino sketch times RC charge curves on two ranges and displays the measured capacitance on the LCD. The code folder contains the Arduino sketch used in the tutorial.
