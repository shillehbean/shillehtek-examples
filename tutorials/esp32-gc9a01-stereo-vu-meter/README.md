# ESP32 GC9A01: Build a Stereo Retro VU Meter

This tutorial shows how to build a retro-style VU meter using an ESP32 and a 1.28" round GC9A01 TFT. The code reads an analog envelope-follower input and renders a damped needle on the round display to visualize audio level. The folder contains the Arduino/ESP32 sketch used to drive the display and needle motion.
