# Arduino HX1838 IR Receiver: Decode Remote Codes

This example shows how to use an HX1838 IR receiver with an Arduino to read and print remote button codes as hexadecimal values. The code listens for IR signals and outputs the decoded command bytes over the Serial console for mapping to relays, servos, or menu actions.
