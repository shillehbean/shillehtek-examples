# Arduino examples

- [`tb6612_motor_control.ino`](./tb6612_motor_control.ino) — Demonstrates using the SparkFun_TB6612 library to drive a DC motor: full-speed forward and reverse, braking, and half-speed PWM with timed delays.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-tb6612fng-12v-dc-motor-control)  
Parts used: [TB6612FNG Pre-Soldered Dual DC & Stepper Motor Driver](https://shillehtek.com/products/tb6612fng-dual-motor-driver-module-arduino-esp32) · [N20 Micro Metal Gear Motor (12V, 100RPM)](https://shillehtek.com/products/n20-micro-metal-gear-motor-12v-100rpm) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
