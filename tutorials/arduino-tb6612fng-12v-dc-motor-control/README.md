# Arduino TB6612FNG: Control a 12V DC Motor

This tutorial shows how to control a 12V DC motor using an Arduino Uno and the TB6612FNG motor driver. The code in this folder demonstrates basic motor operations: full forward, full reverse, braking, and half-speed PWM control using the SparkFun_TB6612 library.
