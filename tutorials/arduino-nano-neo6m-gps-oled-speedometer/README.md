# Arduino Nano NEO-6M GPS: OLED Speedometer Display

This tutorial builds an Arduino Nano GPS speedometer using a NEO-6M GPS module and a 0.96" SSD1306 I2C OLED display. The provided sketch reads NMEA data with TinyGPS++ over a SoftwareSerial port and shows current speed (km/h) and satellite count on the OLED. It's intended for use on an Arduino Nano or compatible board wired to the GPS and OLED modules.
