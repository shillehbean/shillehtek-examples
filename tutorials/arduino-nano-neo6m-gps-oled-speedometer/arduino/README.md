# Arduino examples

- [`gps_oled_speedometer.ino`](./gps_oled_speedometer.ino) — Reads NEO-6M GPS data via SoftwareSerial using TinyGPS++, and displays current speed in km/h and satellite count on an SSD1306 OLED.
