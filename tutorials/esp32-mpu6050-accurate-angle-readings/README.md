# ESP32 MPU6050: Accurate angle readings with i2cdevlib

This tutorial shows how to measure accurate angles using an ESP32 and an MPU6050 IMU via the i2cdevlib library. The code examples include sensor initialization, applying gyro/accelerometer offsets, reading raw sensor data, and basic filtering to compute stable angle estimates.
