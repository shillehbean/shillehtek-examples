# Arduino Nano Relay: Measure 18650 Capacity in mAh

This project builds an Arduino Nano–based 18650 battery capacity tester that discharges the cell through a resistive load controlled by a relay, measures voltage, and accumulates mAh and mWh until a configurable cutoff (default 3.0 V). The code drives an I2C LCD for status and uses a push button to start/stop the test.
