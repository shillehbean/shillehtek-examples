# Arduino examples

- [`18650_capacity_tester.ino`](./18650_capacity_tester.ino) — Arduino sketch for an Arduino Nano that measures an 18650 battery voltage, controls a 1-channel relay to apply a load, accumulates mAh and mWh during discharge, and displays status on an I2C LCD with button control and cutoff protection.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-relay-measure-18650-mah)
