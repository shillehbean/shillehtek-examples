# BME280 LoRa Telemetry with Meshtastic ESP32 SX1262

This tutorial shows how to wire a BME280 sensor to an ESP32 LoRa (SX1262) and use Meshtastic to broadcast temperature, humidity, and pressure across a private LoRa mesh. The code/commands in this folder contain the Meshtastic CLI setup and device configuration commands used to provision the node and request/receive environmental telemetry.
