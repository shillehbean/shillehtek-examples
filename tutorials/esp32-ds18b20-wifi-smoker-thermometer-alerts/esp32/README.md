# Esp32 examples

- [`esp32_ds18b20_thermometer.ino`](./esp32_ds18b20_thermometer.ino) — ESP32 Arduino sketch that reads a DS18B20 probe, displays temperature on an SSD1306 OLED, connects to Wi‑Fi and sends Telegram alerts and a buzzer notification when the target temperature is reached.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-ds18b20-wifi-smoker-thermometer-alerts)
