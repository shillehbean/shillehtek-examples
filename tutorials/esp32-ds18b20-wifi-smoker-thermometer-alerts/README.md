# ESP32 DS18B20: Wi-Fi Smoker Thermometer Alerts

This project builds a Wi‑Fi connected smoker thermometer using an ESP32, a DS18B20 temperature probe, an SSD1306 OLED display, and a buzzer. The provided code reads the probe, shows the current temperature on the OLED, connects to Wi‑Fi, and sends Telegram alerts (and sounds a buzzer) when the target temperature is reached.
