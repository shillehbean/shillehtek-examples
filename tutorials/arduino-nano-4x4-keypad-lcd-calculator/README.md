# Arduino Nano 4x4 Keypad LCD: Build a Calculator

This tutorial shows how to build a simple calculator using an Arduino Nano, a 4x4 membrane matrix keypad, and a 16x2 I2C LCD. The code reads keypad input, builds arithmetic expressions safely, evaluates operations, and displays the current expression and result on the LCD.
