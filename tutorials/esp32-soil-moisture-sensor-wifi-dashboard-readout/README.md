# ESP32 Soil Moisture Sensor: Wi-Fi Dashboard Readout

This tutorial shows how to build an ESP32-based soil moisture sensor that converts ADC readings to a percentage and serves the value on a simple Wi‑Fi web dashboard. The code in this folder includes the ADC-to-percent formula, a minimal serial-output sketch, Wi‑Fi credentials placeholders, and the web server sketch that serves the dashboard and a moisture endpoint.
