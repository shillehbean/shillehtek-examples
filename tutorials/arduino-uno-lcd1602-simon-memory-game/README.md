# Arduino Uno LCD1602: Simon Memory Game with Score

This tutorial shows how to build a Simon-style memory game on an Arduino Uno using four LEDs and buttons, a passive buzzer for tones, and an LCD1602 via an I2C PCF8574 backpack to show the score. The code in this folder implements the game logic: generating and playing sequences, reading player input, producing sounds and LED feedback, and displaying the final score on the LCD.
