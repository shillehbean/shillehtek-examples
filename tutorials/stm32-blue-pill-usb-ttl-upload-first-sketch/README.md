# STM32 Blue Pill USB to TTL: Upload First Sketch

This tutorial shows how to set up the STM32 "Blue Pill" (STM32F103C8T6) in the Arduino IDE and upload your first sketch using a USB-to-TTL converter. The code in this folder includes a small shell helper to point to the STM32CubeProgrammer binary on macOS and a simple Arduino sketch that prints a message over serial every second.
