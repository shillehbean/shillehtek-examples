# Raspberry Pi Pico W MPU6050: Read IMU Data in C++

This tutorial shows how to interface an MPU6050 accelerometer/gyroscope with the Raspberry Pi Pico W using the Raspberry Pi Pico C++ SDK. The code in this folder builds a Pico executable and implements I2C communication to read IMU data from the MPU6050.
