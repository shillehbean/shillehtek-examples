# Arduino DS3231 RTC: OLED Alarm Clock with Buzzer

This tutorial builds an Arduino-based alarm clock using a DS3231 RTC, an SSD1306 OLED display, and a passive buzzer. The code examples initialize and set the RTC, display the current time and alarm status on the OLED, and trigger a buzzer alarm at the configured time.
