# Arduino Nano LCD1602: Measure 0 to 50 V DC

This project builds a DC voltmeter using an Arduino Nano, an LCD1602 with an I2C PCF8574 backpack, and a resistor divider to measure voltages up to about 50 V. The code reads the analog input, averages samples, applies the divider calibration, and displays the measured voltage or warnings on the LCD.
