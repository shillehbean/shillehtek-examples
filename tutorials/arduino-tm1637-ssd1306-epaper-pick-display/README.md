# Arduino TM1637, SSD1306, E-Paper: Pick a Display

This tutorial shows example code for three common Arduino-compatible displays: a TM1637 4-digit LED module, an SSD1306 I2C OLED, and a 2.13" GxEPD2-based e-paper display. The code examples initialize each display, draw simple text or numbers, and demonstrate the minimal calls needed to update the screen.
