# Arduino examples

- [`tm1637_example.ino`](./tm1637_example.ino) — Initialize a TM1637 4-digit LED display, set brightness, and show the number 1234.
- [`ssd1306_hello.ino`](./ssd1306_hello.ino) — Initialize an SSD1306 128x64 I2C OLED, clear the buffer, write "Hello!" with larger text, and send it to the display.
- [`epaper_213_hello.ino`](./epaper_213_hello.ino) — Initialize a 2.13" GxEPD2 black-and-white e-paper display, clear the screen, draw "Hello!", and perform a full-page update.
