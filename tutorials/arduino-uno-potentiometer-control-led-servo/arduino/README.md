# Arduino examples

- [`potentiometer_led_servo.ino`](./potentiometer_led_servo.ino) — Reads a potentiometer on A0 and maps the value to control LED PWM on pin 9 and a servo angle on pin 10 while printing readings to Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-potentiometer-control-led-servo)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
