# Arduino Uno Potentiometer: Control LED and Servo

This example reads a potentiometer connected to an Arduino Uno and uses the reading to control an LED's brightness and the angle of a servo. The sketch maps the analog input to PWM values for the LED and 0–180° for the servo, and prints the values over serial for debugging.
