# Raspberry Pi Camera: Stream Video Anywhere with ngrok

This tutorial shows how to stream video from a Raspberry Pi Camera to any device using a Flask-based MJPEG server and ngrok to expose the local server remotely. The code here runs the camera, serves a continuous JPEG stream over HTTP, and includes the command used to start ngrok to make the stream accessible outside your LAN.
