# Arduino Nano WS2812 Matrix: 2-Player Reaction Timer

Build a two-player reaction timer using an Arduino Nano, an 8x8 WS2812 RGB LED matrix, two tactile buttons, a start button, and a passive buzzer. The included Arduino sketch controls the LED matrix for idle/ready/GO cues, detects false starts, and keeps score when players press their buttons. Load the sketch onto your Nano to run the reaction timer hardware described in the tutorial.
