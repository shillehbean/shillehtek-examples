# Arduino Nano TCS3200: Read RGB Values in Serial

This tutorial shows how to connect a TCS3200 color sensor to an Arduino Nano to read raw RGB values over the Serial console. The code in this folder configures the sensor frequency scaling, selects color channels, measures output pulse durations, and prints R/G/B readings for quick color detection and calibration.
