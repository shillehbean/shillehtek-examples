# Arduino UNO TCRT5000: Read Line Sensor Values

This tutorial shows how to connect a TCRT5000 IR reflective line sensor to an Arduino UNO and read analog reflectance values. The code included reads the sensor on analog pin A0 and prints the raw readings to the Serial Monitor for debugging or calibration.
