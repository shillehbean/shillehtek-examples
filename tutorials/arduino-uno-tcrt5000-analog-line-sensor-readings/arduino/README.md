# Arduino examples

- [`tcrt5000_analog_read.ino`](./tcrt5000_analog_read.ino) — Reads analog reflectance values from a TCRT5000 sensor connected to A0 and prints them to the Serial Monitor.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-tcrt5000-analog-line-sensor-readings)  
Parts used: [TCRT5000 IR Reflective Line Follower Sensor for Arduino Robots](https://shillehtek.com/products/tcrt5000-ir-reflective-line-follower-sensor-for-arduino-robot)
