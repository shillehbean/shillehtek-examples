# Bash examples

- [`install_mosquitto.sh`](./install_mosquitto.sh) — Install and enable the Mosquitto MQTT broker on the Raspberry Pi.
- [`clone_zigbee2mqtt.sh`](./clone_zigbee2mqtt.sh) — Install git/curl, clone the Zigbee2MQTT repository to /opt/zigbee2mqtt, and change into that directory.
- [`install_node18.sh`](./install_node18.sh) — Add the NodeSource Node.js 18 setup script and install Node.js on the Raspberry Pi.
- [`start_zigbee2mqtt.sh`](./start_zigbee2mqtt.sh) — Start Zigbee2MQTT from the cloned repository using npm.
