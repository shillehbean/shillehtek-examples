# Raspberry Pi + Zigbee Dongle Plus-E: Zigbee2MQTT Setup

This tutorial shows how to set up Zigbee2MQTT on a Raspberry Pi using a Zigbee USB dongle (Plus‑E) and connect a motion sensor to report occupancy via MQTT. The code/files in this folder provide the shell steps to install prerequisites and start Zigbee2MQTT, plus the configuration.yaml used to point Zigbee2MQTT to the MQTT broker and the dongle serial port.
