# Arduino examples

- [`pcf8574_led_demo.ino`](./pcf8574_led_demo.ino) — Demonstrates controlling a PCF8574 I2C GPIO expander from an Arduino: walks a single lit LED across the 8 outputs and then turns all outputs on and off.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-pcf8574-add-8-gpio-i2c)
