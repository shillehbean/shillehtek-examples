# Arduino PCF8574: Add 8 GPIO Pins Over I2C

This tutorial shows how to use a PCF8574 I2C GPIO expander with an Arduino to add eight additional digital outputs and control LEDs over the I2C bus. The included sketch demonstrates basic communication with the PCF8574 by walking a single lit LED across the eight outputs and toggling all outputs on and off.
