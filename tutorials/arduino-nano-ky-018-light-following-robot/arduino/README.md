# Arduino examples

- [`light_follower.ino`](./light_follower.ino) — Full Arduino sketch that reads two LDRs and sets motor directions and PWM speeds to steer the robot toward the brighter light.
- [`safety_stop_snippet.ino`](./safety_stop_snippet.ino) — Small snippet to stop both motors when ambient light is below a defined threshold (safety/idle behavior).
