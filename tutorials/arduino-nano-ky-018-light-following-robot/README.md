# Arduino Nano KY-018: Build a Light-Following Robot

This tutorial shows how to build a simple light-following robot using an Arduino Nano, two KY-018 photoresistor modules, and an L298N motor driver. The code reads two LDR sensors, computes a steering correction, and drives two DC motors with differential speeds so the robot turns toward the brighter side. Included wiring and a small safety snippet stop the motors when ambient light is too low.
