# Arduino examples

- [`ky037_double_clap_relay.ino`](./ky037_double_clap_relay.ino) — Arduino sketch that reads a KY-037 sound sensor and toggles a relay on a detected double-clap using simple debounce and timing logic.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ky-037-double-clap-relay-switch)
