# ESP32-C3 DevKit: Arduino setup with WiFi and BLE

This tutorial shows how to set up an ESP32-C3 DevKit in the Arduino IDE and demonstrates basic WiFi and BLE functionality. The code samples here include a simple LED blink with serial output, a WiFi network scanner that prints SSIDs and RSSI, and a BLE GATT server that advertises a notify characteristic and sends periodic notifications. Use these sketches as starting points for building low-cost IoT nodes.
