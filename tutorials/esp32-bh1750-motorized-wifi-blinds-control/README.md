# ESP32 BH1750: Motorized Wi-Fi Blinds Control

This tutorial shows how to build motorized Wi‑Fi blinds using an ESP32, a 28BYJ‑48 stepper with ULN2003 driver, and an optional BH1750 light sensor for automation. The code below runs a web server on the ESP32 to move the blinds up and down and reads ambient light for potential automatic control.
