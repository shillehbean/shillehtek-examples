# Arduino Nano APDS-9960: Gesture LCD Menu Control

This project builds an Arduino Nano gesture-controlled menu using the APDS-9960 RGB/gesture sensor and a 16x2 I2C LCD. The example code displays a simple menu on the LCD, lets you navigate with hand gestures, and toggles two outputs (LEDs or loads) with left/right swipes.
