# ESP32 HLK-LD2410: Reliable Bedroom Occupancy

This tutorial shows how to build an ESP32 + HLK-LD2410 (and related HLK mmWave modules) bedroom occupancy sensor that reliably detects still presence and moving presence, and publishes that data to Home Assistant via ESPHome. The repository contains the ESPHome YAML configuration used on the ESP32 to read the LD2410 over UART and expose a binary occupancy sensor plus several distance/energy sensors.
