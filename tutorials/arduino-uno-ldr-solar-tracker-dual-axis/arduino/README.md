# Arduino examples

- [`ldr_solar_tracker.ino`](./ldr_solar_tracker.ino) — Reads four LDRs, computes left/right and top/bottom averages with a dead band, and drives two servos to track the brightest light by moving one degree per loop while printing positions to Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-ldr-solar-tracker-dual-axis)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Pan-Tilt Servo Bracket Kit](https://shillehtek.com/products/pan-tilt-servo-bracket-kit-sg90-mg90s) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [830-Point Breadboard](https://shillehtek.com/products/shillehtek-830-point-breadboard-for-arduino-raspberry-pi-esp32-and-other-microcontrollers) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
