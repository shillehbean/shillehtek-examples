# Arduino Uno LDR Solar Tracker: Dual-Axis Light Following

This project builds a dual-axis Arduino Uno solar tracker that uses four LDRs (photoresistors) and two servos to follow a light source. The code reads the four analog sensors, computes horizontal and vertical differences with a configurable dead-band, and incrementally moves the pan and tilt servos to track the brightest direction.
