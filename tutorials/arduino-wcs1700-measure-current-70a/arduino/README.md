# Arduino examples

- [`wcs1700_current_monitor.ino`](./wcs1700_current_monitor.ino) — Reads the WCS1700 current sensor using the Robojax_WCS library, prints measured current to Serial, and shows an example threshold-trigger action.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-wcs1700-measure-current-70a)  
Parts used: [WCS1700 70A Hall-Effect Current Sensor Module with Overcurrent Detection](https://shillehtek.com/products/wcs1700-70a-hall-current-sensor-module-overcurrent-detect) · [120pcs 10cm Jumper Wire Set M-F, M-M, F-F for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-10cm-multicolored-jumper-wire)
