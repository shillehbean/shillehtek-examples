# Arduino WCS1700: Measure Current Up to 70A

This example project reads a WCS1700 70A Hall-effect current sensor from an Arduino Uno and prints real-time current measurements to the Serial Monitor. The code demonstrates sensor initialization, zero calibration, averaging, and a simple threshold trigger for custom actions.
