# Arduino ULN2003 Stepper: One-Revolution Control

This tutorial shows how to wire a 28BYJ-48 stepper motor with a ULN2003 driver board to an Arduino Nano and run it for precise single-revolution motions. The code in this folder demonstrates a simple Arduino sketch that rotates the motor one full revolution clockwise and then one full revolution counterclockwise with a pause between moves.
