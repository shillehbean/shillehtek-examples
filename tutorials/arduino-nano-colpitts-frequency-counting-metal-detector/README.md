# Arduino Nano Colpitts Oscillator: Build a Metal Detector

This project builds a simple metal detector using an Arduino Nano and a Colpitts oscillator; the circuit frequency shifts when metal is near the coil. The provided Arduino sketch measures the oscillator frequency, maintains a self-calibrating baseline, and drives LEDs and a buzzer to indicate small and large frequency deviations.
