# STM32 Blue Pill MPU6050: Read data and calibrate gyro

This folder contains Arduino sketches used in the "STM32 Blue Pill MPU6050: Read data and calibrate gyro" tutorial. The examples show how to initialize the MPU6050 over I2C, read raw accelerometer and gyroscope values, and perform a simple gyroscope calibration to remove bias.
