# Arduino examples

- [`mpu6050_read_raw.ino`](./mpu6050_read_raw.ino) — Initializes the MPU6050, verifies the connection, and continuously reads and prints raw accelerometer and gyroscope values over Serial.
- [`mpu6050_gyro_calibration.ino`](./mpu6050_gyro_calibration.ino) — Initializes the MPU6050, runs a gyroscope calibration routine to compute offsets, then reads sensor data and applies the gyro offsets before printing adjusted values.
