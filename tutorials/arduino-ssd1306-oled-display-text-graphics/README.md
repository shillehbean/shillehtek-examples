# Arduino SSD1306 OLED: Display Text and Graphics

This tutorial shows how to wire an Arduino Nano to an SSD1306 0.96" I2C OLED and upload a simple sketch that displays text and basic graphics on a 128x64 screen. The code in this folder initializes the SSD1306 display, prints text at different sizes, draws rectangles, and updates the display once.
