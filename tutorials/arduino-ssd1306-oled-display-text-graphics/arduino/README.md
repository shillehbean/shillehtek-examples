# Arduino examples

- [`ssd1306_oled_demo.ino`](./ssd1306_oled_demo.ino) — Initializes an SSD1306 I2C OLED, prints two lines of text at different sizes, draws a rectangle and a filled rectangle, then updates the display.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ssd1306-oled-display-text-graphics)
