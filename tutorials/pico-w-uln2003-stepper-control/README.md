# Pico W ULN2003: Drive a 28BYJ-48 Stepper

This tutorial shows how to control a 28BYJ-48 stepper motor with a ULN2003 driver board using a Raspberry Pi Pico W running MicroPython. The code implements the stepping sequence, direction control, and motor release; it assumes the stepper is powered from a safe external 5V supply with a shared ground to the Pico W.
