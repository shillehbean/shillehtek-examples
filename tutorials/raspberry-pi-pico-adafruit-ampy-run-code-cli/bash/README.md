# Bash examples

- [`ampy_put.sh`](./ampy_put.sh) — Uploads a local Python file to the Pico's filesystem over the specified serial port using ampy.
- [`ampy_get.sh`](./ampy_get.sh) — Downloads a file from the Pico to the host machine and saves it under a local filename via ampy.
- [`ampy_rm.sh`](./ampy_rm.sh) — Removes a file from the Pico's filesystem over the specified serial port using ampy.
- [`ampy_run.sh`](./ampy_run.sh) — Remotely executes a Python script on the Pico without permanently copying it to the device using ampy run.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-adafruit-ampy-run-code-cli)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
