# Raspberry Pi Pico W HC-SR04: Wi-Fi Robot Course Setup

This tutorial shows how to build a Wi‑Fi controlled obstacle‑avoidance robot using a Raspberry Pi Pico W, an HC‑SR04 ultrasonic sensor, and an L298N motor driver. The code in this folder contains MicroPython examples for the Pico W used for setup and basic hardware tests.
