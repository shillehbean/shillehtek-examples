# ESP32 BLE UART: Phone Control and Notifications

This tutorial shows how to build an ESP32 BLE UART (Nordic UART Service) server so a phone can control an output and receive live sensor notifications. The included code initializes the BLE NUS service, handles incoming write commands from a phone to switch an output, and prepares the ESP32 to send notifications back to a connected phone.
