# Arduino Nano MG995 Servo: High-Torque Position Control

This tutorial shows how to control an MG995 high-torque metal-gear servo using an Arduino Nano with an external 5V supply and a shared ground for stable positioning. The code example demonstrates attaching the servo with an extended pulse-width range suitable for the MG995 and cycles it through several positions to verify full sweep and centering.
