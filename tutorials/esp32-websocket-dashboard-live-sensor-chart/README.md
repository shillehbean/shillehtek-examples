# ESP32 WebSocket Dashboard: Live Browser Sensor Chart

This project builds an ESP32-hosted WebSocket dashboard that streams KY-018 (photoresistor) and DHT11 temperature/humidity sensor readings to a live browser chart. The code here is the ESP32 Arduino sketch that reads the sensors, serves the single-page web UI from flash, and sends sensor updates over a WebSocket while allowing an LED toggle from the page.

**Read the full tutorial:** [ESP32 WebSocket Dashboard: Live Browser Sensor Chart](https://shillehtek.com/blogs/news/esp32-websocket-dashboard-live-sensor-chart)
