# Esp32 examples

- [`esp32_websocket_dashboard.ino`](./esp32_websocket_dashboard.ino) — ESP32 Arduino sketch that reads a KY-018 photoresistor and DHT11 sensor, hosts a single-page web dashboard from flash, and streams sensor values over a WebSocket while handling LED toggle commands.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-websocket-dashboard-live-sensor-chart)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [KY-018 Photoresistor Module](https://shillehtek.com/products/photoresistor-light-sensor-ky-018-arduino-esp32) · [DHT11 Temperature & Humidity Sensor](https://shillehtek.com/products/shillehtek-dht11-with-cables) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
