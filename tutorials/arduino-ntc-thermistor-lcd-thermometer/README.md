# Arduino 10K NTC Thermistor: LCD Thermometer Alarm

This tutorial shows how to build an Arduino-based thermometer using a 10K NTC thermistor, a 10K fixed resistor in a divider, and a 16x2 LCD. The code reads the thermistor, applies Steinhart–Hart calibration to compute stable temperature in °C and °F, and drives LEDs and a buzzer for an over-temperature alarm.
