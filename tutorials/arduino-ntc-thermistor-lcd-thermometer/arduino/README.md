# Arduino examples

- [`ntc_lcd_thermometer.ino`](./ntc_lcd_thermometer.ino) — Arduino sketch that reads a 10K NTC thermistor on A0, computes temperature via the Steinhart–Hart equation, displays Celsius and Fahrenheit on a 16x2 LCD, and controls LEDs and a buzzer for alarms.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ntc-thermistor-lcd-thermometer)
