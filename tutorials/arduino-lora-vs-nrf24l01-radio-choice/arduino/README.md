# Arduino examples

- [`radio_examples.ino`](./radio_examples.ino) — Two minimal Arduino sketches: one transmits a uint32 value over an NRF24L01+ using TMRh20's RF24 library, the other sends a 'hello' packet over LoRa using Sandeep Mistry's LoRa library.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-lora-vs-nrf24l01-radio-choice)
