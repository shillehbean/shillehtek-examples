# Arduino Nano MPU9250 IMU: Stream 9-Axis Data

This tutorial shows how to wire an Arduino Nano to an MPU9250 9-DOF IMU and stream accelerometer, gyroscope, and magnetometer data over the serial port. The code in this folder reads the IMU and prints formatted 9-axis data for quick motion and heading testing.
