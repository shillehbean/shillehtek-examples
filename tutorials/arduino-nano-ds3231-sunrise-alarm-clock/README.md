# Arduino Nano DS3231: Build a Sunrise Alarm Clock

This project builds an Arduino Nano sunrise alarm clock using a DS3231 RTC, an SSD1306 OLED display, a relay (or MOSFET) to control lighting with a gradual fade-in, and a piezo buzzer for the alarm. The code reads the RTC, shows the current time on the OLED, ramps power to the lighting over a configurable fade period before the alarm, and sounds the buzzer at the alarm time.
