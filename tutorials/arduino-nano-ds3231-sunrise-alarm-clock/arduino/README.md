# Arduino examples

- [`sunrise_alarm.ino`](./sunrise_alarm.ino) — Arduino sketch that reads time from a DS3231 RTC, displays it on an SSD1306 OLED, fades a relay/MOSFET output over a pre-alarm period to simulate sunrise, and activates a buzzer at the alarm time.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ds3231-sunrise-alarm-clock)  
Parts used: [DS3231 AT24C32 Precision RTC I2C Module with CR2032 Battery](https://shillehtek.com/products/ds3231-at24c32-iic-module-precision-rtc-module-with-cr2032-battery) · [1-Channel 5V Relay Board for Arduino & Raspberry Pi](https://shillehtek.com/products/1-channel-5v-relay-module) · [KY-006 Passive Piezo Buzzer Module for Arduino](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [SSD1306 0.96" Blue I2C OLED Display Module 4-Pin for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/0-96-i2c-blue-oled-display-module-4-pin-ssd1306) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [TPA3118 PBTL Single Digital Amplifier Board 1x60W](https://shillehtek.com/products/tpa3118-pbtl-single-digital-amplifier-board-1x60w)
