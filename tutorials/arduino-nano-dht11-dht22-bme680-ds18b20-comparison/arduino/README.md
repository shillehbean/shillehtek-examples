# Arduino examples

- [`multi_sensor_examples.ino`](./multi_sensor_examples.ino) — Minimal example snippets showing how to read temperature and humidity from DHT11/DHT22, DS18B20, and BME680 (using BSEC) on an Arduino Nano.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-dht11-dht22-bme680-ds18b20-comparison)
