# Arduino Nano DHT11/DHT22/BME680/DS18B20: Best Pick

This tutorial sketches an Arduino Nano project that reads temperature and humidity from four different sensors (DHT11, DHT22, DS18B20, and BME680) to compare accuracy, waterproof capability, and VOC-related readings.
