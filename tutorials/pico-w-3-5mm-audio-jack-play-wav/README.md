# Pico W 3.5mm Audio Jack: Play WAV via MicroPython

This tutorial shows how to play a WAV file from a Raspberry Pi Pico W through a 3.5mm audio jack breakout using MicroPython and PWM. The code here includes the ffmpeg conversion step to prepare the WAV file, commands to copy files to the Pico, and the MicroPython script that streams 8-bit mono 8 kHz audio to a PWM pin.
