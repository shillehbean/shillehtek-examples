# Arduino examples

- [`tds_oled_ppm_meter.ino`](./tds_oled_ppm_meter.ino) — Reads an analog TDS sensor on A1, applies median filtering and temperature compensation, computes water PPM using the Gravity sensor curve, and displays the value on an SSD1306 OLED.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-tds-sensor-oled-ppm-meter)  
Parts used: [Analog TDS Water Quality Sensor Module](https://shillehtek.com/products/tds-water-sensor-module-arduino-raspberry-pi-esp32) · [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [SSD1306 0.96" I2C OLED Display (128x64)](https://shillehtek.com/products/0-96-i2c-white-oled-display-module-4-pin-ssd1306) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
