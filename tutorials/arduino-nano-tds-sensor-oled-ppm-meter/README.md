# Arduino Nano TDS Sensor: Display Water PPM on OLED

This tutorial shows how to build a simple TDS (total dissolved solids) meter using an Arduino Nano, a Gravity-style analog TDS sensor, and a 0.96" SSD1306 I2C OLED. The provided sketch reads the sensor on the analog pin, applies median filtering and temperature compensation, converts the reading to PPM, and displays the live value on the OLED.
