# D1 Mini I2C LCD: Live YouTube Stats Display

This project builds a live YouTube channel statistics counter using an ESP8266 D1 Mini and an I2C 16x2 LCD. The provided Arduino sketch connects the board to Wi‑Fi, calls the YouTube Data API, parses the JSON response, and displays subscriber count, view count, and video count on the LCD. Update the SSID, password, API key, and channel ID in the sketch before uploading.
