# Micropython examples

- [`install_urequests.py`](./install_urequests.py) — Install the urequests HTTP library on the ESP32 MicroPython runtime using upip.
- [`config.py`](./config.py) — Define the WiFi SSID and password used by the MicroPython camera/network scripts.
