# ESP32-CAM Camera: Run MicroPython with WiFi support

This tutorial shows how to run MicroPython on an ESP32-CAM, enable WiFi, and access the onboard camera to stream images. The code in this folder includes the firmware flashing commands, a small MicroPython helper to install the urequests package, and a configuration file for WiFi credentials used by the camera scripts.
