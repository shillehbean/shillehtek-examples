# Arduino examples

- [`ds18b20_relay_controller.ino`](./ds18b20_relay_controller.ino) — Reads temperature from a DS18B20 sensor and switches a relay on/off to maintain a target incubation temperature with a hysteresis band, while printing status to serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ds18b20-relay-fermentation-controller)  
Parts used: [DS18B20 Waterproof Digital Temperature Sensor Probe 1M for Arduino & Raspberry Pi](https://shillehtek.com/products/ds18b20-waterproof-digital-temp-sensor-probe-1m-for-arduino-pi) · [1-Channel 5V Relay Board for Arduino & Raspberry Pi](https://shillehtek.com/products/1-channel-5v-relay-module) · [LCD1602 16x2 LCD Display Module for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-lcd1602-16x2-character-display-module) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
