# Arduino DS18B20 Relay: Control Fermentation Temps

This tutorial builds an Arduino Nano-based fermentation temperature controller using a DS18B20 waterproof probe, a 1-channel relay, and an LCD (optional). The code monitors the probe temperature and toggles a heating relay with a small hysteresis band to hold a target incubation temperature and prints status to serial.
