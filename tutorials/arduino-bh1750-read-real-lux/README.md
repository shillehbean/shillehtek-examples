# Arduino BH1750: Read Real Lux Over Serial

This tutorial builds an Arduino Nano lux meter using a BH1750 (GY-302) digital light sensor. The code reads real-time light intensity over I2C and prints lux values to the Serial Monitor. The repository contains the Arduino sketch used in the tutorial.
