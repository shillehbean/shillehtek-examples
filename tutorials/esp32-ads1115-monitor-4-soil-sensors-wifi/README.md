# ESP32 ADS1115: Monitor 4 Soil Sensors via Wi-Fi

This tutorial builds an ESP32-based soil moisture monitor that reads four sensors connected to an ADS1115 ADC and serves live readings over Wi‑Fi. The code in this folder starts Wi‑Fi, reads ADS1115 channels, and provides a simple web dashboard showing raw ADC values for each sensor.
