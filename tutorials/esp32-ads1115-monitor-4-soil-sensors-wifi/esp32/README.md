# Esp32 examples

- [`esp32_ads1115_moisture_server.ino`](./esp32_ads1115_moisture_server.ino) — Reads four channels from an ADS1115 ADC and serves a simple HTML page over Wi‑Fi showing the raw ADC values for each soil sensor.
