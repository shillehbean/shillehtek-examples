# Arduino ADXL345: Calibrate and Read 3-Axis Data

This tutorial shows how to connect an ADXL345 3-axis accelerometer to an Arduino, calibrate it, and read the X/Y/Z acceleration values over I2C. The code configures the sensor, includes a calibration routine to compute offsets, and prints the readings to the Serial console.
