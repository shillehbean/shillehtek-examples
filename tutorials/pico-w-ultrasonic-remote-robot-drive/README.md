# Raspberry Pi Pico W Ultrasonic Sensor: Remote Robot Drive

This project builds a Raspberry Pi Pico W robot with Wi‑Fi remote drive, ultrasonic emergency stop, NeoPixel feedback, and an asynchronous MicroPython web server. The code in this folder contains the MicroPython scripts that set up networking, sensor I/O, motor control, and the web server used by the tutorial.
