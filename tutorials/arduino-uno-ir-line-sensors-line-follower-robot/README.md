# Arduino Uno IR Line Sensors: Build a Line Follower Robot

This tutorial builds a simple Arduino Uno line follower robot using two IR (TCRT5000-style) line sensors and an L298N motor driver to control two DC gear motors. The code folder contains the Arduino sketch that reads the sensors and drives the motors with basic rule-based logic to follow a black line.
