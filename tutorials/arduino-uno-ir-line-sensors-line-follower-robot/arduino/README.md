# Arduino examples

- [`line_follower.ino`](./line_follower.ino) — Reads two IR line sensors and controls the L298N motor driver to drive the robot forward, turn left/right, or stop based on simple rule-based line-following logic.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-ir-line-sensors-line-follower-robot)  
Parts used: [L298N Motor Driver Board](https://shillehtek.com/products/shillehtek-l298n-motor-driver-controller-board) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [N20 Micro Metal Gear Motors (12V, 100RPM)](https://shillehtek.com/products/n20-micro-metal-gear-motor-12v-100rpm) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard)
