# Arduino Nano LCD1602: Build a Whack-a-Mole Game

This project builds a simple Whack-a-Mole game using an Arduino Nano, five LEDs/buttons, an I2C LCD1602 display, and a buzzer. The provided code drives the game logic: lighting random "moles", reading button hits, updating score and a countdown bar on the LCD, and playing buzzer sounds for hits/misses.
