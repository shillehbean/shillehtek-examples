# Arduino examples

- [`analogread_serial.ino`](./analogread_serial.ino) — Simple example that reads the analog voltage on A0 and prints the raw ADC value to the Serial console every 100 ms.
- [`mq7_co_monitor.ino`](./mq7_co_monitor.ino) — MQ-7 CO monitor sketch that reads the MQ-7 on A0 and a DS18B20 temperature sensor on a OneWire bus, prints readings to Serial, and sounds a buzzer when CO exceeds a defined limit.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-mq-7-co-buzzer-alarm)  
Parts used: [MQ-7 Carbon Monoxide (CO) Gas Sensor Module](https://shillehtek.com/products/mq-7-co-gas-sensor-module-arduino-esp32) · [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [DS18B20 Waterproof Temperature Probe](https://shillehtek.com/products/ds18b20-waterproof-digital-temp-sensor-probe-1m-for-arduino-pi) · [KY-006 Passive Piezo Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
