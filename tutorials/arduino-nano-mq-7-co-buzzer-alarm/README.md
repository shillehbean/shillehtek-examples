# Arduino Nano MQ-7 Sensor: CO Readings and Buzzer Alarm

This project demonstrates an Arduino Nano-based carbon monoxide monitor using an MQ-7 sensor, a DS18B20 temperature probe, and a passive buzzer. The code examples include a simple analog reader that streams A0 values to Serial and a full monitor sketch that reads CO and temperature and triggers a buzzer when CO exceeds a configurable threshold.
