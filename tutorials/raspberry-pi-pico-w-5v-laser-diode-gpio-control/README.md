# Raspberry Pi Pico W 5V Laser Diode: Safe GPIO Control

This tutorial shows how to safely control a 5V laser diode from a Raspberry Pi Pico W using a simple transistor switch and an MB102 breadboard power supply. The folder contains a wiring diagram (text) and a MicroPython example that blinks the laser on and off for testing.
