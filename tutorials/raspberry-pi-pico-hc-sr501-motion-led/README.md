# Raspberry Pi Pico HC-SR501 PIR: Motion LED Trigger

This tutorial shows how to wire an HC-SR501 PIR motion sensor to a Raspberry Pi Pico (or Pico W) and use MicroPython to detect motion and trigger an LED. The code in this folder implements a simple motion detection loop with debounce handling, turning an LED on when motion is detected and off after motion stops.
