# Arduino Uno MQ135: Read Serial Monitor Values

This tutorial shows how to connect an MQ-135 air quality sensor to an Arduino Uno and read live analog values. The example code reads the sensor on analog pin A0 and prints raw ADC values to the Serial Monitor every second for quick testing and calibration.
