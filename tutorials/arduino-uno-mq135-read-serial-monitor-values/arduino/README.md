# Arduino examples

- [`mq135_analog_read.ino`](./mq135_analog_read.ino) — Reads the MQ-135 sensor on analog pin A0 and prints the raw ADC value to the Serial Monitor every second.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-mq135-read-serial-monitor-values)  
Parts used: [MQ-135 Air Quality Hazardous Gas Sensor Module for Arduino](https://shillehtek.com/products/mq-135-air-quality-hazardous-gas-sensor-module-for-arduino)
