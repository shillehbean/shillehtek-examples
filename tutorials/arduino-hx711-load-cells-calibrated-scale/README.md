# Arduino HX711 Load Cells: Build Calibrated Scale

This tutorial shows how to build a calibrated Arduino scale using an HX711 amplifier and load cells (Wheatstone bridge). The code folder contains a calibration sketch to determine the correct scale factor and a demo sketch that prints calibrated weight readings to the serial console.
