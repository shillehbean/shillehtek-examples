# Arduino examples

- [`hx711_calibration.ino`](./hx711_calibration.ino) — Calibration sketch that reads the HX711, prints zero factor, and lets you adjust the calibration factor via the serial console to match a known weight.
- [`hx711_scale_demo.ino`](./hx711_scale_demo.ino) — Demo sketch that applies the calibrated scale factor and continuously prints weight readings (in pounds) to the serial console.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-hx711-load-cells-calibrated-scale)
