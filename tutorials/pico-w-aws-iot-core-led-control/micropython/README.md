# Micropython examples

- [`aws_iot_mqtt_pico.py`](./aws_iot_mqtt_pico.py) — MicroPython script for Raspberry Pi Pico W that reads PEM certificate files, connects to Wi‑Fi, and prepares an MQTT client for a secure TLS connection to AWS IoT Core while controlling the on‑board LED.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pico-w-aws-iot-core-led-control)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
