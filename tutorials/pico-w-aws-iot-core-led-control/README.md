# Raspberry Pi Pico W AWS IoT Core: MQTT LED Control

This tutorial shows how to connect a Raspberry Pi Pico W to AWS IoT Core and send/receive MQTT messages to control the Pico's LED using mutual TLS authentication. The code in this folder contains the MicroPython script that reads certificate files, connects the Pico W to Wi‑Fi, and prepares an MQTT client to communicate securely with AWS IoT Core.
