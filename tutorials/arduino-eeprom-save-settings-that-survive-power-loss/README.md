# Arduino EEPROM: Save Settings After Power Loss

This tutorial builds simple Arduino examples that save settings to EEPROM so they survive power loss. The code demonstrates saving a single LED state and a structured settings object (with defaults, a magic marker, and a boot counter) using EEPROM.update, EEPROM.put, and EEPROM.get.
