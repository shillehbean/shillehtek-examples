# Bash examples

- [`setup.sh`](./setup.sh) — Install system packages and Python libraries required for capture, streaming, and video assembly (OpenCV, Flask, Picamera2, ffmpeg).
- [`assemble_timelapse.sh`](./assemble_timelapse.sh) — Assemble captured JPEG frame files into a 30 fps H.264-encoded MP4 timelapse using ffmpeg.
