# Raspberry Pi 4B Camera Module: Build a time-lapse

This tutorial shows how to build a Raspberry Pi time-lapse using the Pi Camera and Picamera2. The code here captures frames on a schedule, overlays timestamps, can stream a live MJPEG preview via Flask, and includes the ffmpeg command to assemble frames into a final MP4.
