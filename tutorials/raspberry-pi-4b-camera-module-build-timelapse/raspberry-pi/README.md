# Raspberry Pi examples

- [`timelapse_capture.py`](./timelapse_capture.py) — Initialize the Picamera2, capture frames repeatedly for a timed timelapse session, overlay the current time on each frame, and prepare an output directory for frames.
- [`stream_server.py`](./stream_server.py) — Provide a Flask-based MJPEG endpoint that streams live camera frames with a timestamp overlay to web clients.
