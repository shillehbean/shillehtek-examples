# Arduino LCD2004 I2C: Hello World on 20x4 Display

This example shows how to connect a 20x4 character LCD with a PCF8574 I2C adapter to an Arduino Nano using only four connections (VCC, GND, SDA, SCL). The provided Arduino sketch initializes the LCD over I2C and prints a four-line "Hello, World!" message. Use these files as a starting point for menus or sensor readouts on a 20x4 I2C display.
