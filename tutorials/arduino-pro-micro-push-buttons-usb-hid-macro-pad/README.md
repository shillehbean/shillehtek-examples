# Arduino Pro Micro Push Buttons: USB HID Macro Pad

This tutorial turns an Arduino Pro Micro (ATmega32U4) into a 4-button USB HID macro pad that sends media/function keys to a host computer. The code in this folder reads four pushbuttons using internal pull-ups and sends F13–F16 keypresses over USB when each button is pressed.
