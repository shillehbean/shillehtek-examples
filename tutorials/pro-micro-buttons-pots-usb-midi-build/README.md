# Pro Micro Buttons and Pots: USB MIDI Build

This tutorial builds a USB MIDI controller using a Pro Micro (ATmega32U4) with eight momentary buttons and four potentiometers. The sketch below uses the MIDIUSB library to send MIDI Note On/Off messages for the buttons and MIDI Continuous Controller (CC) messages for the pots so a DAW recognizes the controller instantly. Load the sketch onto the Pro Micro and wire the buttons to digital pins and pots to analog inputs as shown in the tutorial.
