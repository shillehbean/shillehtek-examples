# ESP32 Xedge SMTP: Send Email Securely

This tutorial shows how to send email securely from an ESP32 using the Xedge IDE and its built-in SMTP support with Lua. The code examples demonstrate constructing an email message and invoking xedge.sendmail from firmware running on XIAO and other ESP32-based boards. Use the provided Lua snippet to configure recipient, subject, and body, and to handle the send result via a callback.
