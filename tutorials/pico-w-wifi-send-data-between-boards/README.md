# Pico W WiFi: Send data between boards

This tutorial shows how to send data between multiple Raspberry Pi Pico W boards on a local network using Thonny and MicroPython. The code folder includes a simple TCP server that sends a random number and a client that requests and prints that number; update the client with the server IP before running.
