# Arduino Nano DS3231 + TM1637: Drift-Free Alarm Clock

This tutorial shows how to build a drift-free alarm clock using an Arduino Nano, a DS3231 precision RTC, and a TM1637 4-digit display. The code here reads time and temperature from the DS3231 and drives the TM1637 to show the time (with a periodic temperature display). Wiring information and the Arduino sketch are provided for replication.
