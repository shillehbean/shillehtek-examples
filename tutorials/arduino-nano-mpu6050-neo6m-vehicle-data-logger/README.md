# Arduino Nano MPU6050 + NEO-6M: Log GPS + IMU to SD

This tutorial shows how to build an Arduino Nano vehicle data logger that records GPS position/speed and IMU (MPU6050) accelerometer/gyroscope data to a microSD card. The included code reads the NEO-6M GPS and MPU6050, then writes timestamped CSV records to an SD card for later analysis.
