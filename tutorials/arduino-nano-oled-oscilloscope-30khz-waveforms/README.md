# Arduino Nano OLED: Triggered Waveforms to ~30 kHz

This project builds a simple mini-oscilloscope using an Arduino Nano and a 0.96" SSD1306 I2C OLED. The sketch captures triggered ADC waveforms, displays the trace on the OLED, and computes peak-to-peak voltage and frequency up to about 30 kHz.
