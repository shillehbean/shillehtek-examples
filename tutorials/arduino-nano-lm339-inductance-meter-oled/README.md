# Arduino Nano LM339: Measure Inductance on OLED

This tutorial shows how to build an LC ring inductance meter using an Arduino Nano, an LM339 comparator oscillator, and a 0.96" I2C SSD1306 OLED. The provided sketch charges the LC tank, measures the oscillation period with pulseIn(), computes inductance from a calibrated capacitor value, and displays the result on the OLED.
