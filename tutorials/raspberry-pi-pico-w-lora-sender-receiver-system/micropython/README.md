# Micropython examples

- [`lora_picow_sender.py`](./lora_picow_sender.py) — Configures a LoRa module over UART and repeatedly sends a text message to a remote address using AT commands.
- [`lora_picow_receiver.py`](./lora_picow_receiver.py) — Configures a LoRa module over UART and listens for incoming messages, parsing +RCV responses and printing received payloads.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-lora-sender-receiver-system)
