# Raspberry Pi Pico W LoRa: Build a Sender Receiver Link

This tutorial shows how to build a long-range, low-power LoRa sender-receiver link using a Raspberry Pi Pico W and an AT-command based LoRa module. The code in this folder contains two MicroPython scripts: one to configure the LoRa module and send periodic messages, and one to configure the module and listen for incoming messages over UART.
