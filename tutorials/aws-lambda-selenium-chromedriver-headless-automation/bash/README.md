# Bash examples

- [`chrome-installer.sh`](./chrome-installer.sh) — Installer script that downloads the latest stable Chrome and Chromedriver releases from the chrome-for-testing JSON feed and unpacks them into /opt.
- [`push_to_ecr.sh`](./push_to_ecr.sh) — Shell commands to tag the built image for ECR, authenticate Docker to ECR, and push the image to the specified ECR repository.
