# AWS Lambda Selenium ChromeDriver: Run Headless Automation

This example shows how to run Selenium with ChromeDriver in AWS Lambda by packaging a headless Chrome and Chromedriver inside a container-based Lambda. The repo contains the Lambda handler, a Dockerfile to build the Lambda image, a script to download and install the matching Chrome and Chromedriver artifacts, and helper commands to build and push the image to ECR.
