# ESP32 ESP-NOW: Send DHT11 Data to OLED

One ESP32 reads a DHT11 and sends temperature and humidity to a second ESP32 over ESP-NOW; the receiver displays the readings on an SSD1306 OLED. Open and upload the sender and receiver as separate sketches to their respective boards. Set RECEIVER_MAC in the sender to the MAC printed by the receiver before using the pair.
