# ESP32 ESP-NOW: Send DHT11 Data to OLED

This tutorial builds an ESP-NOW pair where one ESP32 reads temperature and humidity from a DHT11 and broadcasts the data, and a second ESP32 receives those broadcasts and displays them on an SSD1306 OLED. The code in this folder contains the Arduino-framework ESP32 sketch for the sender (DHT11 + ESP-NOW) and the beginning of the receiver (OLED) implementation.
