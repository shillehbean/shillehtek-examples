# ESP32 DHT11 MQTT: Home Assistant dashboard sensor

This example builds an ESP32-based room sensor using a DHT11 that publishes temperature and humidity over MQTT and accepts a relay ON/OFF command from Home Assistant. The folder contains the ESP32 Arduino sketch for Wi‑Fi/MQTT/DHT handling and the Home Assistant MQTT configuration to create sensors and a switch from the MQTT topics.
