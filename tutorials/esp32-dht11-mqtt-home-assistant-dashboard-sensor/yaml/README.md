# Yaml examples

- [`home_assistant_mqtt.yml`](./home_assistant_mqtt.yml) — Home Assistant YAML configuration that defines MQTT sensors for temperature and humidity and a switch linked to MQTT command and state topics.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-dht11-mqtt-home-assistant-dashboard-sensor)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [DHT11 Temperature & Humidity Sensor](https://shillehtek.com/products/shillehtek-dht11-with-cables) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [ESP8266 D1 Mini](https://shillehtek.com/products/esp8266-d1-mini-v3-4mb-dev-board-presoldered) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
