# Arduino examples

- [`blink_pc13.ino`](./blink_pc13.ino) — Blink the onboard LED (PC13) on the STM32F411 Black Pill with a 100 ms on/off interval.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/stm32-black-pill-arduino-ide-dfu-upload)  
Parts used: [STM32F411CEU6 Pre-Soldered Black Pill ARM Development Board for Arduino](https://shillehtek.com/products/shillehtek-pre-soldered-authentic-stm32f411ceu6)
