# STM32 Black Pill Arduino IDE: Upload via DFU Bootloader

This tutorial shows how to set up the Arduino IDE for the STM32F411 Black Pill (pre-soldered) and upload a simple blink sketch via the DFU bootloader using STM32CubeProgrammer. The code folder contains the Board Manager package index reference used to add STM32 cores to the Arduino IDE and a minimal Arduino sketch that blinks the onboard LED on PC13.
