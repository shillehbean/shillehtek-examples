# Arduino Nano DS18B20: Build a Sous-Vide Controller

This example builds a simple sous-vide controller using an Arduino Nano, a DS18B20 waterproof temperature probe, and a relay to switch a heater. The sketch reads temperature, applies a hysteresis control around a target temperature, and reports status over the serial console.
