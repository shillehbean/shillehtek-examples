# Raspberry Pi SG90 Servos: Python Pan-Tilt Control

This tutorial shows how to build a Raspberry Pi pan-tilt platform using SG90/MG90S micro servos and safe external 5V power. The code in this folder demonstrates simple PWM-based angle control of two servos (pan and tilt) using the RPi.GPIO library and an angle-to-duty conversion suitable for standard hobby servos.
