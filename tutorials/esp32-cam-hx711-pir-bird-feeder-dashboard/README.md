# ESP32-CAM HX711 PIR: Motion photos with seed weight

This project builds an ESP32-CAM bird feeder monitor that captures motion-triggered photos using a PIR sensor and logs seed weight via an HX711 load cell amplifier. The code initializes the camera, Wi-Fi, PIR input, and HX711, takes photos when motion is detected, and reads seed weight to report via Serial or a POST endpoint.
