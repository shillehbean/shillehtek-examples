# ESP32 Telegram Bot: Remote Relay Pump Control

This tutorial shows how to build an ESP32-powered Telegram bot to remotely control a relay-driven pump, with support for /on, /off, timed runs, status replies, and a local button override. The code connects the ESP32 to Wi‑Fi and the Telegram Bot API, listens for messages from a single allowed chat, and toggles a relay accordingly.
