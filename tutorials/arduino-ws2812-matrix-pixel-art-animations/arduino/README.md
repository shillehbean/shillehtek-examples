# Arduino examples

- [`ws2812_8x8_animation.ino`](./ws2812_8x8_animation.ino) — Reads an 8x8 pixel frame stored in PROGMEM and displays it on a WS2812 (NeoPixel) matrix using FastLED; demonstrates how to add additional frames and cycle them for animations.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ws2812-matrix-pixel-art-animations)  
Parts used: [CJMCU-64 8x8 WS2812 RGB LED Matrix Module](https://shillehtek.com/products/ws2812-8x8-led-matrix-arduino-esp32-raspberry-pi) · [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [MB102 Breadboard Power Supply](https://shillehtek.com/products/shillehtek-universal-power-supply-module) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
