# Arduino WS2812 8x8 Matrix: Play Pixel Art Animations

This tutorial builds an Arduino-driven 8x8 WS2812 (NeoPixel) LED matrix that plays pixel art animations using the FastLED library. The code stores pixel frames in flash (PROGMEM) and renders them to the 8x8 matrix. The example sketch shows loading a frame and how to extend it to cycle multiple frames for animation.
