# Arduino UNO SSD1306 OLED: Wire and Display Text

This tutorial shows how to wire a 0.91" SSD1306 128x32 I2C OLED to an Arduino UNO and display text using the U8g2 library. The code in this folder initializes the OLED over I2C and draws two lines of text on the screen.
