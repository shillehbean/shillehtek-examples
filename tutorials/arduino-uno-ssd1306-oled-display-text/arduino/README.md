# Arduino examples

- [`ssd1306_text.ino`](./ssd1306_text.ino) — Initializes an SSD1306 128x32 I2C OLED with U8g2 and displays two lines of text repeatedly.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-ssd1306-oled-display-text)  
Parts used: [SSD1306 0.91" 128x32 I2C OLED Display Module for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/oled-ssd1306-128x32-i2c-0-91in) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
