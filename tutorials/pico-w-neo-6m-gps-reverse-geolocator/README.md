# Pico W NEO-6M GPS: Reverse geocode your location

This tutorial shows how to build a reverse geolocator using a Raspberry Pi Pico W and a NEO-6M GPS module. The included code reads NMEA GPS data over UART, connects the Pico W to Wi‑Fi, and sends reverse-geocoding requests to obtain city and country information for the current coordinates.
