# Micropython examples

- [`pico_w_gps_reverse_geocode.py`](./pico_w_gps_reverse_geocode.py) — Initializes UART to read NMEA sentences from the GPS, provides a Wi‑Fi connection helper, and performs HTTP requests for reverse geocoding (MicroPython code for Pico W).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pico-w-neo-6m-gps-reverse-geolocator)
