# Raspberry Pi examples

- [`ky037_detect_sound.py`](./ky037_detect_sound.py) — Sets up GPIO4 as a digital input and reads the KY-037's D0 output to print whether sound is detected; includes comments on tuning the module sensitivity.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-ky-037-detect-sound-python)
