# Raspberry Pi KY-037: Detect Sound in Python

This tutorial shows how to wire a KY-037 sound sensor to a Raspberry Pi and read its digital output with Python. The code in this folder configures a GPIO pin, reads the sensor's digital output, and prints whether sound is detected; it also includes notes about adjusting the module's sensitivity potentiometer.
