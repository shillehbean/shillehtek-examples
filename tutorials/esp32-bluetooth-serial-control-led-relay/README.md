# ESP32 Bluetooth Serial: Control an LED or Relay

This tutorial builds an ESP32 Bluetooth Serial (SPP) command interface so you can control an LED or a relay from an Android phone and receive two-way status feedback. The code in this folder implements a BluetoothSerial server that accepts plain-text commands (led on, led off, toggle, status) and echoes status back to the phone and the USB serial monitor.
