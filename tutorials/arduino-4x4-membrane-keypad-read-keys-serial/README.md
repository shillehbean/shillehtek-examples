# Arduino 4x4 Membrane Keypad: Read Keys in Serial

This folder contains Arduino example sketches that demonstrate how to read a 4×4 membrane matrix keypad and stream key presses to the Serial Monitor. One example shows simple key reading and printing; the other implements a basic passcode checker that pulses a lock pin on successful entry. Use the Keypad library and connect the keypad rows/columns to the Arduino digital pins shown in the sketches.
