# Arduino examples

- [`keypad_serial_read.ino`](./keypad_serial_read.ino) — Reads a 4×4 membrane matrix keypad and prints each pressed key to the Serial Monitor.
- [`keypad_passcode.ino`](./keypad_passcode.ino) — Implements a simple passcode checker: collect digits, use '#' to submit, '*' to clear, and pulse a lock output on correct code.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-4x4-membrane-keypad-read-keys-serial)
