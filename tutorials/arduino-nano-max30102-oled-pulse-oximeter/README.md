# Arduino Nano MAX30102: OLED Pulse Oximeter Build

This tutorial shows how to build a simple pulse oximeter using an Arduino Nano, a MAX30102 heart rate/SpO2 sensor, and a 0.96" SSD1306 I2C OLED. The code in this folder reads the sensor's IR values, detects heart beats, computes a moving-average BPM, and displays the heart rate on the OLED.
