# Arduino 74HC595: Drive 8 LEDs from 3 Pins

This tutorial shows how to use a 74HC595 shift register with an Arduino to drive eight LEDs while using only three Arduino pins. The included code demonstrates updating all outputs at once with shiftOut(), and provides example patterns: a binary counter and a Knight Rider style chase.
