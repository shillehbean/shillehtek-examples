# Arduino examples

- [`shift_register_74hc595.ino`](./shift_register_74hc595.ino) — Drives eight LEDs via a 74HC595 shift register using shiftOut(); implements a binary counter and a Knight Rider chase pattern.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-74hc595-drive-8-leds-3-pins)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [830-Point Breadboard](https://shillehtek.com/products/shillehtek-830-point-breadboard-for-arduino-raspberry-pi-esp32-and-other-microcontrollers) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
