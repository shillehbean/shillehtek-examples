# Arduino Nano LCD1602: Auto-Ranging Ohmmeter Build

This tutorial shows how to build an auto-ranging ohmmeter using an Arduino Nano, five reference resistors, and an LCD1602 display with an I2C adapter. The included code controls the reference resistor pins, reads the sense analog input, selects ranges automatically, and prints measured resistance on the LCD. The repository contains the Arduino sketch used in the tutorial.
