# Raspberry Pi Pico W + MB102 Power Supply: Reliable Breadboard Power

This tutorial demonstrates powering a Raspberry Pi Pico W from an MB102 breadboard power supply and provides wiring tips for a clean, reliable setup. The code in this folder contains a simple MicroPython example that blinks the Pico W onboard LED to verify power and connections.
