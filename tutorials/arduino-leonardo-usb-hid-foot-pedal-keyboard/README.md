# Arduino Leonardo USB HID: Build a Foot Pedal Keyboard

This tutorial shows how to build a USB HID foot pedal keyboard using an Arduino Leonardo / ATmega32U4 board to send Page Up and Page Down keystrokes for hands-free control. The code folder contains a simple two-pedal example and a configurable multi-pin keyboard mapper sketch, plus a short wiring note.
