# ESP8266 Espalexa: Alexa Relay Voice Control

This tutorial builds a local Alexa-discoverable smart relay using an ESP8266/ESP32 and the Espalexa library so Alexa can control devices without cloud skills. The code below runs on the ESP board, exposes two devices (a dimmable lamp and a relay-controlled fan) and handles discovery and commands from Alexa.
