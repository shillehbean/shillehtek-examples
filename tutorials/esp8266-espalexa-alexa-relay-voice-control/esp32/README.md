# Esp32 examples

- [`espalexa_relay.ino`](./espalexa_relay.ino) — Arduino-framework sketch that uses Espalexa to expose a dimmable lamp (PWM) and a relay-controlled fan to Alexa over local WiFi, handling discovery and commands.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp8266-espalexa-alexa-relay-voice-control)  
Parts used: [ESP8266 D1 Mini](https://shillehtek.com/products/esp8266-d1-mini-v3-4mb-dev-board-presoldered) · [ESP32 38-Pin Dev Board](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
