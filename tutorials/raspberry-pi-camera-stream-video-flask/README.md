# Raspberry Pi Camera: Stream Video with Flask

This tutorial shows how to stream live video from a Raspberry Pi Camera to a web browser on your local network using Python and Flask. The code in this folder runs the PiCamera, captures continuous JPEG frames, and serves them as an MJPEG stream at the /video_feed endpoint.
