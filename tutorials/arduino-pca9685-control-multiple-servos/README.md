# Arduino PCA9685: Control Multiple Servos Easily

This tutorial shows how to build an Arduino Uno multi-servo controller using the PCA9685 16-channel PWM driver for cleaner I2C wiring and stable servo timing. The code in this folder demonstrates a basic servo sweep across multiple PCA9685 channels so you can verify wiring and servo motion.
