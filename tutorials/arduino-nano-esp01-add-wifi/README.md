# Arduino Nano ESP-01: Add Wi-Fi with AT Commands

This tutorial shows how to add Wi‑Fi to an Arduino Nano using an ESP8266 ESP‑01 module and AT commands over a serial connection. The included sketch connects the ESP‑01 to a Wi‑Fi network, opens a TCP connection to example.com, sends an HTTP GET request, and prints the response to the Serial Monitor.
