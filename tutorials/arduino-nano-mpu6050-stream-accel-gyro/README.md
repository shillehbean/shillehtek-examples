# Arduino Nano MPU6050: Stream Accel and Gyro Data

This tutorial shows how to connect an MPU6050 IMU to an Arduino Nano and stream live accelerometer and gyroscope data over the serial connection. The code in this folder reads sensor events from the Adafruit MPU6050 library and prints the accel/gyro values to Serial for use in logging or real-time motion projects.
