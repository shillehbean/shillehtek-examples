# Pico W BMP180: Pressure, temp, altitude readings

This tutorial shows how to connect a BMP180 pressure and temperature sensor to a Raspberry Pi Pico W over I2C and read temperature, pressure, and altitude. The code in this folder demonstrates a MicroPython script that polls the BMP180 and prints temperature (C and F), pressure (hPa), and calculated altitude.
