# ESP32-C6 Zigbee: Build a Light + Switch Network

This tutorial builds a two-node ESP32-C6 Zigbee network with a light (end device) and a switch (coordinator). The code in this folder contains the ESP32 Arduino-framework sketches: one for the Zigbee light endpoint that controls a local LED, and one for the Zigbee coordinator/switch that forms the network and sends on/off commands.
