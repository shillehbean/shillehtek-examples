# Raspberry Pi Pico W Rshell: Use REPL to Blink LED

This tutorial demonstrates using rshell to access the MicroPython REPL on a Raspberry Pi Pico or Pico W and to manage and run MicroPython code files. The code in this folder provides a minimal example that toggles the Pico's onboard LED using the machine.Pin API.
