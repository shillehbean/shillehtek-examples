# Arduino Uno 16x2 LCD: Custom Icons and Animations

This tutorial shows how to drive a 16x2 HD44780-compatible LCD over I2C from an Arduino Uno, create custom characters with createChar(), and use them for icons, a smooth 80-step progress bar, and a simple walking animation. The code here contains small example sketches and character data you can drop into an Arduino project and run with an LCD1602 + PCF8574 I2C adapter.
