# Arduino Uno HX711 Load Cell: Read Weight in Serial Monitor

This tutorial shows how to connect an HX711 load cell amplifier to an Arduino Nano/Uno and read live weight measurements in the Serial Monitor. The code provided initializes the HX711, tares the scale, applies a calibration factor, and prints the weight readings periodically.
