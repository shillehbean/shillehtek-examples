# Arduino examples

- [`hx711_weight_read.ino`](./hx711_weight_read.ino) — Arduino sketch that initializes an HX711 load cell amplifier, tares the scale, applies a calibration factor, and prints weight readings to the Serial Monitor.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-hx711-load-cell-read-weight)
