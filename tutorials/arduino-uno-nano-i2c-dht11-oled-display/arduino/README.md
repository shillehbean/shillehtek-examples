# Arduino examples

- [`nano_dht11_i2c_peripheral.ino`](./nano_dht11_i2c_peripheral.ino) — Arduino Nano peripheral sketch: reads DHT11 temperature and humidity every 2 seconds, stores values as tenths, responds to I2C requests with four bytes (temp10 high/low, hum10 high/low), and accepts a one-byte LED on/off command from the bus master.
- [`uno_oled_i2c_master.ino`](./uno_oled_i2c_master.ino) — Arduino Uno master sketch: requests four bytes (temperature and humidity in tenths) from the peripheral at 0x08, displays the values on an SSD1306 128x64 OLED and prints to Serial, and (intended to) send an LED control command back to the peripheral (note: this block is truncated at the end).
