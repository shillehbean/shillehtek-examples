# Raspberry Pi Pico Wokwi: Simulate projects without hardware

This tutorial demonstrates how to simulate Raspberry Pi Pico and Pico W projects in Wokwi without physical hardware, including examples that use the MPU6050 IMU. The code in this folder contains MicroPython examples for the Pico such as a simple onboard LED blink and sensor interface examples referenced in the post.
