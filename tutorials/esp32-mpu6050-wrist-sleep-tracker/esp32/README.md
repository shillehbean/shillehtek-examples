# Esp32 examples

- [`mpu6050_sleep_tracker.ino`](./mpu6050_sleep_tracker.ino) — Reads the MPU6050 accelerometer, computes the per-minute peak acceleration magnitude (activity level) minus gravity, and prints the 1-minute peak to Serial.
