# ESP32 MPU6050: Build a Wrist Sleep Tracker

This tutorial shows how to build a wrist sleep tracker using an ESP32 board and an MPU6050 IMU to log overnight motion and infer sleep depth from movement. The code in this folder reads accelerometer data, computes a per-minute peak activity metric, and outputs the results over serial for logging or further upload.
