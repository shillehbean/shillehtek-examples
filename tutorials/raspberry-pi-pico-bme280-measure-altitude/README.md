# Raspberry Pi Pico BME280: Measure altitude

This tutorial shows how to measure altitude with a BME280 sensor connected to a Raspberry Pi Pico running CircuitPython. The included code initializes the I2C bus, configures the BME280, and prints temperature, humidity, pressure, and calculated altitude continuously.
