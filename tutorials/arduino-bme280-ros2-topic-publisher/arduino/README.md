# Arduino examples

- [`bme280_serial.ino`](./bme280_serial.ino) — Arduino sketch that reads temperature, humidity, and pressure from a BME280 over I2C and prints CSV (temp,hum,press) to Serial every 2 seconds.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-bme280-ros2-topic-publisher)
