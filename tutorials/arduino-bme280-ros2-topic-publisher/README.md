# Arduino BME280: Publish ROS 2 Topic on Raspberry Pi

This tutorial shows how to connect a BME280 sensor to an Arduino and publish its temperature, humidity, and pressure readings as a ROS 2 topic on a Raspberry Pi. The repository contains the Arduino sketch that prints CSV sensor data over serial, a ROS 2 Python node that reads the serial data and publishes a Float32MultiArray topic, and helper scripts for creating, building, and running the ROS 2 package.
