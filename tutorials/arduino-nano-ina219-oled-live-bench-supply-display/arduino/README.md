# Arduino examples

- [`ina219_oled_bench_supply.ino`](./ina219_oled_bench_supply.ino) — Reads bus voltage, current, and power from an INA219 sensor and displays the values on an SSD1306 OLED, updating approx. every 250 ms.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ina219-oled-live-bench-supply-display)
