# Arduino Nano INA219 OLED: Live Bench Supply Display

This tutorial builds a simple bench power monitor using an Arduino Nano, an LM2596 buck regulator, an INA219 current/power sensor, and a 0.96" SSD1306 I2C OLED. The code reads voltage, current, and power from the INA219 and displays live measurements on the OLED. Use the sketch to get continuous real-time readouts while powering your projects.
