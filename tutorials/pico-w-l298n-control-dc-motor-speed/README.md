# Pico W L298N Motor Driver: Control DC Motor Speed

This tutorial shows how to control a DC motor with a Raspberry Pi Pico W using an L298N motor driver board and MicroPython. The code in this folder provides a simple example to set motor direction and PWM-based speed, and demonstrates forward, stop, and reverse actions in a loop.
