# ESP8266 WS2812 Ring: NTP-Synced NeoPixel Clock

This project builds an ESP8266 D1 Mini desk clock using a 24-LED WS2812 (NeoPixel) ring and NTP to keep time. The code here connects the board to Wi‑Fi, retrieves time from an NTP server, and drives the NeoPixel ring to display the current time.
