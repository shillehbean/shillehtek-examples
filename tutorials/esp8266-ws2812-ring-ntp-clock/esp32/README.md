# Esp32 examples

- [`esp8266_ntp_neopixel.ino`](./esp8266_ntp_neopixel.ino) — ESP8266 Arduino-framework sketch that connects to Wi‑Fi, syncs time via NTP, and drives a 24-LED WS2812 NeoPixel ring to act as a clock.
