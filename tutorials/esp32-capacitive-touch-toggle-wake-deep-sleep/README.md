# ESP32 Capacitive Touch Pins: Toggle LED and Wake Sleep

This tutorial shows how to use an ESP32's capacitive touch pins to make a touch button that toggles an LED or relay and to wake the board from deep sleep with a touch. The repository contains two Arduino/ESP32 sketches: one that reads a touch pad, debounces it, and toggles an output; and another that arms the touch pad as a wake source and enters deep sleep for ultra-low-power operation.
