# Arduino HC-SR04 Servo: Touchless Pump Dispenser Build

This project builds a touchless sanitizer dispenser using an HC-SR04 ultrasonic distance sensor and a servo to press a pump once per detected hand presence. The code reads distance, triggers the servo to press and release the pump, and prints distance values over Serial for debugging.
