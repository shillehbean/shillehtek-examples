# Arduino examples

- [`hcsr04_servo_dispenser.ino`](./hcsr04_servo_dispenser.ino) — Reads distance from an HC-SR04 and moves a servo to actuate a sanitizer pump when a hand is detected, ensuring one pump per hand and printing distances over Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-hc-sr04-servo-touchless-sanitizer-dispenser)  
Parts used: [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [Servo Tester](https://shillehtek.com/products/servo-tester-rc-ccpm-checker) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
