# Arduino Uno LED Traffic Light: Build a Sequencing Controller

This tutorial builds a simple Arduino Uno LED traffic light controller that sequences green, yellow, and red LEDs with realistic timing. The code in this folder implements the light control functions and a main loop that runs the go/caution/stop cycle.
