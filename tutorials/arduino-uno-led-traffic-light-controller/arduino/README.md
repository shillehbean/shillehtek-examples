# Arduino examples

- [`led_traffic_light.ino`](./led_traffic_light.ino) — Controls three LEDs on pins 2, 4, and 6 to implement a traffic-light sequence (green, yellow, red) with specified durations.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-led-traffic-light-controller)
