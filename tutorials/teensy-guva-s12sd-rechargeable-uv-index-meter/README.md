# Teensy 4.0 GUVA-S12SD: Rechargeable UV Index Meter

This project builds a rechargeable UV index meter using a Teensy 4.0, a GUVA-S12SD UV sensor module, an ST7789 color LCD, and a TP4056 LiPo charging board. The code reads UV index and battery percentage and updates the display only when values change.
