# Arduino Nano Piezo Knock Sensor: Secret Knock Relay Lock

This project builds an Arduino Nano piezo knock sensor that flashes an LED for each tap and unlocks a relay when a three-knock code is detected within a timing window. The code reads the piezo analog input, debounces hits, counts knocks, and drives an active-low relay module accordingly.
