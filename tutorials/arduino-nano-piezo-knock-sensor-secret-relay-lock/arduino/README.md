# Arduino examples

- [`secret_knock_lock.ino`](./secret_knock_lock.ino) — Reads a piezo sensor, flashes an LED on each knock, counts knocks within a timing window, and unlocks an active-low relay when the secret knock count is matched.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-piezo-knock-sensor-secret-relay-lock)  
Parts used: [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [KY-006 Passive Piezo Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
