# Arduino examples

- [`servo_angle_smooth.ino`](./servo_angle_smooth.ino) — Smoothly sweep a servo between MIN_ANGLE and MAX_ANGLE by incrementing/decrementing the target angle and writing positions with Servo.write().
- [`servo_microseconds_smooth.ino`](./servo_microseconds_smooth.ino) — Smoothly sweep a servo by gradually adjusting the pulse width (microseconds) and sending pulses with Servo.writeMicroseconds() for finer control.
