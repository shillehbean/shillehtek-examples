# Raspberry Pi Pico W MQTT: Send messages anywhere

This tutorial demonstrates sending MQTT messages between Raspberry Pi Pico W devices over Wi‑Fi. The code folder contains Wi‑Fi connection helpers and two MicroPython MQTT client examples (one using umqtt.robust and one using umqtt.simple) that connect to an SSL MQTT broker.
