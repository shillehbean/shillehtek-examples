# Micropython examples

- [`mqtt_client_robust.py`](./mqtt_client_robust.py) — Provides Wi‑Fi connection helper and an MQTT client using umqtt.robust to connect to an SSL MQTT broker.
- [`mqtt_client_simple.py`](./mqtt_client_simple.py) — Provides Wi‑Fi connection helper and an MQTT client using umqtt.simple to connect to an SSL MQTT broker.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-mqtt-send-messages-anywhere)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
