# Arduino Nano RCWL-0516: Through-Wall Motion Detect

This tutorial shows how to build a through-wall motion detector using an RCWL-0516 microwave Doppler radar module, an Arduino Nano, and a 5V relay (optionally alongside a PIR and a photoresistor for night-only operation). The included code reads the radar module output and drives a relay for a configurable hold time when motion is detected.
