# Bash examples

- [`update_and_upgrade.sh`](./update_and_upgrade.sh) — Updates the package lists and upgrades installed packages on the Raspberry Pi.
- [`add_tailscale_repo.sh`](./add_tailscale_repo.sh) — Adds Tailscale's GPG key and APT repository for Raspbian Buster so the package can be installed from Tailscale's repository.
- [`install_tailscale.sh`](./install_tailscale.sh) — Refreshes APT package lists and installs the Tailscale package on the Raspberry Pi.
