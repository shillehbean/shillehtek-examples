# Arduino Nano MQ-2: Build a Gas Leak Alarm

This tutorial shows how to build a gas and smoke alarm using an Arduino Nano and an MQ-2 sensor, with an optional OLED display and an ESP32 for Wi‑Fi notifications. The code samples include the core Nano sketch that reads the sensor and drives a buzzer, an OLED helper for displaying estimated ppm, and an ESP32 notifier that posts alerts to ntfy.sh.
