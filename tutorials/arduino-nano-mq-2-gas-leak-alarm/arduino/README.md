# Arduino examples

- [`mq2_nano_alarm.ino`](./mq2_nano_alarm.ino) — Reads the MQ-2 analog output on A0, prints readings over serial, and sounds a buzzer when the analog value exceeds a threshold.
- [`mq2_oled_helpers.ino`](./mq2_oled_helpers.ino) — Initializes an SSD1306 OLED object and provides a helper function to estimate gas ppm from a raw analog reading (placeholder calibration values).
