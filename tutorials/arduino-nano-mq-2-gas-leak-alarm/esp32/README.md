# Esp32 examples

- [`esp32_notify_ntfy.ino`](./esp32_notify_ntfy.ino) — ESP32 Arduino-framework snippet that checks an analog input and sends an HTTP POST notification to ntfy.sh when the reading exceeds a threshold.
