# Arduino examples

- [`hidden_touch_relay.ino`](./hidden_touch_relay.ino) — Arduino sketch that reads the TTP223B touch sensor and toggles a 5V relay (active LOW) on each touch, with a simple debounce.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ttp223b-hidden-touch-relay-switch)  
Parts used: [TTP223B Pre-Soldered Capacitive Touch Switch Sensor Module](https://shillehtek.com/products/digital-sensor-ttp223b-module-capacitive-touch-switch) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [1-Channel 5V Relay Board for Arduino & Raspberry Pi](https://shillehtek.com/products/1-channel-5v-relay-module) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
