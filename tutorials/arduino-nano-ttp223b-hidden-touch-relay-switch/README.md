# Arduino Nano TTP223B: Hidden Touch Relay Switch

This project builds a hidden capacitive touch relay switch using an Arduino Nano and a TTP223B sensor to toggle a 5V relay through materials like acrylic or wood. The code here reads the touch sensor and toggles the relay state on each detected touch, with a small debounce delay.
