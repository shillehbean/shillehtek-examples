# Arduino Nano IR Sensor: Measure RPM on OLED Display

This tutorial shows how to build an Arduino Nano tachometer using an IR sensor to count rotation pulses and an SSD1306 0.96" I2C OLED to display RPM. The code in this folder reads interrupt-driven pulses, computes RPM once per second, and renders the value on the OLED.
