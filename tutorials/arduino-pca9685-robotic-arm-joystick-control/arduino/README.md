# Arduino examples

- [`pca9685_init_center.ino`](./pca9685_init_center.ino) — Initialize the PCA9685 PWM driver, set 50 Hz refresh rate, and center the first six servos.
- [`joystick_two_axis_control.ino`](./joystick_two_axis_control.ino) — Read two analog joystick axes and map them to servo angles for base and shoulder, updating channels 0 and 1 on the PCA9685.
