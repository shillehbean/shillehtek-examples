# Arduino PCA9685: Joystick-Controlled 6-DOF Arm

This tutorial shows how to build a 6-DOF robotic arm using an Arduino Nano, a PCA9685 servo driver, MG90S servos, and a dual-axis analog joystick. The code in this folder initializes the PCA9685, centers the servos, and provides a simple joystick-to-servo mapping for the base and shoulder axes (using analog inputs A0 and A1).
