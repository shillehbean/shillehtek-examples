# Arduino Nano RC522 RFID: Unlock a Servo Cat Door

This project builds an Arduino Nano-controlled cat door using an RC522 RFID reader and a servo latch. The included sketch reads RFID key fobs, checks them against an authorized UID list, and moves a servo to unlock the latch for allowed tags.
