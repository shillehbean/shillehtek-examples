# Arduino examples

- [`obstacle_avoiding_robot.ino`](./obstacle_avoiding_robot.ino) — Arduino sketch that initializes the HC-SR04 and servo, reads distances, and provides motor-control functions to drive an obstacle-avoiding robot.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-hc-sr04-obstacle-avoiding-robot)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [L298N Motor Driver](https://shillehtek.com/products/shillehtek-l298n-motor-driver-controller-board) · [N20 Gear Motors](https://shillehtek.com/products/n20-micro-metal-gear-motor-12v-100rpm) · [TB6612FNG Driver](https://shillehtek.com/products/tb6612fng-dual-motor-driver-module-arduino-esp32) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
