# Arduino Uno HC-SR04: Build an Obstacle-Avoiding Robot

This tutorial shows how to build an obstacle-avoiding robot using an Arduino Uno, an HC-SR04 ultrasonic sensor mounted on a servo, and an L298N motor driver to steer two DC gear motors. The code in this folder is the Arduino sketch that measures distance, sweeps the sensor, and controls the motors to navigate around obstacles.
