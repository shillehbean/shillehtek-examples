# Arduino Nano IR Obstacle Sensor: Filament Run-Out Alarm

This tutorial shows how to build a simple filament run-out alarm using an IR obstacle sensor and a passive piezo buzzer connected to an Arduino Nano. The code in this folder reads the IR sensor and sounds a repetitive buzzer pattern when filament is detected as absent. It is a minimal sketch intended for use as a local alarm and can be extended to signal a printer controller for pause behavior.
