# Micropython examples

- [`pico_w_mpu6050_mqtt.py`](./pico_w_mpu6050_mqtt.py) — MicroPython script for the Raspberry Pi Pico W that initializes I2C for an MPU6050, reads certificate files, connects to Wi‑Fi, and prepares an MQTT client to publish sensor data to AWS IoT Core.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-mpu6050-send-data-dynamodb)
