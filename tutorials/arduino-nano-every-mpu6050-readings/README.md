# Arduino Nano Every MPU6050: Read I2C Sensor Values

This tutorial shows how to connect an MPU6050 IMU sensor to an Arduino Nano Every, wire the I2C lines, configure the sensor, and read accelerometer and gyroscope values over serial. The code in this folder demonstrates initializing the Adafruit MPU6050 library, setting sensor ranges, and streaming sensor readings for calibration and troubleshooting.
