# Arduino MAX3421E USB Host Shield: Read USB Barcodes

This tutorial shows how to use a MAX3421E USB Host Shield with an Arduino to read input from a USB HID barcode scanner. The example code initializes the USB host, parses keyboard (HID) reports from the scanner, and prints each scanned barcode to the Serial port.
