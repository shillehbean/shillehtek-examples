# ESP32 AutoConnect: Captive Wi-Fi Setup Portal

This tutorial shows how to build an ESP32 captive Wi-Fi setup portal using the AutoConnect library so a phone or other client can provision Wi-Fi credentials without reflashing. The code in this folder implements a minimal sketch that hosts the portal, serves a simple root page, and retains/reconnects saved network credentials.
