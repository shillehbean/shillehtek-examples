# Esp32 examples

- [`esp32_autoconnect.ino`](./esp32_autoconnect.ino) — Creates an ESP32 sketch that uses the AutoConnect library to host a captive Wi-Fi setup portal, serves a simple root web page, and saves/reconnects Wi‑Fi credentials.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-autoconnect-wifi-setup-portal)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [ESP8266 D1 Mini](https://shillehtek.com/products/esp8266-d1-mini-v3-4mb-dev-board-presoldered) · [XIAO ESP32-C6](https://shillehtek.com/products/xiao-seeed-esp32c6-pre-soldered-with-usb-c-cable) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
