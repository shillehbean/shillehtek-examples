# ESP32-C6 Zigbee: Build a Wireless Light Switch

This tutorial builds a two-node ESP32-C6 Zigbee network consisting of a wireless switch and a remote LED light. The code in this folder contains the ESP32-C6 Zigbee light endpoint firmware that registers an endpoint with the Zigbee core, drives an LED, and handles a button for local toggle and factory reset.
