# Raspberry Pi Pico + KY-037: Clap Toggle Desk Lamp

This tutorial shows how to build a clap-controlled desk lamp using a KY-037 sound sensor and a Raspberry Pi Pico wired to an IoT relay. The code folder contains a MicroPython toggle program that debounces/clamps repeated triggers and a simple monitor script to test the sensor output and onboard LED.
