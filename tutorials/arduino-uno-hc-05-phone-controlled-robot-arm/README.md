# Arduino Uno HC-05: Phone-Controlled Robot Arm Build

This tutorial demonstrates building a 3DOF robot arm (with additional wrist/gripper servos) controlled from an Android phone over an HC-05 Bluetooth module. The code in this folder is an Arduino sketch that reads simple Bluetooth commands to move six servos and includes hooks for saving and replaying motion sequences.
