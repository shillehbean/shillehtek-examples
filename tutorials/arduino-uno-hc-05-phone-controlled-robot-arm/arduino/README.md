# Arduino examples

- [`robot_arm_bluetooth.ino`](./robot_arm_bluetooth.ino) — Arduino sketch that controls six servos from an HC-05 Bluetooth connection, parsing commands like 's1NNN' to set servo angles and providing placeholders for speed control, save (record) and run (replay) motion steps.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-hc-05-phone-controlled-robot-arm)  
Parts used: [MG995 Metal Gear Servo (12kg High Torque)](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [HC-05 6-Pin Bluetooth Module](https://shillehtek.com/products/hc-05-6pin-bluetooth-module-no-button) · [Arduino Uno R3](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [LM2596 Adjustable Step-Down Converter](https://shillehtek.com/products/shillehtek-lm2596-dc-dc-adjustable-step-down-power-supply-module) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [3DOF DIY Robot Arm Kit with 3x MG995 Servos](https://shillehtek.com/products/3dof-robot-arm-kit-mg995-servos)
