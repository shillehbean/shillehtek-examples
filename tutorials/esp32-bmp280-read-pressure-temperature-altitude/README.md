# ESP32 BMP280: Read pressure, temperature, altitude

This tutorial shows how to connect a BMP280 pressure/temperature sensor to an ESP32 and read pressure, temperature, and calculated altitude. The code in this folder contains the example Arduino sketch used to initialize the BMP280 (I2C or SPI) and print sensor readings over Serial.
