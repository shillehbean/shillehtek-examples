# Arduino Nano BMP280: Stream Serial Readings

This tutorial shows how to wire a BMP280 pressure/temperature sensor to an Arduino Nano over I2C and stream live temperature, pressure, and altitude readings to the Serial Monitor. The sketch uses the Adafruit_BMP280 library to read sensor data and prints values once per second. Use the Arduino IDE to open and upload the included sketch to your Nano with the BMP280 connected to SDA/SCL, 3.3V (or 5V as appropriate), and GND.
