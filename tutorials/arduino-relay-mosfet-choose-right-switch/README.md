# Arduino Relay vs MOSFET: Choose the Right Switch

This tutorial compares relay modules, NPN transistors, and logic‑level MOSFETs and shows wiring and Arduino examples for switching AC and DC loads. The code snippets in this folder demonstrate how to drive an active‑LOW 5V relay and an NPN transistor from an Arduino Nano (digital pin 7), including a PWM example for the transistor.
