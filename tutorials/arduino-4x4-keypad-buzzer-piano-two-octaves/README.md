# Arduino 4x4 Keypad: Two-Octave Buzzer Piano

This tutorial builds a two-octave piano using an Arduino Nano, a 4x4 membrane keypad, and a passive piezo buzzer. The provided Arduino sketch scans the keypad, maps each key to a musical note frequency, plays the note on the buzzer, and prints the frequency to the Serial monitor.
