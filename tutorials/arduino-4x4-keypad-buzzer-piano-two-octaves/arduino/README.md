# Arduino examples

- [`keypad_piano.ino`](./keypad_piano.ino) — Scans a 4x4 matrix keypad, maps each key to a frequency for two octaves, plays the note on a passive buzzer, and prints the key and frequency to Serial.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-4x4-keypad-buzzer-piano-two-octaves)  
Parts used: [Arduino Nano V3.0 Pre-Soldered](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [4x4 Membrane Matrix Keypad](https://shillehtek.com/products/4x4-membrane-matrix-keypad-16-key-switch-module-for-arduino-diy) · [KY-006 Passive Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
