# ESP32 Reed Switch Relay: Remote Garage Door Control

This project builds an ESP32-based garage door controller that uses a reed switch to detect door position and a relay to trigger the opener. The ESP32 connects to Wi‑Fi and uses a Telegram bot to send real-time door status updates and accept remote /open and /close commands. The code in this folder implements the Wi‑Fi connection, Telegram integration, reed input monitoring, and relay control.
