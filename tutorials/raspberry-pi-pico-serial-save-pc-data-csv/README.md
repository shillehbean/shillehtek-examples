# Raspberry Pi Pico Serial: Save PC Data to CSV

This example shows how to send data from a desktop computer to a Raspberry Pi Pico over a serial connection and save the received values to a CSV file on the Pico. The folder contains a PC-side Python script that streams comma-separated values over a serial port and a MicroPython script for the Pico that reads stdin, splits on commas, and appends each value to data.csv.
