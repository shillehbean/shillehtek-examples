# Micropython examples

- [`pico_save_to_csv.py`](./pico_save_to_csv.py) — Runs on the Pico to read characters from stdin, accumulate them until a comma is seen, and append each completed value as a new line to data.csv.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-serial-save-pc-data-csv)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
