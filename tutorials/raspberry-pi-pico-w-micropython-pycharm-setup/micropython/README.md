# Micropython examples

- [`led_blink.py`](./led_blink.py) — Toggles the Raspberry Pi Pico W onboard LED in a loop with a 0.1 second delay between state changes.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-micropython-pycharm-setup)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
