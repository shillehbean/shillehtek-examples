# Arduino Nano Passive Buzzer: Play Real Songs with tone()

This tutorial shows how to build a simple Arduino Nano music player that uses a KY-006 passive piezo buzzer and the tone() function to play melodies. The code in this folder demonstrates playing the first phrase of "Ode to Joy" using note and duration arrays and tempo-based timing. It runs once at boot and requires the buzzer connected to the specified digital pin.
