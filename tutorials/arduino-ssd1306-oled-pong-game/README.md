# Arduino Uno SSD1306 OLED: Build a Pong Game

This tutorial builds a two-player Pong game on an Arduino Uno using a 0.96" SSD1306 I2C OLED, two potentiometer paddles, and a passive buzzer. The provided Arduino sketch drives the display, reads the paddles, updates ball physics, handles scoring and plays beeps on collisions.
