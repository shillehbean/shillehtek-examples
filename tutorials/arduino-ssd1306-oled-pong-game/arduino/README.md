# Arduino examples

- [`pong.ino`](./pong.ino) — Arduino sketch that implements a two-player Pong game on a 0.96" SSD1306 I2C OLED, reading two potentiometers for paddles and using a buzzer for sound effects.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ssd1306-oled-pong-game)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [SSD1306 0.96" I2C OLED](https://shillehtek.com/products/0-96-i2c-white-oled-display-module-4-pin-ssd1306) · [KY-006 Passive Buzzer](https://shillehtek.com/products/ky-006-passive-piezo-buzzer-alarm-module-for-arduino-projects) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
