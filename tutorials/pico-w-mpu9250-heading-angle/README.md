# Pico W MPU9250: Heading Angle in MicroPython

This tutorial shows how to read magnetometer data from an MPU9250 connected to a Raspberry Pi Pico W and convert it into a stable heading angle and human-readable compass direction. The code examples include a simple low-pass filter function and a MicroPython script that initializes the sensor, calibrates the magnetometer, applies filtering, and maps headings to compass points.
