# Arduino YF-S201 Water Flow Sensor: Measure L/min

This tutorial demonstrates measuring water flow (liters per minute) and accumulating total liters using a YF-S201 flow sensor with an Arduino Nano. The code examples include a basic serial-output flow meter, an LCD totalizer example, and a valve-control sketch to shut off flow after a target volume is reached.
