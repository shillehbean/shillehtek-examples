# Raspberry Pi MPU9250: Read 9-Axis Sensor Data

This tutorial shows how to read 9-axis sensor data (accelerometer, gyroscope, and magnetometer) from an MPU9250 connected to a Raspberry Pi. The code in this folder installs the required system and Python dependencies so you can run the example scripts that read sensor data using the mpu9250-jmdev library.
