# ESP32 + DHT22: Read Temperature and Humidity

This tutorial shows how to read temperature and humidity from a DHT22 sensor using an ESP32 development board. The provided sketch reads humidity and temperature (Celsius and Fahrenheit) from the sensor and prints the values to the Serial Monitor every two seconds.
