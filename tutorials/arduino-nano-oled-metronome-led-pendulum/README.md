# Arduino Nano OLED: LED Pendulum Metronome BPM Display

This project builds an LED pendulum metronome using an Arduino Nano, a 0.96" I2C SSD1306 OLED display, a potentiometer tempo knob, and a passive buzzer for accents. The included Arduino sketch drives eight LEDs as a pendulum, reads tempo from the pot, sounds an accented beat on the buzzer, and shows the current BPM and tempo marking on the OLED.
