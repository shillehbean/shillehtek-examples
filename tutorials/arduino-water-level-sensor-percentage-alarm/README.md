# Arduino Uno Water Level Sensor: LCD % and Full Alarm

This tutorial shows how to build a water level monitor with an Arduino Uno, an analog water level sensor, an I2C LCD, RGB LEDs and a passive buzzer. The included code reads and averages the sensor, maps the value to a percentage, shows the live percentage on the I2C LCD, and triggers LED colors and a buzzer when the tank is nearly full.
