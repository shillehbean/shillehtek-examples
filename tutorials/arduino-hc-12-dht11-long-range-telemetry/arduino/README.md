# Arduino examples

- [`lcd_base_station.ino`](./lcd_base_station.ino) — Arduino base-station sketch that reads 4-byte telemetry packets from an HC-12, displays temperature and humidity on an I2C 16x2 LCD, and sends simple toggle commands when buttons are pressed.
- [`dht11_hc12_node.ino`](./dht11_hc12_node.ino) — Arduino sensor-node sketch that reads temperature and humidity from a DHT11, packs the values into four bytes and sends them over HC-12 every 3 seconds, and responds to incoming command bytes to toggle LEDs.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-hc-12-dht11-long-range-telemetry)
