# Arduino HC-12 + DHT11: Long-Range Telemetry Link

This tutorial shows how to build a long-range telemetry link using HC-12 433MHz transceivers between an Arduino-based sensor node and an I2C LCD base station. The sensor node reads temperature and humidity from a DHT11 and transmits packed telemetry bytes; the base station receives and displays the values and can send simple toggle commands back to the node.
