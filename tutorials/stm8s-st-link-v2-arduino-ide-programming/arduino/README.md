# Arduino examples

- [`stm8s_toggle_ports_blink.ino`](./stm8s_toggle_ports_blink.ino) — Toggles all GPIO ports on an STM8S board in a loop to create a blink/LED pattern using the Sduino core.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/stm8s-st-link-v2-arduino-ide-programming)  
Parts used: [ST-LINK V2 Programmer/Debugger for STM8 & STM32](https://shillehtek.com/products/st-link-v2-stm8-stm32-programmer-downloader)
