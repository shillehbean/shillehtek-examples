# STM8S + ST-Link V2: Program in Arduino IDE

This tutorial shows how to set up the Arduino IDE with the Sduino core and use an ST‑LINK V2 over SWIM to program an STM8S development board. The example code toggles the STM8S GPIO ports to demonstrate uploading and running a simple blink-style sketch.
