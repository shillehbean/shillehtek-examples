# Arduino examples

- [`hcsr04_rgb_distance.ino`](./hcsr04_rgb_distance.ino) — Initializes and sets colors on the HC-SR04 module's built-in RGB LEDs and prepares the trigger/echo pins for distance measurement on an Arduino Uno.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-hcsr04-rgb-distance-leds)
