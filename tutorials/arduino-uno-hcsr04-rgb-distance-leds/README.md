# Arduino Uno HCSR04 RGB: Distance readings with LEDs

This tutorial shows how to wire and use an HC-SR04 ultrasonic distance sensor with a built-in RGB LED module on an Arduino Uno. The example code initializes the sensor's RGB LEDs and reads distance values from the HC-SR04, demonstrating how to control colors and display readings with the module.
