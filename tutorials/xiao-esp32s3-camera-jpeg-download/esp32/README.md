# Esp32 examples

- [`xiao_esp32s3_camera.ino`](./xiao_esp32s3_camera.ino) — Arduino/ESP32 sketch that initializes the XIAO ESP32S3 Sense camera, runs a web server with routes (/ , /snap, /capture, /download) and caches the last captured JPEG in RAM for exact-download.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/xiao-esp32s3-camera-jpeg-download)  
Parts used: [XIAO ESP32S3 Pre-Soldered Microcontroller with WiFi & Bluetooth for Arduino & MicroPython](https://shillehtek.com/products/xiao-seeed-esp32s3-pre-soldered-with-usb-c-cable)
