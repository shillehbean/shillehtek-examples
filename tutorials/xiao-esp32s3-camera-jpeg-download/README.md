# XIAO ESP32S3 Sense Camera: Exact JPEG Capture & Download

This tutorial builds a small web photo app on the XIAO ESP32S3 Sense that captures a fresh JPEG from the onboard camera and lets a browser download the exact same frame. The code initializes the camera robustly, serves a simple web UI, captures images to RAM, and provides routes to view, capture, and download the cached JPEG.
