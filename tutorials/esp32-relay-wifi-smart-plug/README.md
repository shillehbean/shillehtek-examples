# ESP32 Relay: Build a Wi-Fi Smart Plug

This tutorial shows how to build an ESP32-based Wi‑Fi smart plug that controls a relay over the network. The code in this folder is a minimal Arduino-framework sketch that runs on an ESP32 and exposes /on and /off HTTP endpoints to switch a relay pin. Use it as a simple starting point for web UI or MQTT integration.
