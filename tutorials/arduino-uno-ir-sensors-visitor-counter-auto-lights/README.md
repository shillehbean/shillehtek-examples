# Arduino Uno IR Sensors: Bidirectional Visitor Counter

This project builds an Arduino Uno bidirectional visitor counter using two IR break-beam sensors, an I2C LCD1602 display, and a relay to automatically switch lights based on occupancy. The provided sketch monitors the two sensors to detect entry and exit, updates in/out and inside counts on the LCD, and drives the relay while anyone is present.
