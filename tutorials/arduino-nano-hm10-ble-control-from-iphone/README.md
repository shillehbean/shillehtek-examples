# Arduino Nano HM-10 BLE: Control from iPhone

This tutorial shows how to control an Arduino Nano from an iPhone using an HM-10 BLE module. The code forwards serial data between the Nano and the BLE module and toggles an LED based on simple '1'/'0' commands received over BLE.
