# ESP32 MPU6050: 3D Orientation Animation in Processing

This tutorial shows how to stream orientation data from an MPU6050 IMU connected to an ESP32 and render a real-time 3D orientation animation in Processing (using Toxiclibs). The code in this folder includes the Arduino/ESP sketch to run the MPU6050 DMP and the Processing sketch that visualizes the sensor orientation.
