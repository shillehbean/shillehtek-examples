# Arduino examples

- [`mpu6050_dmp_arduino_demo.ino`](./mpu6050_dmp_arduino_demo.ino) — Arduino/ESP sketch demonstrating use of the I2Cdev library and MPU6050 DMP (MotionApps v2.0) to read orientation, quaternions and Euler angles from the sensor.
