# Arduino CapacitiveSensor: Touch Toggle Lamp Switch

This tutorial builds a simple capacitive touch toggle using an Arduino, a coin electrode, and a 1 MΩ resistor to control an LED or a relay. The code reads a capacitive sensor, auto-calibrates a baseline, applies debounce, and toggles the output on touch events. It also slowly tracks baseline drift and prints sensor readings over serial for debugging.
