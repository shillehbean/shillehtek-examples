# Digispark ATtiny85 Thermistor: Phone USB Thermometer Readout

This example shows how to build a simple USB thermometer using a Digispark (ATtiny85) and a 10K NTC thermistor. The Arduino sketch reads the thermistor on pin P2 (A1), converts the ADC value to temperature using the B-parameter Steinhart formula, and streams readings over USB CDC to a connected host (phone or PC). The folder contains the wiring note and the Digispark Arduino sketch used in the tutorial.
