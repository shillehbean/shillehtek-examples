# Arduino examples

- [`digispark_thermistor.ino`](./digispark_thermistor.ino) — Arduino sketch for the Digispark ATtiny85 that reads a 10K NTC thermistor on A1 (physical P2), calculates temperature in Celsius using the B-coefficient (Steinhart formula), and sends readings over USB CDC when the host polls.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/digispark-attiny85-thermistor-phone-thermometer-readout)  
Parts used: [ATtiny85 USB Development Board (Digispark) for Arduino Pre-Soldered](https://shillehtek.com/products/attiny85-digispark-usb-arduino-development-board) · [10K NTC Thermistor Temperature Sensor (MF52-103)](https://shillehtek.com/products/10k-ntc-thermistor-temperature-sensor-mf52-103) · [820PCS 1/4W 1% Metal Film Resistors Kit, 41 Values, 20pcs Each (Plastic Box)](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box)
