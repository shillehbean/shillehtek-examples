# Arduino BMP180: Real-Time Dashboard with Node-RED

This tutorial shows how to build a real-time dashboard that displays temperature and pressure from a BMP180 sensor using an Arduino and Node-RED. The included code reads the BMP180, prints JSON over the serial port, and provides a small Node-RED function to extract the pressure value for dashboard widgets.
