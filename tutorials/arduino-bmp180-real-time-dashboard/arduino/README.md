# Arduino examples

- [`bmp180_serial.ino`](./bmp180_serial.ino) — Reads temperature and pressure from an Adafruit BMP085/BMP180 sensor and prints JSON-formatted readings over Serial every 2 seconds.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-bmp180-real-time-dashboard)
