# Arduino Nano DS3231 RTC: Schedule Servo Pet Feeder

This project builds an Arduino Nano pet feeder that uses a DS3231 RTC to dispense food on a schedule, with a servo motor to actuate the gate, a buzzer for alerts, and a pushbutton for manual override. The code in this folder reads time from the DS3231 and triggers the servo and buzzer at configured feed times or when the button is pressed.
