# Arduino examples

- [`ds3231_servo_feeder.ino`](./ds3231_servo_feeder.ino) — Reads time from a DS3231 RTC and dispenses food by moving a servo and sounding a buzzer at configured hours; also allows manual dispensing via a button.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ds3231-servo-pet-feeder)
