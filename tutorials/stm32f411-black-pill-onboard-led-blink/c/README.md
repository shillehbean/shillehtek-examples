# C examples

- [`gpio_init.c`](./gpio_init.c) — Enable the GPIOC clock and configure pin PC13 as a push-pull output with no pull-up/pull-down and low speed.
- [`blink_loop.c`](./blink_loop.c) — Main loop that blinks the onboard LED by setting and resetting PC13 with 1 second delays.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/stm32f411-black-pill-onboard-led-blink)  
Parts used: [STM32F411CEU6 Pre-Soldered Black Pill ARM Development Board for Arduino](https://shillehtek.com/products/shillehtek-pre-soldered-authentic-stm32f411ceu6)
