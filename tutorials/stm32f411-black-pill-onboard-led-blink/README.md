# STM32F411 Black Pill Onboard LED: Blink with HAL

This tutorial shows how to blink the onboard LED (PC13) on an STM32F411 Black Pill using STM32CubeIDE and the HAL library. The code in this folder initializes the GPIO for PC13 and implements a simple main loop that toggles the pin with 1 second delays to verify flashing and the toolchain.

**Read the full tutorial:** [STM32F411 Black Pill Onboard LED: Blink with HAL](https://shillehtek.com/blogs/news/stm32f411-black-pill-onboard-led-blink)  
**Parts used:** [STM32F411CEU6 Pre-Soldered Black Pill ARM Development Board for Arduino](https://shillehtek.com/products/shillehtek-pre-soldered-authentic-stm32f411ceu6)
