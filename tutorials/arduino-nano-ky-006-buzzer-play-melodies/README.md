# Arduino Nano KY-006 Buzzer: Play Melodies with tone()

This tutorial shows how to drive a KY-006 passive piezo buzzer from an Arduino Nano using the tone() function to play melodies. The code examples include a simple single-tone sketch and a short melody (the opening of "Twinkle Twinkle") implemented with note and duration arrays.
