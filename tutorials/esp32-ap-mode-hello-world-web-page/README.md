# ESP32 AP Mode: Host a Hello World Web Page

This tutorial shows how to configure an ESP32 as a Wi‑Fi Access Point and host a simple "Hello World" web page using the Arduino framework. The code sample starts the ESP32 in AP mode, runs a basic HTTP server, and handles incoming client connections to serve the web page for testing and basic IoT demos.
