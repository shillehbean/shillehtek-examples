# Raspberry Pi Pico 2W E-Paper HAT: Wi-Fi Name Badge

This tutorial builds a Wi‑Fi name badge using a Raspberry Pi Pico W and a 2.13" black & white SPI e‑paper HAT. The code here shows the wiring and a MicroPython example that initializes the display, draws name/title/message/footer text, updates the e‑paper, and puts the display to sleep to minimize idle power.
