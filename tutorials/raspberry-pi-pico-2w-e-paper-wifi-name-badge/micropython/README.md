# Micropython examples

- [`main.py`](./main.py) — MicroPython script for the Pico W that initializes the 2.13" e-paper HAT, draws header, message, and footer text for a name badge, updates the display, and puts the display to sleep to save power.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-2w-e-paper-wifi-name-badge)
