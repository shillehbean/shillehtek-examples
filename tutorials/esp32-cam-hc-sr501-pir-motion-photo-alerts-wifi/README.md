# ESP32-CAM HC-SR501 PIR: Motion Photo Alerts via Wi-Fi

This tutorial builds an ESP32-CAM doorbell using an HC-SR501 PIR motion sensor to capture photos on motion and send alerts over Wi‑Fi (email). The code here is an example Arduino-style ESP32 sketch that monitors the PIR pin, captures a camera frame with esp_camera, and demonstrates sending the image via SMTP using ESP_Mail_Client.
