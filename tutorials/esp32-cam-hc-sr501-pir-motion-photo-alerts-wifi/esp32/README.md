# Esp32 examples

- [`esp32cam_pir_email.ino`](./esp32cam_pir_email.ino) — Monitors a PIR sensor and, on motion, captures a photo with esp_camera and sends it via SMTP using ESP_Mail_Client (camera init and SMTP attachment details are left as placeholders).
