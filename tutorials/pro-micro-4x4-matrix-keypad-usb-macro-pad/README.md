# Pro Micro 4x4 Matrix Keypad: USB Macro Pad Build

This project builds a USB macro pad using a Pro Micro (ATmega32U4) and a 4x4 membrane matrix keypad. The included sketch reads the keypad and sends USB keyboard shortcut macros to the host (e.g., for OBS or workflow hotkeys).
