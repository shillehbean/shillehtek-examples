# Arduino examples

- [`pro_micro_4x4_macro_pad.ino`](./pro_micro_4x4_macro_pad.ino) — Reads a 4x4 matrix keypad and sends USB keyboard macros (pressing Ctrl+Alt+Shift plus a function or other key) via the Pro Micro's USB HID interface.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/pro-micro-4x4-matrix-keypad-usb-macro-pad)  
Parts used: [Pro Micro ATmega32U4 (Pre-Soldered)](https://shillehtek.com/products/pro-micro-atmega32u4-5v-16mhz-presoldered-micro-usb) · [4x4 Membrane Matrix Keypad](https://shillehtek.com/products/4x4-membrane-matrix-keypad-16-key-switch-module-for-arduino-diy)
