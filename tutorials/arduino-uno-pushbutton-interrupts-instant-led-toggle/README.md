# Arduino Uno Pushbutton Interrupts: Instant LED Toggle

This example demonstrates using an external interrupt on an Arduino Uno to toggle an LED instantly when a pushbutton is pressed, even while the main loop is blocked. It includes simple debounce logic and a safely shared press counter updated inside an ISR and read atomically from loop().
