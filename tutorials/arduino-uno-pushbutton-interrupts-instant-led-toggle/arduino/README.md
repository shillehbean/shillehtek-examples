# Arduino examples

- [`pushbutton_interrupt_toggle.ino`](./pushbutton_interrupt_toggle.ino) — Interrupt-driven pushbutton handler that debounces presses, toggles an LED instantly, and counts presses while the main loop performs long blocking work.
