# Arduino A4988: Control a NEMA 17 Stepper Motor

This tutorial shows how to wire an Arduino Nano to an A4988 stepper driver to control a NEMA 17 stepper motor using basic STEP and DIR signals. The code in this folder provides a minimal Arduino sketch that pulses the STEP pin to rotate the motor one full revolution forward and then one full revolution in reverse.
