# Arduino examples

- [`a4988_nema17_stepper.ino`](./a4988_nema17_stepper.ino) — Simple Arduino sketch to drive a NEMA 17 stepper via an A4988 using STEP and DIR pins; it rotates one full revolution forward then one full revolution in reverse.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-a4988-nema17-stepper-control)
