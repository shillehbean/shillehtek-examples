# Arduino Laser Diode: Build a Tripwire Alarm

This tutorial shows how to build a simple laser tripwire alarm using an Arduino, a red laser diode, an LDR (light-dependent resistor), and a piezo buzzer. The included code powers the laser, continuously reads the LDR value, and triggers the buzzer when the beam is interrupted.
