# Esp32 examples

- [`blink_led.ino`](./blink_led.ino) — Blink the Wemos D1 Mini built-in LED with a 300 ms on/off cycle (D4 LED is active LOW).
- [`print_wifi_ip.ino`](./print_wifi_ip.ino) — Connect the Wemos D1 Mini to a Wi‑Fi network and print its local IP address to the Serial console.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/wemos-d1-mini-esp8266-blink-led-wifi-ip)  
Parts used: [ESP8266 D1 Mini V3 4MB Pre-Soldered Dev Board for Arduino](https://shillehtek.com/products/esp8266-d1-mini-v3-4mb-dev-board-presoldered)
