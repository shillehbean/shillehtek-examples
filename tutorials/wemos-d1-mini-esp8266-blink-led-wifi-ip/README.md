# Wemos D1 Mini ESP8266: Blink LED and Print Wi-Fi IP

This tutorial shows how to set up a Wemos D1 Mini (ESP8266) with the Arduino IDE, flash a blinking onboard LED, and connect the board to Wi‑Fi to print its IP address over Serial. The folder contains the Arduino sketches used for the examples and a text file with the Boards Manager URL needed to add ESP8266 support to the Arduino IDE.
