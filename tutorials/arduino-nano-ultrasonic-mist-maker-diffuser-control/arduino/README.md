# Arduino examples

- [`led_rainbow.ino`](./led_rainbow.ino) — Controls a single WS2812B LED with a cycling hue and sets the relay control pin at startup.
- [`soil_moisture_automist.ino`](./soil_moisture_automist.ino) — Reads a capacitive soil moisture sensor and toggles a relay to run the mist maker on a timed cycle when the soil is dry.
