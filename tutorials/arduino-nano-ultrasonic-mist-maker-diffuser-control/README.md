# Arduino Nano Ultrasonic Mist Maker: DIY Diffuser Control

This tutorial shows how to build an Arduino Nano driven ultrasonic mist maker diffuser with relay control, WS2812B lighting, and an optional soil moisture-based automatic misting mode. The code in this folder contains example Arduino sketches: one to run an RGB LED animation and control the relay, and one to perform soil-moisture-based misting automation. Wiring notes are also included.
