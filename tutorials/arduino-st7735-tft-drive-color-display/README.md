# Arduino ST7735 TFT: Drive a Color Display via SPI

This tutorial shows how to drive a 1.8-inch ST7735 128x160 color TFT from an Arduino-compatible board using the Adafruit GFX/ST7735 libraries over SPI. The code in this folder includes a demo sketch that initializes the display, prints static text, and updates a numeric counter, plus a short snippet showing alternative init options for different ST7735 module variants.
