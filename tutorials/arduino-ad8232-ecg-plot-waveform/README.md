# Arduino AD8232 ECG Module: Plot a Live ECG Waveform

This example reads the AD8232 ECG module with an Arduino Nano and streams the raw ECG signal to the Serial Monitor/Serial Plotter. The sketch prints ADC values from the sensor and emits a marker when the AD8232 lead-off detection pins indicate a disconnected electrode. Use the Arduino Serial Plotter at 9600 baud to visualize the live waveform.
