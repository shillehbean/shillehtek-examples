# ESP32 Timer Wake-Up: Deep Sleep for Battery Life

This example shows how to use the ESP32 deep sleep timer to periodically wake, perform brief work, and return to deep sleep to extend battery life. The sketch logs a persistent boot count, prints the wake reason, blinks the onboard LED, then configures a timer wakeup and goes back to sleep.
