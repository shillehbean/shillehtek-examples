# Raspberry Pi Pico W Gmail: Send Email in MicroPython

This tutorial demonstrates how to send email from a Raspberry Pi Pico W using MicroPython and Gmail's SMTP server with an app password. The code connects the Pico W to Wi-Fi and uses the umail library to authenticate and send a message.
