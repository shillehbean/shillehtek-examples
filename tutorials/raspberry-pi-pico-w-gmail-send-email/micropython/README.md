# Micropython examples

- [`pico_w_gmail.py`](./pico_w_gmail.py) — Connects the Raspberry Pi Pico W to Wi‑Fi and sends an email via Gmail using the umail library (requires filling in your Gmail address, app password, and Wi‑Fi credentials).

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/raspberry-pi-pico-w-gmail-send-email)  
Parts used: [Raspberry Pi Pico 2W with Pre-Soldered Headers](https://shillehtek.com/products/raspberry-pi-pico-2w-presoldered-headers)
