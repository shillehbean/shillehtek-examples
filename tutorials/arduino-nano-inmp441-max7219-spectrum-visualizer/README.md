# Arduino Nano INMP441: LED Spectrum Visualizer

This example builds an audio spectrum visualizer using an Arduino Nano and a MAX7219 32x8 LED matrix. The sketch samples a microphone input, computes an FFT, and draws vertical frequency-band bars on the LED matrix. Use this code as the starting point for visualizing audio on a MAX7219 matrix with an Arduino.
