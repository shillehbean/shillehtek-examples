# Esp32 examples

- [`esp32_oled_crypto_ticker.ino`](./esp32_oled_crypto_ticker.ino) — Connects the ESP32 to Wi-Fi, fetches cryptocurrency prices and 24h change data from the CoinGecko API over HTTPS, parses the JSON response, and prepares values for display on an SSD1306 OLED.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-oled-live-crypto-ticker)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [ESP8266 D1 Mini](https://shillehtek.com/products/esp8266-d1-mini-v3-4mb-dev-board-presoldered) · [0.96" I2C OLED (SSD1306, blue)](https://shillehtek.com/products/0-96-i2c-blue-oled-display-module-4-pin-ssd1306) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
