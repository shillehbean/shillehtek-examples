# ESP32 OLED (SSD1306): Live Crypto Price Ticker

This project builds an ESP32-based SSD1306 OLED cryptocurrency price ticker that pulls live price and 24-hour change data from the CoinGecko API over HTTPS and cycles through multiple coins on the display. The code here connects the ESP32 to Wi-Fi, requests and parses CoinGecko JSON, and prepares values to render on the OLED display.
