# Heltec V3 LoRa + GT-U7 GPS: Send Coordinates via Meshtastic

This tutorial shows how to connect a GT-U7 (NEO-6M) GPS module to a Heltec V3 LoRa tracker and send GPS coordinates over a Meshtastic LoRa mesh to a base station. The code folder includes a Python receiver script used to connect to a Meshtastic serial interface and format/display incoming GPS position packets for logging or further processing.
