# Arduino Uno VL53L0X: Show Distance on SSD1306 OLED

This tutorial builds an Arduino Uno distance meter using a VL53L0X time-of-flight sensor and an SSD1306 0.96" I2C OLED to show real-time distance in millimeters. The code in this folder is an Arduino sketch that reads the VL53L0X, prints values to Serial, and updates the OLED display.
