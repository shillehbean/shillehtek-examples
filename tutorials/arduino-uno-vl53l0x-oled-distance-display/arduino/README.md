# Arduino examples

- [`vl53l0x_oled_distance.ino`](./vl53l0x_oled_distance.ino) — Arduino sketch that reads distance from a VL53L0X ToF sensor, prints the reading to Serial, and displays the distance on an SSD1306 OLED.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-uno-vl53l0x-oled-distance-display)  
Parts used: [VL53L0X Pre-Soldered Laser Ranging ToF Sensor Module](https://shillehtek.com/products/gy-vl53l0xv2-laser-ranging-tof-sensor-module) · [SSD1306 0.96" I2C OLED Display Module](https://shillehtek.com/products/0-96-i2c-blue-oled-display-module-4-pin-ssd1306) · [120pcs Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
