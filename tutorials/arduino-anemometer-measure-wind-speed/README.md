# Arduino Analog Anemometer: Live Wind Speed Readings

This tutorial shows how to build an Arduino-based analog anemometer that powers the sensor from VIN and reads a 0–5V output to produce live wind speed readings in the Serial Monitor. The code in this folder contains the wiring note and an Arduino sketch that converts the sensor's analog voltage into a wind speed value and prints it via Serial.
