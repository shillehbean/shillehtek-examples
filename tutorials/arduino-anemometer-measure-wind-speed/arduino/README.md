# Arduino examples

- [`analog_anemometer.ino`](./analog_anemometer.ino) — Reads analog voltage from the anemometer on A0, converts it to wind speed using calibrated min/max voltages, and prints voltage and wind speed to the Serial Monitor every second.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-anemometer-measure-wind-speed)  
Parts used: [Wind Speed Sensor Anemometer with 0-5V Analog Output](https://shillehtek.com/products/anemometer-wind-speed-0-5v-analog-output) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [BME280 Pre-Soldered Temperature, Pressure & Humidity Sensor for Arduino & Raspberry Pi](https://shillehtek.com/products/bme280-pre-soldered-atmospheric-temperature-pressure-and-humidity-sensor)
