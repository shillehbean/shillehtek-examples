# Arduino ADXL345: Stream 3-Axis Acceleration Data

This tutorial wires an Arduino Nano to an ADXL345 3-axis accelerometer and streams live X/Y/Z acceleration values over the serial port for motion and tilt testing. The code in this folder reads acceleration from the ADXL345 using the Adafruit ADXL345 library and prints the values to Serial every 200 ms.
