# XIAO RP2040 + BME280: Read I2C Sensor Data

This tutorial shows how to connect a BME280 temperature/pressure/humidity sensor to a Seeed Studio XIAO RP2040 over I2C and read sensor values. The code in this folder demonstrates initializing the I2C bus, creating a BME280 object, and printing the sensor readings in a loop.
