# Micropython examples

- [`bme280_read.py`](./bme280_read.py) — Initializes I2C on the XIAO RP2040, creates a BME280 sensor object, and continuously prints temperature, pressure, and humidity readings.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/xiao-rp2040-bme280-read-i2c-sensor-data)
