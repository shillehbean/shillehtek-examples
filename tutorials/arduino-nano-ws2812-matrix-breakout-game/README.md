# Arduino Nano WS2812 Matrix: Build Breakout Game

This tutorial builds a two-button Breakout-style game using an Arduino Nano and an 8x8 WS2812 LED matrix, including lives and sound via a passive buzzer. The code provided runs the game loop, draws the LEDs with FastLED, handles paddle and ball physics, brick state, and plays simple beeps for events.
