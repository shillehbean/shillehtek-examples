# Bash examples

- [`create_react_app.sh`](./create_react_app.sh) — Create a new React app and change into the project directory.
- [`install_frontend_deps.sh`](./install_frontend_deps.sh) — Install frontend development and runtime dependencies including reCAPTCHA helper, axios, and toast notifications.
- [`setup_backend.sh`](./setup_backend.sh) — Create a backend folder, initialize npm, and install backend dependencies and dev tools like nodemon.
