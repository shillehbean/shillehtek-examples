# Arduino examples

- [`rfid_rc522_read_uid.ino`](./rfid_rc522_read_uid.ino) — Initializes the RC522 via SPI, detects MIFARE cards/key fobs, and prints their UID in hexadecimal to the Serial Monitor.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-rc522-read-uid)  
Parts used: [RC522 RFID Reader Writer Module 13.56MHz SPI Kit for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/rc522-rfid-reader-writer-module-13-56mhz-spi-kit-for-arduino) · [13.56MHz RFID Smart Card with S50 1K Chip, ISO14443A Access Control](https://shillehtek.com/products/13-56mhz-rfid-smart-card-s50-1k-chip-iso14443a-access-control) · [13.56MHz RFID Key Fob Tag with S50 IC ISO14443A Access Control Token](https://shillehtek.com/products/13-56mhz-rfid-key-fob-tag-ic-s50-token-iso14443a-access-control) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [1-Channel 5V Relay Board for Arduino & Raspberry Pi](https://shillehtek.com/products/1-channel-5v-relay-module) · [Micro SD TF Card Adapter Reader Module SPI Interface for Arduino](https://shillehtek.com/products/micro-sd-tf-card-adapter-reader-module-spi-interface-for-arduino) · [SSD1306 0.96" Blue I2C OLED Display Module 4-Pin for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/0-96-i2c-blue-oled-display-module-4-pin-ssd1306)
