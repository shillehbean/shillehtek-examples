# ESP32 WebServer Relay Module: Local Phone Control

This project creates a simple web server on an ESP32 to control an LED or a 1-channel 5V relay module from any phone on the same 2.4 GHz Wi‑Fi network. The provided sketch serves a small web page with ON/OFF buttons and toggles a GPIO pin wired to the LED or relay. Flash the sketch to an ESP32 dev board and connect the relay IN pin to the configured GPIO.
