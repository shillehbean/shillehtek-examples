# Esp32 examples

- [`esp32_webserver_relay.ino`](./esp32_webserver_relay.ino) — ESP32 Arduino-framework sketch that connects to Wi‑Fi, hosts an HTTP server, serves a simple control page, and toggles a GPIO to drive an LED or relay.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-webserver-relay-module-local-phone-control)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [Uno Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
