# Arduino Nano DFPlayer Mini: OLED MP3 Player Build

This project builds an Arduino Nano-based MP3 player using a DFPlayer Mini, a 1.3" SH1106 I2C OLED for a simple menu, and push-button controls. The code initializes the display, input buttons, RGB LEDs, and the DFPlayer, and restores saved settings (volume, EQ, and last-played track) from EEPROM.
