# Arduino Uno 7-Segment Display: Build a Digital Dice

This tutorial builds a digital dice using an Arduino Uno, a single 7-segment display, and a push button. The included Arduino sketch drives the segments, seeds the RNG from a floating analog pin, and produces an animated roll when the button is pressed.
