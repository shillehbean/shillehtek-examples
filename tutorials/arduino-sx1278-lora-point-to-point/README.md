# Arduino SX1278 LoRa: Build 433MHz Point-to-Point Link

This tutorial shows how to build a 433 MHz point-to-point LoRa link using an Arduino Nano and an RA-02 (SX1278) module. The repository contains an example LoRa sender sketch and a LoRa receiver sketch that displays received messages and signal info on an SSD1306 OLED.
