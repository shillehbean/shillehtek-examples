# Arduino EMG Muscle Sensor: Control a Servo Claw

This tutorial shows how to build an Arduino Nano EMG muscle sensor that drives a servo claw when you flex, demonstrating a simple biofeedback/prosthetic-style interaction. The code in this folder reads the EMG analog input, calibrates a baseline, prints readings to Serial, and moves a servo between open and closed positions based on a threshold.
