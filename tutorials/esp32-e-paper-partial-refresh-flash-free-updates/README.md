# ESP32 2.9-inch E-Paper: Flash-Free Partial Refresh

Builds an ESP32 with a 2.9-inch e-paper display using GxEPD2 and U8g2 to enable fast, flash-free partial updates. The example initializes the display, renders a static header with a full refresh, and then updates an uptime value in a partial window every second.
