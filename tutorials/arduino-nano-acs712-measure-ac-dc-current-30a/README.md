# Arduino Nano + ACS712: Measure AC/DC Current Up to 30A

This tutorial shows how to build a current meter using an Arduino Nano and an ACS712 current sensor to measure AC and DC currents up to 30A. The code examples include a simple DC reading sketch and an RMS sampling function for AC measurements, plus a wiring reference for connecting the sensor and load.
