# Arduino examples

- [`acs712_basic.ino`](./acs712_basic.ino) — Simple Arduino sketch that reads the ACS712 analog output, applies zero-offset calibration and sensitivity to compute current, and prints the result over Serial every 500 ms.
- [`acs712_rms_function.ino`](./acs712_rms_function.ino) — Function to sample the ACS712 rapidly over a time window and return the RMS current (useful for AC measurements).
