# Raspberry Pi Pico W USB Serial: C++ Hello World

This example builds and flashes a simple C++ "Hello, World!" program for the Raspberry Pi Pico W that prints over USB serial. The folder contains the CMake project file and main.cpp, plus small helper shell scripts for installing dependencies, fetching the Pico SDK, preparing the build, and flashing the generated UF2.
