# Arduino WS2812B + KY-037: Music-Reactive LED Effects

This project builds a music-reactive WS2812B LED strip driven by an Arduino Nano and a KY-037 sound sensor. The code folder contains a main FastLED sketch and separate effect routines (VU meter, beat pulse, and chase) that read the KY-037 analog output to produce audio-reactive animations.
