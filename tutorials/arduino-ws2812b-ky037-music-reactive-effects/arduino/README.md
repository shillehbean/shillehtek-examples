# Arduino examples

- [`music_reactive_main.ino`](./music_reactive_main.ino) — Main Arduino sketch that initializes FastLED and runs a simple rainbow sweep across the WS2812B strip.
- [`vu_meter.ino`](./vu_meter.ino) — VU meter function that reads the KY-037 analog output (A0) and lights LEDs up to the measured peak using a rainbow ramp.
- [`beat_pulse.ino`](./beat_pulse.ino) — Beat pulse function that captures audio peaks from A0, maps peak amplitude to brightness, fills the strip with color, and applies a decay.
- [`chase_effect.ino`](./chase_effect.ino) — Chase effect function that advances a colored head along the strip while fading the tail for a moving-trail animation.
