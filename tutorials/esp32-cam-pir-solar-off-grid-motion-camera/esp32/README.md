# Esp32 examples

- [`esp32cam_pir_telegram.ino`](./esp32cam_pir_telegram.ino) — Initializes the ESP32-CAM camera, connects to WiFi, captures a photo and POSTS it to Telegram, then configures an RTC GPIO wakeup from a PIR sensor and enters deep sleep.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-cam-pir-solar-off-grid-motion-camera)
