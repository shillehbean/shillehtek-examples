# ESP32 Servo: Control LED brightness by web sliders

This tutorial builds an ESP32-powered web page with live sliders to dim an LED using PWM and to set a servo angle from a phone or browser. The code runs a simple HTTP server on the ESP32, serves the slider UI, and updates the LED and servo in response to slider changes.
