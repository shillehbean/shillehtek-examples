# Esp32 examples

- [`esp32_servo_led_web.ino`](./esp32_servo_led_web.ino) — Runs a Wi-Fi web server on an ESP32 that serves an HTML page with sliders and handles requests to update LED PWM brightness and a servo angle.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/esp32-servo-web-sliders-led-control)  
Parts used: [ESP32 38-Pin Dev Board (CP2102, USB-C)](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb) · [MG995 Metal Gear Servo](https://shillehtek.com/products/mg995-metal-gear-servo-motor-12kg-high-torque-180-degree-diy) · [MB102 Breadboard Power Supply](https://shillehtek.com/products/shillehtek-universal-power-supply-module) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
