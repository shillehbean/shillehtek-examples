# Raspberry Pi Pico W BME280: Send data to Blynk

This tutorial shows how to read temperature, pressure and humidity from a BME280 on a Raspberry Pi Pico W and send the data to Blynk. The code in this folder connects the Pico W to Wi‑Fi, initializes Blynk, reads the BME280 over I2C, and prints sensor values to the console (and can be extended to push readings to Blynk).
