# Arduino Nano SG92R Servo: Smooth 0-180 Sweep

This tutorial shows how to connect an SG92R 9g micro servo to an Arduino Nano and perform a smooth 0°–180° sweep. The code provided uses the Arduino Servo library to incrementally move the servo back and forth with a small delay for smooth motion. Wiring guidance in the original post covers power, ground, and signal connections for reliable operation.
