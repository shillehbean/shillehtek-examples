# Raspberry Pi Pico W + IFTTT: Log data to Google Sheets

This tutorial shows how to use a Raspberry Pi Pico W with a BME280 sensor to send temperature, pressure, and humidity readings to IFTTT so they can be logged into Google Sheets. The code in this folder connects the Pico W to Wi‑Fi, reads the BME280 over I2C, and posts the sensor values to an IFTTT Webhook event.
