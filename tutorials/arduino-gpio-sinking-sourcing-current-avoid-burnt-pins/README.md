# Arduino GPIO Sinking vs Sourcing Current: Avoid Burnt Pins

This tutorial demonstrates the difference between Arduino GPIO sinking and sourcing using simple LED wiring examples and safe current-limiting practices. The code in this folder shows how to drive an LED from an Arduino pin both as a source and as a sink, and includes notes on using a transistor as a low-side switch so you don't exceed pin current limits.
