# Node-RED + Telegram: Instant Sensor Status

This example integrates a BMP180 temperature & pressure sensor with Node-RED and Telegram so you can request sensor status and receive real-time updates on your phone. The code in this folder contains the Node-RED function node scripts used to store incoming sensor readings and respond to the Telegram "status" command. Sensitive items (like the bot token) and sample message outputs are noted but must not be committed to a public repo.
