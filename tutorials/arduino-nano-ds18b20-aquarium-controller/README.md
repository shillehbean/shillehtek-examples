# Arduino Nano DS18B20: Automated Aquarium Control

This project builds an Arduino Nano aquarium controller that monitors water temperature with a DS18B20, keeps time with a DS3231 RTC, drives heater and light relays, and displays status on an SSD1306 OLED. The code implements temperature-based heater control, scheduled lighting, and a simple OLED status readout.
