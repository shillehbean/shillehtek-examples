# Arduino examples

- [`aquarium_controller.ino`](./aquarium_controller.ino) — Reads temperature from a DS18B20 and current time from a DS3231, controls heater and light relays based on temperature and a daily schedule, and updates an SSD1306 OLED display with status.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-nano-ds18b20-aquarium-controller)  
Parts used: [DS18B20 Waterproof Digital Temperature Sensor Probe 1M for Arduino & Raspberry Pi](https://shillehtek.com/products/ds18b20-waterproof-digital-temp-sensor-probe-1m-for-arduino-pi) · [DS3231 AT24C32 Precision RTC I2C Module with CR2032 Battery](https://shillehtek.com/products/ds3231-at24c32-iic-module-precision-rtc-module-with-cr2032-battery) · [2-Channel 5V Relay Module for Arduino & Raspberry Pi](https://shillehtek.com/products/2-channel-5v-relay-module) · [SSD1306 0.96" Blue I2C OLED Display Module 4-Pin for Arduino, Raspberry Pi & ESP32](https://shillehtek.com/products/0-96-i2c-blue-oled-display-module-4-pin-ssd1306) · [Arduino Nano V3.0 Pre-Soldered CH340G ATmega328P](https://shillehtek.com/products/arduino-nano-v3-presoldered-ch340g-atmega328p) · [120pcs 20cm Dupont Jumper Wires for Arduino & Raspberry Pi](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire) · [Micro SD TF Card Adapter Reader Module SPI Interface for Arduino](https://shillehtek.com/products/micro-sd-tf-card-adapter-reader-module-spi-interface-for-arduino) · [ESP32 Dev Board 4MB CP2102 USB-C Pre-Soldered 38-Pin](https://shillehtek.com/products/esp32-dev-board-cp2102-type-c-4mb)
