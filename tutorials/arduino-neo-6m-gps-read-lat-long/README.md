# Arduino NEO-6M GPS: Read Lat/Long in Serial

This tutorial shows how to build an Arduino Nano + NEO-6M GPS reader that streams live latitude, longitude, satellite count, and UTC time over the serial connection. The included code reads NMEA data from the GPS module using SoftwareSerial and TinyGPS++ and prints parsed location and time to the Serial monitor for mapping or logging.
