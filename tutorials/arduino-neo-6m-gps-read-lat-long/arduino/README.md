# Arduino examples

- [`neo6m_gps_reader.ino`](./neo6m_gps_reader.ino) — Reads NMEA data from a NEO-6M GPS via SoftwareSerial, parses it with TinyGPS++, and prints latitude, longitude, satellite count, and UTC time to the Serial monitor.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-neo-6m-gps-read-lat-long)
