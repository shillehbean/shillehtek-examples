# Arduino IR Receiver: Decode Remote and Toggle Loads

This tutorial shows how to use an IR receiver with an Arduino to decode remote button presses and use them to toggle outputs such as LEDs or a relay. The included code examples first decode and print the remote command values to the serial console, and then use learned button codes to toggle two digital outputs while ignoring repeat frames.
