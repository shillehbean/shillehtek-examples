# Arduino examples

- [`ir_decode_serial.ino`](./ir_decode_serial.ino) — Initial sketch that initializes an IR receiver on pin D3 and prints decoded remote button command values to the serial console.
- [`ir_toggle_outputs.ino`](./ir_toggle_outputs.ino) — Sketch that listens for two specific IR button codes and toggles two digital outputs (pins 8 and 9), ignoring NEC repeat frames so one press equals one toggle.

Full walkthrough: [tutorial](https://shillehtek.com/blogs/news/arduino-ir-receiver-toggle-leds-relay)  
Parts used: [Arduino Uno R3 Super Starter Kit](https://shillehtek.com/products/arduino-uno-r3-starter-kit) · [Resistor Kit](https://shillehtek.com/products/820pcs-1-4w-1-41-kinds-each-value-20pcs-metal-film-resistors-kit-plastic-box) · [1-Channel 5V Relay Module](https://shillehtek.com/products/1-channel-5v-relay-module) · [400-Point Breadboard](https://shillehtek.com/products/shillehtek-400-point-breadboard) · [Dupont Jumper Wires](https://shillehtek.com/products/shillehtek-120pcs-multicolored-dupont-wire)
