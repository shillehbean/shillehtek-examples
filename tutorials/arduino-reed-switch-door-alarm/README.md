# Arduino Reed Switch: Build a Door Alarm

This project builds a simple door alarm using an Arduino Nano, a normally-open reed switch magnetic sensor, and a passive piezo buzzer. When the magnet is away (door open) the Arduino detects the reed switch and sounds the buzzer. The code and wiring notes in this folder provide the sketch and connections needed to reproduce the tutorial example.
