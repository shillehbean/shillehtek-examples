# ESP32 ILI9341 TFT Touchscreen: Show Text and Touch

This tutorial builds an ESP32 project using a 2.8" ILI9341 SPI TFT with an XPT2046 resistive touchscreen. The code initializes the display and touch controller and shows touch coordinates and pressure on both the TFT and the serial console.
