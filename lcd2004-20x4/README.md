# LCD2004 20x4 Character LCD Display with Blue Backlight for Arduino, Raspberry Pi & ESP32

The LCD2004 is a 20x4 HD44780-compatible character LCD with a blue backlight. Developers can use it to display status, menus, telemetry, or simple user interfaces from Arduino, Raspberry Pi, ESP32, or MicroPython projects.
