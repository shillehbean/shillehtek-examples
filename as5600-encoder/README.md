# AS5600 Pre-Soldered Magnetic Rotary Encoder Module

The AS5600 is a contactless magnetic rotary position sensor that reports a 12-bit absolute angle (4096 steps/turn) over I2C. Developers can use this pre-soldered module to add a durable rotary knob, motor/servo position feedback, or absolute angle sensing to projects.
