# Arduino examples

- [`example.ino`](./example.ino) — Reads the GUVA-S12SD on Arduino A0, averages multiple 10-bit ADC samples, converts the result to millivolts assuming a 5V reference, estimates UV index as mV/100, and prints voltage and UV index over Serial.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/uv-sensor-guva-s12sd-arduino-esp32-manual)
