# GUVA-S12SD UV Light Intensity Sensor Module for Arduino & ESP32

The GUVA-S12SD is an analog UV light intensity sensor that outputs a voltage proportional to UV irradiance. Developers can use it to build sunlight sensors, UV exposure loggers, or alert systems by reading the sensor voltage with Arduino, ESP32, Raspberry Pi (via an ADC), or MicroPython boards and converting to an approximate UV index.
