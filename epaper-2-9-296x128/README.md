# 2.9" E-Paper E-Ink Display Module 296x128 Black/White SPI for Arduino, Raspberry Pi & ESP32

This is a 2.9-inch 296×128 black-and-white SPI E‑Paper (E‑Ink) display compatible with Arduino, Raspberry Pi, and ESP32. It is useful for building low-power information displays such as clocks, counters, gauges, and status panels that retain an image without power.
