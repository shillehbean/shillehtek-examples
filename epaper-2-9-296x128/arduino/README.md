# Arduino examples

- [`example.ino`](./example.ino) — Uses the GxEPD2 Arduino library to draw text, a rectangle and a fake gauge on the 2.9" e-Paper, performs a full refresh, then puts the display into hibernation to save power.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/e-ink-display-2-9-inch-296x128-spi-manual)
