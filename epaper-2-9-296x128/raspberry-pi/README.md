# Raspberry Pi examples

- [`example.py`](./example.py) — Uses Waveshare's epd2in9_V2 Python driver and Pillow on a Raspberry Pi to render text, a timestamp and a gauge to the 2.9" e-Paper and then put the display to sleep.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/e-ink-display-2-9-inch-296x128-spi-manual)
