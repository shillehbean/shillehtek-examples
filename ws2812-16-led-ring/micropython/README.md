# Micropython examples

- [`example_1.py`](./example_1.py) — ESP32 MicroPython example using the neopixel module to implement spinner, gauge, and breathing animations on GPIO13 with brightness scaling.
- [`example_2.py`](./example_2.py) — Raspberry Pi Pico MicroPython countdown-timer demo that empties the ring over a specified number of seconds and then flashes the LEDs (using GP0).
