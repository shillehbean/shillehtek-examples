# WS2812 16-LED RGB Ring

The WS2812 16-LED RGB Ring is a circular addressable LED array with 16 individually controllable WS2812 RGB LEDs and a single data input. Developers can use it to build rotating indicators, progress gauges, countdown timers, and other LED effects with Arduino, ESP32 (MicroPython), or Raspberry Pi projects.
