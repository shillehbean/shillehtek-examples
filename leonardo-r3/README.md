# Leonardo R3 ATmega32U4 Development Board for Arduino

The Leonardo R3 is an ATmega32U4-based Arduino-compatible development board with native USB HID and CDC (serial) support. Developers can use it to build USB keyboards/mice, serial sensor interfaces, relay controllers, and simple display or actuator projects using the Arduino IDE.
