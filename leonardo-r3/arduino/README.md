# Arduino examples

- [`example_1.ino`](./example_1.ino) — Blink the onboard LED on pin 13 every 500 ms and print a startup message over the USB serial port, waiting for the host serial connection (Leonardo-specific).
- [`example_2.ino`](./example_2.ino) — Use the Leonardo's native USB HID to send a typed text macro when a pushbutton on pin 2 is pressed, using the internal pull-up and a simple debounce.
