# BMP280 I2C IIC Digital Atmospheric Pressure, Temperature, Altitude Sensor

The BMP280 is a digital I2C sensor that measures atmospheric pressure, temperature, and provides estimated altitude. This repository contains example code for Arduino, Raspberry Pi, and MicroPython boards to read these values and build projects such as weather stations, altitude loggers, or drone telemetry.
