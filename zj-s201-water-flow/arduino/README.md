# Arduino examples

- [`example.ino`](./example.ino) — Arduino sketch that uses an interrupt on D2 to count pulses from the flow sensor and prints the instantaneous flow (L/min) and cumulative liters to Serial every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/water-flow-sensor-g1-2-1-30l-min-manual)
