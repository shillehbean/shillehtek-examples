# ZJ-S201 Water Flow Sensor G1/2" (1-30L/min) for Arduino, Raspberry Pi & ESP32

The ZJ-S201 is a G1/2" hall-effect water flow sensor that outputs pulses proportional to flow (approx. 1–30 L/min range). Developers can use it to build water meters, leak detectors, irrigation monitors, or logging projects with Arduino, ESP32, Raspberry Pi, or MicroPython-capable boards.
