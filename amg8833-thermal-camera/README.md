# AMG8833 Pre-Soldered 8x8 IR Thermal Imaging Camera Sensor for Arduino, Raspberry Pi & ESP32 (Pre-Soldered)

The AMG8833 is an 8x8 infrared thermal imaging sensor that reports per-pixel temperatures over I2C. Developers can use it for simple heat mapping, presence/body detection, or temperature-based interactions on Arduino, ESP32, or Raspberry Pi projects.
