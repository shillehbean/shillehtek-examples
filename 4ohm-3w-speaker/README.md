# 4 Ohm 3W Square Mini Speaker with 150mm Dupont Lead

This is a small square passive speaker (4 Ω, 3 W) with mounting tabs and a 150 mm red/black Dupont-style two-pin lead. Developers can use it for alarms, spoken prompts, MP3 playback, and game sound effects when paired with a suitable amplifier or audio output device.
