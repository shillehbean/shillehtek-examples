# 1027 Flat Coin Vibration Motor for Arduino, Raspberry Pi & ESP32

The 1027 Flat Coin Vibration Motor is a compact, low-profile eccentric-mass vibration motor intended for haptic feedback in small electronics projects. Developers can use it to add taps, buzzes, and ramped vibration patterns to Arduino, ESP32, or MicroPython-based boards; drive it via a transistor or motor driver from a 3.3V rail.
