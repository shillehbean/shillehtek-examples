# RC Servo Tester & CCPM Consistency Checker

This RC Servo Tester & CCPM Consistency Checker is a small board used to center servos, verify travel and direction, and compare CCPM-linked servos without a radio system. Developers can use it with microcontrollers to read tester output pulses, generate standard servo PWM signals, and automate travel/direction or CCPM consistency tests.
