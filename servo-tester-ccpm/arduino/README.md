# Arduino examples

- [`example_1.ino`](./example_1.ino) — Measure the pulse-width output from the tester on D2 and print the servo pulse width in microseconds to the serial console.
- [`example_2.ino`](./example_2.ino) — Read a potentiometer on A0 and output corresponding 800–2200 µs servo pulses on D9 to manually position a servo.
