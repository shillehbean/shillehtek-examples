# Arduino examples

- [`example.ino`](./example.ino) — Arduino example using SoftwareSerial and the Adafruit Fingerprint library to initialize the R307S, display stored template count, capture a fingerprint image, convert it to a template, and run a fast search for a matching template.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/fingerprint-sensor-r307s-optical-arduino-esp32-manual)
