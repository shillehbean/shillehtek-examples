# R307S Optical Fingerprint Sensor Module with Cable for Arduino, Raspberry Pi & ESP32

The R307S is an optical fingerprint sensor with a TTL serial interface and onboard template storage for enrolling and matching fingerprints. Developers can use it to add biometric authentication to projects on Arduino, Raspberry Pi, or ESP32 — for example door locks, time attendance systems, or device login.
