# BNO085 Pre-Soldered IMU Orientation Sensor Module

The BNO085 is a 9‑axis IMU that includes accelerometer, gyroscope, magnetometer and an on‑board SH‑2 sensor‑fusion processor that outputs quaternions, orientation, linear acceleration and more. These examples show how to use the module over UART (RVC) and I2C on Arduino/ESP32, Raspberry Pi (Python) and MicroPython (Pico).
