# BMP180 I2C IIC Digital Atmospheric Pressure, Temperature, Altitude Sensor

The BMP180 is an I2C atmospheric pressure sensor that provides temperature, barometric pressure, and derived altitude readings. This repository includes short examples for Arduino, Raspberry Pi (CircuitPython), and MicroPython so developers can integrate the BMP180 into weather stations, drones, or GPS/altitude-related projects.
