# Arduino examples

- [`example.ino`](./example.ino) — Reads temperature and pressure from a BMP180 using the Adafruit BMP085 Unified library and prints temperature, pressure, and computed altitude to the Serial console every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/bmp180-i2c-iic-digital-atmospheric-pressure-temperature-altitude-sensor)
