# Micropython examples

- [`example.py`](./example.py) — Runs on a MicroPython board (example: Pico) to read temperature, pressure, and altitude from a BMP180 via a third-party bmp180.py driver and prints the readings every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/bmp180-i2c-iic-digital-atmospheric-pressure-temperature-altitude-sensor)
