# Arduino examples

- [`example_1.ino`](./example_1.ino) — Blinks the onboard LED on pin 13 and writes LED state messages to the USB Serial Monitor at 9600 baud.
- [`example_2.ino`](./example_2.ino) — Bridges data between the USB Serial Monitor (Serial) and the board's hardware UART Serial1 (pins RX1=19, TX1=18), allowing passthrough to devices like GPS or Bluetooth modules.
