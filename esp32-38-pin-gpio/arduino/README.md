# Arduino examples

- [`example_1.ino`](./example_1.ino) — Toggle a chosen GPIO (TEST_PIN) on and off every 500 ms to blink an LED or verify wiring on the breakout.
- [`example_2.ino`](./example_2.ino) — Scan the I2C bus using SDA=21 and SCL=22 and print any detected device addresses over serial.
