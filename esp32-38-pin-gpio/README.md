# ESP32 38-Pin GPIO Expansion Breakout Board for ESP32 Development Boards

A 38-pin GPIO expansion breakout for ESP32 development boards that brings labeled GPIOs to easier-to-access terminals for cleaner sensor, display, and relay wiring. Use it to prototype and wire multiple peripherals without repeatedly swapping jumper wires on the raw ESP32 header. The examples show simple pin verification, I2C scanning, ADC reading with Wi‑Fi active, and a MicroPython pin-test routine.
