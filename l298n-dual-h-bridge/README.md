# L298N Motor Driver Controller Board Module for Stepper Motor & DC Dual H-Bridge

The ShillehTek L298N is a dual H-bridge motor driver board for driving two DC motors or a bipolar stepper with PWM speed control and direction. The examples in this repo show how to connect and control motors from Arduino, ESP32, Raspberry Pi (gpiozero), and Raspberry Pi Pico (MicroPython) to build small robot chassis, smart cars, or other motorized projects.
