# BH1750 Pre-Soldered Light Intensity Module

The SHILLEHTEK GY-302 BH1750 Pre-Soldered Light Intensity Sensor is a small I2C digital lux sensor with pre-soldered pins for easy connection. Use it to add ambient light measurement to projects such as automatic lighting control, display dimming, or environmental data logging; the examples cover Arduino, ESP32, Raspberry Pi, and MicroPython usage.
