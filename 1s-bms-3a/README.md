# 1S 3.7V 3A BMS

This is a single-cell (1S) 3.7V 3A battery management system (BMS) for 18650 lithium-ion cells. Developers use it to protect and manage charging/discharging of a single 18650 cell and to build battery-powered projects such as handheld devices, small IoT nodes, or simple battery monitors.
