# Esp32 examples

- [`example.ino`](./example.ino) — Reads battery voltage on an ESP32 ADC pin (GPIO34) through a 220k/100k divider, converts the 12-bit ADC value to the actual battery voltage, and prints it over Serial once per second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/1s-3-7v-3a-2mos-bms-li-ion-18650-battery-protection-board-manual)
