# Arduino examples

- [`example.ino`](./example.ino) — Reads a single-cell battery voltage on an Arduino via a 100k/100k divider (A0), converts the ADC result to battery voltage, estimates a rough state-of-charge percentage, and prints the values to Serial every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/1s-3-7v-3a-2mos-bms-li-ion-18650-battery-protection-board-manual)
