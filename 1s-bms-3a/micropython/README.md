# Micropython examples

- [`example.py`](./example.py) — Runs on a Raspberry Pi Pico (MicroPython) to read ADC0 (GP26) through a 100k/100k divider, convert the 16-bit ADC reading to battery voltage, and print the voltage every second.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/1s-3-7v-3a-2mos-bms-li-ion-18650-battery-protection-board-manual)
