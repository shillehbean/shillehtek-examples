# VL53L1X Pre-Soldered Time-of-Flight Laser Distance Sensor 400cm for Arduino, Raspberry Pi & ESP32

The VL53L1X is a time-of-flight (ToF) laser distance sensor capable of measuring up to about 4 meters. This pre-soldered breakout exposes the VL53L1X for easy use with Arduino, Raspberry Pi, and ESP32 so you can add distance sensing to robots, obstacle avoidance, presence detection, or level-measurement projects.
