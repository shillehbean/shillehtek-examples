# Esp32 examples

- [`example.ino`](./example.ino) — Sets up the VL53L1X on an ESP32 (explicit SDA/SCL pins) in short distance (fast) mode with a 20 ms timing budget and continuously prints distances to Serial at ~50 Hz.

Full wiring + setup notes: [manual](https://shillehtek.com/blogs/shillehtek-product-manuals/vl53l1x-tof-sensor-4m-pre-soldered-esp32-manual)
