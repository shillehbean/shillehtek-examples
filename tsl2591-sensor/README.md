# TSL2591 Pre-Soldered Digital Light Sensor Module

The TSL2591 is a high-dynamic-range digital light sensor with separate visible+IR and IR photodiodes and 16-bit converters. This pre-soldered breakout lets developers measure illuminance (lux) for ambient light control, data logging, or automated lighting projects.
