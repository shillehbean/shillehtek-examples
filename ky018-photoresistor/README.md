# KY-018 Photoresistor Light Sensor Module for Arduino & ESP32

The KY-018 is a simple photoresistor (LDR) sensor board that provides an analog voltage proportional to ambient light. Developers can use it to detect light/dark conditions for projects such as night lights, ambient light logging, or simple light-triggered events on Arduino, ESP32, Raspberry Pi (with an ADC), and MicroPython boards.
